# Fidenne 할 일별 지시서 — "무엇을 하려면"

할 일마다 **단계 → 잘 됐는지** 한 줄입니다. 안 되면 [문제 확인 가이드](TROUBLESHOOTING.md), 페이지마다 무엇이 있는지는 [사용 설명서](MANUAL.md)(각 절 끝의 **자세히**), 처음 켠 날은 [설치 · 사용 가이드](GUIDE.md), 왜 그렇게 동작하는지는 [설명](EXPLANATIONS.md)에 있습니다.
화면 위치는 `페이지 › 구역 › 조작` 입니다. 페이지는 사이드바에서 고릅니다(⌘1 스트리밍 · ⌘2 로컬 · ⌘3 청취 기록 · ⌘4 EQ · ⌘5 입출력 · 진단). 설정은 ⌘, 로 엽니다.
못 하는 것은 [알려진 한계](KNOWN_LIMITATIONS.md)에 있습니다.

## 1. Apple Music · Spotify 를 Fidenne 으로 듣기
1. `입출력 · 진단 › 고급 › 입력 (소리 받기)` 에서 **Fidenne Inlet**(없으면 같은 칸의 **설치…**, 관리자 암호 한 번) 또는 설치 없이 시스템 소리를 받는 **Process Tap** 을 고릅니다. 다른 루프백 앱은 **+ 다른 입력 장치**.
2. 출력 장치 카드의 출력 DAC 피커에서 DAC 를 고릅니다(안 보이면 ↻).
3. `입출력 · 진단 › 고급 › 스트리밍 앱 자동 재생 › 엔진 시작 후` 에서 **자동 감지** · **Apple Music** · **Spotify** · **YouTube Music(브라우저)** 중 하나. 선택: 입력이 Fidenne Inlet 이면 **Apple Music 원본 레이트 자동 적용** 으로 원본 레이트를 따릅니다.
4. 하단 재생 막대의 **엔진 스위치**를 켜고(처음이면 macOS 가 묻는 오디오 녹음 · 자동화를 허용) 재생 앱에서 곡을 틉니다.

**잘 됐는지**: 막대 상태 글자가 "실행 중" 이고 **Playback Chain** 의 음원 · 입력 · 장치 줄이 고른 것과 같습니다. 자세히: 설명서 [§7.3](MANUAL.md#73-스트리밍-앱-자동-재생--입력과-출력-장치) · [§3](MANUAL.md#3-스트리밍-페이지).

## 2. 특정 앱의 소리만 받기
1. 시스템 탭(Process Tap)은 이 판에서 **시스템 전체** 만 받습니다. 앱 하나의 소리만 받으려면 그 앱의 출력을 **Fidenne Inlet** 으로 보내고(시스템 설정 › 사운드 › 출력, 또는 그 앱의 출력 장치 설정), `입출력 · 진단 › 고급 › 입력 (소리 받기)` 을 **Fidenne Inlet** 으로 둡니다.
2. 엔진이 돌고 있으면 껐다 켭니다 — 다음 시작부터 적용됩니다.

**잘 됐는지**: 그 앱의 원래 출력은 들리지 않고 엔진 소리만 들립니다. 자세히: 설명서 [§7.3](MANUAL.md#73-스트리밍-앱-자동-재생--입력과-출력-장치).

## 3. 이 Mac 의 음악 파일 듣기
1. `로컬` 에서 **폴더 추가…**(또는 **음악 폴더** 메뉴)로 음악 폴더를 고르고 색인이 끝나길 기다립니다(다시: **음악 폴더 › 다시 색인**).
2. 검색 칸으로 곡을 찾아 두 번 누르거나 ⋯ → **다음에 재생** / **대기열 끝에 추가**. 재생목록은 **새 재생목록 이름** → **만들기**.
3. 순서는 줄을 끌어 바꿉니다(여러 곡은 ⌘-클릭 · Shift-클릭, 재생은 Return).
4. 선택: YouTube Music 재생목록은 `스트리밍 › YouTube Music › 내 재생목록` 맨 아래 **YouTube Music 보관함** 의 **YouTube Music 재생목록 가져오기…** 로 Google 테이크아웃 폴더를 고릅니다.

**잘 됐는지**: 막대에 곡이 뜨고 Playback Chain 의 소스가 파일입니다. 자세히: 설명서 [§4 보관함](MANUAL.md#4-로컬-페이지) · [§4.1](MANUAL.md#41-youtube-music-재생목록-가져오기).

## 4. 출력 장치(DAC) 바꾸기
1. `입출력 · 진단 › 출력 장치` 의 출력 DAC 피커에서 고릅니다. PCM Direct에서는 재생 중에도 바꿀 수 있습니다. 엔진으로 처리 중이면 엔진을 끈 뒤 바꿉니다.
2. 같은 USB DAC 를 다른 포트로 옮기기 전에는 엔진을 멈춥니다.
3. 선택: DAC 가 잠깐 빠졌다 돌아올 때 이어 재생하려면 `입출력 · 진단 › 고급 › DAC 다시 연결 › 30초 안에 다시 연결되면 이어서 재생` 을 켭니다.

**잘 됐는지**: Playback Chain 의 장치 줄이 새 장치 이름입니다. 자세히: 설명서 [§7.2](MANUAL.md#72-dac-형식-확인전-엔진-출력-형식) · [§7.3](MANUAL.md#73-스트리밍-앱-자동-재생--입력과-출력-장치).

## 5. 출력 형식 바꾸기 — DSD · PCM 정수 · PCM Direct
1. `입출력 · 진단 › 출력 방식` (또는 막대의 출력 방식 메뉴)에서 고릅니다 — **PCM Direct** · **PCM 오버샘플** · **DSD**.
2. PCM 오버샘플은 `고급 › PCM` 에서 **출력 레이트**(새 설정은 음원 레이트 유지 — [37](#37-pcm-출력-레이트-고르기--음원-계열-따라가기)번 절)와 **비트 깊이**(24 · 16-bit) · **디더** 도 고릅니다.
3. PCM Direct 로 바꾸기 전에는 DAC 음량을 낮춥니다 — 엔진의 헤드룸이 적용되지 않습니다.
4. 정지 상태에서 바꾸는 것이 가장 확실합니다. 재생 중이면 "다음 시작부터 적용됩니다".

**잘 됐는지**: Playback Chain 의 출력 줄이 고른 형식이고 `DAC 형식 확인` 표에서 **확인됨**(✓). 이 DAC 가 받는 것을 미리 보려면 정지 후 **모두 확인**. 자세히: 설명서 [§7.1](MANUAL.md#71-출력-독립-제어--출력-방식) · [§7.2](MANUAL.md#72-dac-형식-확인전-엔진-출력-형식).

## 6. 필터 · DSD 변환을 고르고 사운드 프리셋으로 저장
1. `입출력 · 진단 › 고급 › 필터`(막대의 출력 방식 메뉴 → **사운드 설정…** 도 여기로 옵니다)에서 처음이면 **어디서부터 들어볼까요?** 의 **추천 조합** 을 누릅니다. 직접은 **처리 방식** · **계열** · **길이**, 대가로 고르려면 **조건으로 고르기 · 비용 비교**.
2. DSD 변환은 `고급 › DSD 변환` 의 **변환 방식** · **출력 레이트**(정지 상태에서만). PCM 헤드룸은 **자동 (권장)** 으로 둡니다.
3. **지금 설정을 프리셋으로 저장…** 을 누릅니다 — 막대의 출력 방식 메뉴 "저장한 프리셋" 에 뜨고, 고르면 저장한 엔진 출력 방식(DSD 또는 PCM 깊이 · 출력 레이트)으로 바뀝니다. PCM Direct 는 저장하지 않습니다.

**잘 됐는지**: Playback Chain 의 필터 · 출력 줄이 고른 것입니다. 자세히: 설명서 [§7.4](MANUAL.md#74-필터--모듈레이터--출력-게인-카드--dsd-경로의-소리-설정).

## 7. 헤드폰 측정 · 타깃 불러오기
1. `DSP › EQ` 의 **Auto EQ** 줄(밴드 열 바로 앞)에서 **내 헤드폰** 를 폅니다. 즐겨찾기한 헤드폰이면 바로 고릅니다.
2. 없으면 **헤드폰 검색…**(처음이면 **목록 받기**)에서 이름을 넣고 결과를 눌러 **적용** 합니다. 줄 앞 ☆ 로 즐겨찾기에 넣습니다.
3. 목표는 **목표** 의 **타깃 곡선**(DF · DF t · Harman …) 또는 **목표 헤드폰 즐겨찾기**. 파일은 **측정 파일 열기…** · **타깃 파일 열기…**.

**잘 됐는지**: Response 그래프에 Headphone · Target 층이 그려지고 두 메뉴에 이름이 뜹니다(소리는 바뀌지 않습니다). 인터넷 목적지 squig.link 가 켜져 있어야 합니다([19](#19-인터넷에-나가는-것-끄기)). 자세히: 설명서 [§6.5](MANUAL.md#65-headphone---target--equalizer-의-auto-eq-줄--고급--파일--고역--생성형-ai-접힘).

## 8. 헤드폰에 맞춰 자동 EQ
1. 7번 절로 측정과 타깃을 정합니다.
2. `DSP › EQ › Auto EQ` 에서 **밴드 수** 로 밴드 수(기본 10)를 고르고 **적용** 을 누릅니다. 결과는 바로 들립니다.
3. 약하게는 **강도** 를 내리고, 좁은 굴곡이 남으면 Bands 를 12–16 으로 올려 다시 적용.
4. 마음에 들면 머리의 **저장**(⌘S). 한 칸 전은 ⌘Z, 저장한 것으로는 **저장본으로 되돌리기**.

**잘 됐는지**: 머리가 "엔진 설정과 일치" · "✓ 저장됨" 이고 **보정 뒤** 선이 점선 **타깃** 에 붙습니다. 탐지기가 경고하면 10번 절. 자세히: 설명서 [§6.6](MANUAL.md#66-bands--strength--auto-fit-equalizer-의-auto-eq-줄--자동-맞춤이-한-일-접힘).

## 9. EQ 를 손으로 만들고 적용 · 저장
1. `DSP › EQ` 에서 **EQ 켜기** 을 켭니다.
2. 밴드 열의 슬라이더나 그래프의 파란 점을 끌거나 종류 · Gain · Freq · Q 칸에 넣습니다(Return 으로 확정). 바꾸는 대로 바로 들립니다. 밴드는 **밴드 추가**, 31밴드는 **31밴드 그래픽**, 텍스트 프리셋은 **EQ 프리셋 열기…**.
3. 처음부터는 **초기화**, 저장본으로는 **저장본으로 되돌리기**, 한 칸은 ⌘Z.
4. **저장**(⌘S)을 누릅니다 — 들리는 EQ 가 화면의 Headphone · Target 과 함께 **지금 프리셋**(머리에 보이는 이름)에 저장되고 다음 실행에도 쓰입니다. Headphone · Target 만 바꿔도 저장이 켜집니다. 새 이름으로 남기려면 **다른 이름으로 저장…**. 이전 것은 **이전 저장본으로 되돌리기**.

**잘 됐는지**: 머리 "엔진 설정과 일치" · "✓ 저장됨", 앱을 다시 켜도 같은 밴드입니다. 자세히: 설명서 [§6.2](MANUAL.md#62-equalizer).

## 10. 과한 설정(부스트 · 클리핑) 고치기
1. Response 그래프 아래 탐지기에 "과한 설정 있음" 이 뜨면 **보정 제안…** 을 누릅니다.
2. 창은 **업계 관례**(Preamp 만 내림)로 열립니다. 선택: 넘친 밴드만 고치려면 **개선** 을 고릅니다. 바뀌는 밴드 표를 보고 **보정 적용**. 싫으면 탐지기의 **ⓘ › 보정 되돌리기**.
3. 클리핑만 막으려면 **ⓘ › 클리핑 막기 — Preamp 자동 낮춤** 을 켭니다(기본 꺼짐, Preamp 만 낮추고 밴드는 바꾸지 않음). 재생 중 잘리면 PCM 헤드룸이 **자동** 인지 보고, 아니면 `Equalizer › Clipping & Headroom` 의 **Apply Headroom N dB** 또는 **Turn Limiter On**.

**잘 됐는지**: 탐지기가 "과한 설정 없음", Clipping & Headroom 이 "이 재생에서 출력 단 클리핑 없음". 자세히: 설명서 [§6.2](MANUAL.md#62-equalizer) · [§6.1](MANUAL.md#61-response-그래프).

## 11. 저음 · 존재감 · 폭을 Ostrum 으로 다듬기
1. `DSP › Ostrum` 에서 **Ostrum On** 을 켭니다. 움직이는 것은 모두 바로 들립니다.
2. 머리의 **프리셋 ▾ → 자연스럽게** 로 시작합니다. 손으로는 **Tune** 을 정하고 **Mix** 를 올립니다(Mix 0 이면 Bass · Presence 가 들리지 않습니다).
3. Bass · Presence · Width 를 들으면서 맞춥니다. Harmonics 를 켰으면 **권장값으로 Headroom 맞추기**. Presence **Linear Phase** 는 **Restart Now** 로 바로 듣습니다.
4. 머리의 **저장**(⌘S). 싫으면 **저장본으로 되돌리기**. 여러 벌은 **프리셋 ▾ → 지금 설정을 내 프리셋으로 저장…**.

**잘 됐는지**: 머리에 `✓ 저장됨` · "적용됨 · 리비전 N" 이 뜨고 Response 그래프의 Ostrum 층이 0 dB 에서 벗어납니다. 자세히: 설명서 [§6.3](MANUAL.md#63-ostrum).

## 12. 헤드폰의 좌우 분리를 줄이기 — 크로스피드
1. `DSP › 크로스피드` 에서 **크로스피드 켜기** 를 켭니다.
2. **가볍게 · 보통 · 진하게** 를 눌러 보고, **양** 과 **주파수** 노브로 맞춥니다.
3. 마음에 드는 값은 **내 설정 › 지금 값을 저장…** 에 이름을 붙입니다.

**잘 됐는지**: 재생 중 M/S 창의 Side 가 내려갑니다(Mid 는 0.00 dB 그대로). 자세히: 설명서 [§6.4](MANUAL.md#64-crossfeed).

## 13. 잰 헤드폰 · 스피커 · 방의 소리를 입히기 — IR(컨볼루션)

**준비물**: WAV · AIFF IR 파일(1 · 2 · 4채널, 44.1–192 kHz). 앱에는 IR이 없습니다.

1. 사이드바 **DSP › 컨볼루션** 페이지에서 **IR 파일 고르기…**로 파일을 고릅니다.
2. 파일 준비가 끝나면 파일 정보와 **게인**을 확인합니다. 새 파일에는 현재 게인과 그 파일의 제안 게인 중 작은 값이 들어갑니다. 4채널 파일은 **채널 순서**도 확인합니다.
3. **켜기**를 켭니다.
4. 선택: 게인을 바꾸려면 숫자를 고친 뒤 **적용**을 누릅니다. **제안값**은 제안 게인을 바로 적용합니다. 상한은 0 Hz를 포함한 전 대역 응답으로 정해집니다.
5. 선택: IR이 적용 중일 때 **IR 없이 같은 지연으로 비교**를 켜서 비교합니다. IR을 끄려면 **켜기**를 끕니다.

**잘 됐는지**: 재생 중 패널에 **IR 적용 중**과 실제 지연이 나오고, Playback Chain의 PCM-A 체인에 컨볼루션이 보입니다. 지연은 약 24–49 ms 늘어납니다. 파일을 바꾸면 준비 중에는 이전 IR이 유지되므로 적용 상태를 확인합니다.

**안 되면**: 패널의 안내와 게인 상한을 확인합니다.

## 14. A/B 로 같은 음량 비교
이번 베타에서는 A/B 비교를 **숨겨 두었습니다** — DSP 페이지에 A/B 단추가 없습니다. 고친 뒤 다시 켭니다. 자세히: [알려진 한계](KNOWN_LIMITATIONS.md#베타-1-에서-뺀-것).

## 15. 차이가 정말 들리는지 가리고 시험하기 — ABX
이번 베타에서는 ABX 시험도 **숨겨 두었습니다**(A/B 와 같은 까닭). 자세히: [알려진 한계](KNOWN_LIMITATIONS.md#베타-1-에서-뺀-것).

## 16. 켬 · 끔을 자동으로 번갈아 듣기 — Auto Bypass · Loop
이번 베타에서는 Auto Bypass · Loop 비교도 **숨겨 두었습니다**. 켬 · 끔을 견주려면 DSP 페이지에서 그 기능의 켬 스위치를 직접 눌러 듣습니다. 자세히: [알려진 한계](KNOWN_LIMITATIONS.md#베타-1-에서-뺀-것).

**잘 됐는지**: 가사 패널에 가사가 뜹니다. 자세히: 설명서 [§2.3](MANUAL.md#23-가사).

## 18. 청취 기록 보기 · 내보내기

**잘 됐는지**: 고른 기간 · 출처의 재생이 그래프와 곡별 기록에 보입니다. 자세히: 설명서 [§5](MANUAL.md#5-청취-기록-페이지).

## 19. 인터넷에 나가는 것 끄기

2. 가사만 끄려면 `사이드바 › 가사 탭 › 가사 출처` 의 lrclib.net 스위치.

**잘 됐는지**: 전부 꺼도 소리 받기 · DSP · DSD 변환 · DAC 출력 · 로컬 재생은 됩니다. 자세히: 설명서 [§8](MANUAL.md#8-설정-창).

## 20. 문제가 생겼을 때 지원 파일 보내기
1. **도움말 → 문제 제보용 진단 만들기…**. 처음 실행할 때 «문제 제보용 진단 기록»에 동의했다면 이미 기록되고 있으니, 문제가 생긴 뒤 앱을 끄기 전에 바로 번들을 만듭니다. 꺼 두었다면 **진단 기록 시작** 을 눌러 두고, 다음에 문제가 생기면 그때 만듭니다.
2. **번들 만들고 내용 보기** 로 내용을 확인합니다(시각 · 서비스 · 레이트와 임의의 곡 표지가 들어 있고, 곡 이름은 가려집니다).
3. **메일로 보내기** 로 메일 앱이 열리면 다운로드 폴더의 .zip 파일을 첨부합니다(내용을 복사해 붙여 넣으면 잘립니다). 다른 메일(Gmail 등)을 쓰면 **메일 양식 복사** 로 주소 · 제목 · 양식을 복사해 붙여 넣습니다. 진단 번들은 메일로만 보내고 GitHub 이슈에는 올리지 않습니다.
4. 문제가 생긴 그때 **⌥⌃⌘K**(**도움말 → 방금 이상했음 표시**)를 눌러 두면 그 시각이 진단 기록에 표시되어 번들에서 찾기 쉽습니다.

**잘 됐는지**: **.zip 파일 보기** 로 다운로드 폴더의 .zip 파일이 보이고, 열면 폴더 안에 `support.json` · `manifest.json` · `tracks.json` · `README.txt` 가 있습니다. 자세히: 설명서 [§10](MANUAL.md#10-지원-파일-보내기).

## 21. 슬라이더 · 재생 위치를 두 손가락으로 조절
1. 포인터를 조작(재생 위치 · EQ 게인 · Ostrum 노브 · PCM 헤드룸 슬라이더 등) 위에 둡니다.
2. **⌘ 를 누른 채** 두 손가락으로 위로 쓸면 올라가고 아래로 쓸면 내려갑니다(느리게는 ⌥ 나 Shift 를 더합니다). 마우스는 ⌘ 를 누른 채 휠을 돌립니다 — 가로로 놓인 슬라이더는 ⌘ + Shift + 휠입니다. 재생 위치는 손을 뗄 때 한 번 이동합니다.
3. EQ 는 남기려면 저장(⌘S). 그래프 점은 먼저 눌러 고른 뒤 씁니다.

**잘 됐는지**: 쓰는 동안 조작 옆 숫자가 바뀝니다. 안 되면 `설정 › 조작과 단축키 › 두 손가락 스크롤로 값 바꾸기` 를 봅니다. 자세히: 설명서 [§2.6](MANUAL.md#26-노브--슬라이더--eq-점-다루기).

## 22. 기능 · 그래프 설명을 자세히 읽기
1. 구역 제목 아래 한 줄 끝의 **ⓘ** 를 누릅니다(키보드는 Tab 후 스페이스). 그래프는 줄 끝의 **ⓘ**.
2. **언제 쓰나요? · 무엇을 넣나요? · 바꾸면 무엇이 달라지나요? · 대가** 를 읽고 모르는 낱말은 **용어 풀이**. **Esc** 로 닫습니다.

**잘 됐는지**: 풍선이 ⓘ 바로 아래에 뜹니다(커서만 올려서는 열리지 않습니다). 자세히: 설명서 [§2.5](MANUAL.md#25-설명--그래프-읽는-법--용어-풀이).

## 23. 새 버전이 나왔는지 확인하기
1. 앱 메뉴 **Fidenne › 업데이트 확인…** 을 누릅니다.
2. "최신입니다" 면 끝. 새 판이 있으면 업데이트 창이 바뀐 점과 함께 뜨고, 설치를 고를 때만 새 판을 받습니다. 받은 판은 서명을 확인한 뒤에만 설치하고 Fidenne 을 다시 시작합니다. 아직 공개된 릴리스가 없으면 그렇다고 알립니다. 새 판을 받을 때 github.com 이 다른 주소(`release-assets.githubusercontent.com`)로 안내할 수 있고, 그 안내는 업데이트 도구가 직접 따라갑니다.
3. 누르지 않아도 됩니다: 처음 실행 때 GitHub 연결을 켜 두었으면 앱이 4 시간마다(켤 때와 잠자기에서 깰 때도) 스스로 확인하고, 새 판이 있으면 알림 창에 바뀐 것이 몇 줄 함께 뜹니다. 앱이 뒤에 있으면 새 버전마다 한 번 알림 배너가 뜨고, 누르면 업데이트 창이 열립니다(처음에 알림 권한을 묻고, 거절해도 앱 안 창으로 알립니다). 끄려면 `설정 › 개인정보 › 네트워크 목적지` 맨 아래 스위치 **새 버전을 자동으로 확인(4 시간마다)** 을 끕니다.

**잘 됐는지**: 결과 창의 "지금 판" 이 설정 창 맨 위 줄의 판 번호와 같습니다. 자세히: 설명서 [§8](MANUAL.md#8-설정-창).

## 24. 소리 내기 전 음량 안내 · 출력 감시 켜고 끄기
1. 처음 재생하면 뜨는 **음량을 낮추고 시작하세요** 에서 DAC · 앰프 음량을 낮추고 **낮췄어요, 시작**. 천천히 올립니다.
2. 매번 뜨는 것이 번거로우면 `설정 › 소리 안전 › 켤 때마다 음량 안내` 를 끕니다(처음 쓰는 DAC 는 한 번 뜹니다).
3. `설정 › 소리 안전 › 음악에 없는 신호가 나오면 음소거` 는 켜 둡니다.

**잘 됐는지**: 재생이 시작되고 창 머리에 음소거 줄이 없습니다. 자세히: 설명서 [§1](MANUAL.md#1-처음-켤-때--처음-설정-다섯-단계) · [§8](MANUAL.md#8-설정-창).

## 25. YouTube Music(Chrome)을 Fidenne 에서 보고 조작하기
1. `설정 › 일반` 의 **YouTube Music (실험 기능)** 을 켠 뒤, `설정 › 개인정보 › YouTube Music › 브라우저 확장과 연결 (Safari · Chrome · Edge)` 을 켜고 **설치 안내…** 에서 **Chrome** 이나 **Edge** 를 고릅니다.
2. 안내 창의 순서대로 합니다 — **주소 복사** → 주소창에 붙여 넣고 Return → **개발자 모드** 켬 → **압축해제된 확장 프로그램을 로드합니다**(Edge 는 **Load unpacked**) → **경로 복사** → 파일 창에서 ⌘⇧G · ⌘V · Return · **열기**.
3. 열려 있던 YouTube Music 탭을 ⌘R 로 새로 고치고 곡을 틉니다.
4. 쓰지 않는 탭을 재우는 브라우저에는 `music.youtube.com` 을 예외로 둡니다 — Chrome: 설정 → 성능 → 메모리 절약 → **항상 활성 상태를 유지할 사이트**, Edge: 설정 → 시스템 및 성능 → 리소스 절약 → **이 사이트를 절전 모드로 전환하지 않음**.

**잘 됐는지**: 안내 창 아래 줄이 `브라우저 1개 연결됨` 이고 막대에 그 곡과 "YouTube Music (브라우저)" 가 보입니다. 앱을 업데이트한 뒤에는 `chrome://extensions`(Edge `edge://extensions`)의 **Fidenne for YouTube Music** 카드에서 ↻ 를 한 번 누르고 탭을 ⌘R 합니다. 자세히: 설명서 [§8.1](MANUAL.md#81-youtube-music-쓰기-chrome-확장).

## 26. 스트리밍 페이지에서 YouTube Music 곡 틀기
1. 스트리밍 페이지 검색 칸 앞의 서비스 단추에서 **YouTube Music** 을 고릅니다. "연결 안 됨" 이면 25번 절을 합니다.
2. **내 재생목록** 에서 목록을 열어 **전체 재생**(또는 곡 하나). 목록이 없으면 YouTube Music 에서 그 화면을 한 번 엽니다 — 몇 초 안에 `브라우저에서` 로 나타납니다.
3. 찾으려면 **YouTube Music 에서 검색** 칸에 적고 Return.

**잘 됐는지**: 상태 줄이 `Chrome 에서 재생 중` 이고 곡과 이전 · 재생 · 다음 단추가 보입니다. 자세히: 설명서 [§8.1](MANUAL.md#81-youtube-music-쓰기-chrome-확장) · [§3](MANUAL.md#3-스트리밍-페이지).

## 27. 한 번에 찾아서, 보관함에 없는 곡을 Apple Music 보관함에 넣고 틀기
1. 스트리밍 페이지에서 서비스를 **Apple Music** 으로 두고 검색 칸에 적고 Return. 결과는 **Apple Music**(내 보관함) → **Apple Music 카탈로그** → **로컬 보관함** 순입니다.
2. 카탈로그 줄에서 **보관함에 추가** 를 누르고 처음 뜨는 확인 창에서 **추가**.
3. 줄이 `추가했습니다 · 보관함에 나타나는 중` 으로 바뀌었다가 단추가 **재생** 으로 바뀌면 누릅니다. Spotify 결과는 맨 위 **Spotify** 탭.

**잘 됐는지**: 추가한 곡이 Music 앱 보관함에도 보입니다. 자세히: 설명서 [§3](MANUAL.md#3-스트리밍-페이지).

## 28. Music 앱에서 튼 곡을 Fidenne 대기열로 이어 듣기
1. Music 앱에서 곡을 틉니다. Fidenne 하단 재생 캡슐의 표지를 눌러 큰 재생 화면을 열면 **다음 재생** 에 이어지는 곡이 뜹니다.
2. 순서를 Fidenne 이 정하게 하려면 곡 줄의 ⋯ 에서 **다음에 재생** · **대기열 끝에 추가**, 또는 막대의 셔플 · 반복을 씁니다.
3. 단추 셋이 뜨면 **이 앨범 이어 듣기** · **Fidenne 목록으로 돌아가기** · **Apple Music 자동 재생에 맡기기** 중 고릅니다.

**잘 됐는지**: 곡이 끝날 때 다음 재생의 다음 곡이 이어집니다. 자세히: 설명서 [§2.2](MANUAL.md#22-하단-재생-막대).

## 29. Spotify 를 처음 연결하기(내 키)
1. 스트리밍 페이지의 Spotify 옆 점(또는 Spotify 화면의 **연결하기**)을 눌러 여는 연결 창에서 **개발자 대시보드 열기** 를 눌러 Spotify 개발자 대시보드에서 앱을 하나 만듭니다.
2. 그 앱의 Redirect URI 에 칸에 보이는 주소를 넣습니다(옆 **복사** 단추).
3. 대시보드의 **Client ID** 를 Fidenne 의 칸에 붙여 넣습니다(Client Secret 은 넣지 않습니다).
4. **키 확인** 후 **Spotify 연결** 을 눌러 로그인 창에서 허용합니다.

**잘 됐는지**: 스트리밍 페이지 서비스 목록에서 Spotify 로 검색하면 결과가 나오고 연결 창에 **재생 권한 갱신** · **연결 해제** 가 있습니다. 키가 없어도 Spotify 앱 곡의 소리 처리는 됩니다. 자세히: 설명서 [§3](MANUAL.md#3-스트리밍-페이지).

## 36. Fidenne 이 열리다 멈출 때
1. 두 번 연속 시작을 마치지 못하면 세 번째에 **시작 복구** 창이 뜹니다. 설정은 지워지지 않습니다.
2. **안전하게 시작** 을 누르면 이번 한 번만 엔진 · 캡처 · 브라우저 확장 · 자동 재생 연결을 끄고 들어갑니다.
3. 문제를 알리려면 **진단 만들기…** 로 자료를 만들어 보냅니다(20번 절).
4. 앱을 끄고 다시 켜면 보통으로 돌아갑니다. 문제가 없어 보이면 **그대로 시작** 을 눌러도 됩니다.

**잘 됐는지**: 창에 `안전 시작 중` 이 보이고 설정을 열어 볼 수 있습니다. 자세히: 설명서 [시작이 두 번 연속 끝나지 못했을 때](MANUAL.md#1-처음-켤-때--처음-설정-다섯-단계).

## 37. PCM 출력 레이트 고르기 · 음원 계열 따라가기
**준비물**: 출력 방식 **PCM 오버샘플**. PCM Direct의 로컬 파일은 음원 레이트 유지 · 처리 우회 · 디더 끔을 사용합니다.
1. `입출력 · 진단 › 출력 방식` 에서 **PCM 오버샘플** 을 고르고 `고급 › PCM` 을 엽니다.
2. **출력 레이트** 팝업에서 레이트를 고릅니다(44.1 · 48 · 88.2 · 96 · 176.4 · 192 · 352.8 · 384 · 705.6 · 768 kHz). 장치가 받지 않는 레이트는 흐리게 `이 장치가 받지 않음` 으로 보입니다. 고른 레이트를 장치가 받지 않으면 나오는 **○○ kHz로 바꾸기** 를 누르면 장치가 받는 가장 높은 레이트가 됩니다.
3. 선택: 곡의 계열에 맞추려면 **음원 계열 따라가기** 를 켭니다. 44.1 kHz 계열 곡은 44.1 계열로, 48 kHz 계열 곡은 48 계열로 나가고, 팝업이 `88.2 / 96 kHz (×2)` 같은 배수 줄로 바뀝니다.
4. 선택: 배수 대신 장치가 받는 가장 높은 것을 쓰려면 팝업 첫 줄 **자동(장치 최고)** 을 고릅니다.

**잘 됐는지**: 팝업 아래 줄이 `음원 44.1 kHz → 출력 176.4 kHz (×4) · 24-bit` 처럼 실제로 한 일을 말하고, 자동이면 `자동 → 384 kHz` 가 보입니다. 계열이 바뀌는 곡 사이에는 잠깐 조용해집니다. 자세히: 설명서 [§7.1](MANUAL.md#71-출력-독립-제어--출력-방식).

**안 되면**: DAC 가 그 계열을 받지 않으면 `이 DAC는 … 계열을 받지 않아 … 계열로 변환해 내보냅니다` 가 뜨고 다른 계열로 나갑니다. 음원 레이트를 아직 모르는 곡은 `음원 레이트 확인 전 — 지금 계열 유지` 입니다.

## 38. 곡 사이 이음새 고르기 · DAC 첫 소리가 잘릴 때
**준비물**: **PCM 오버샘플** 로 듣는 로컬 파일(스트리밍 소리를 받아 처리하는 재생 · DSD 에서는 이 방식이 적용되지 않습니다).
1. `입출력 · 진단 › 고급 › PCM` 의 **곡 사이** 에서 **그대로**(음악 소리를 건드리지 않고 디지털 무음으로 잇기) 또는 **부드럽게**(곡이 끝나기 직전 0.02 초 동안 줄이기)를 고릅니다. 다음 곡부터 적용됩니다.
2. 곡이 바뀔 때 DAC 가 새 레이트를 잡는 동안 첫 소리가 잘리면 **레이트를 바꿀 때 기다림** 을 **0.5초** · **1초** · **2초** 로 늘립니다. DAC 마다 따로 정하고, 기본은 **0.25초** 입니다(**꺼짐** 도 있습니다).

**잘 됐는지**: 곡마다 `이번 곡: 그대로 · 레이트가 바뀌어 앞에 250 ms 무음` 또는 `레이트가 그대로라 앞 무음 없음` 한 줄이 보입니다. 자세히: 설명서 [§7.1](MANUAL.md#71-출력-독립-제어--출력-방식).

**안 되면**: 장치를 고르기 전에는 기다림을 정할 수 없습니다(`출력 장치를 고르면 정할 수 있습니다.`). Fidenne 이 내장 스피커 · AirPods 로도 소리를 처리해서 보내지만, 장치 레이트는 macOS 가 정하므로 Fidenne 이 바꾸지 않아 이 기다림 항목은 해당 없음입니다.

## 39. 내장 스피커 · AirPods · HDMI 로 Fidenne 처리해 듣기
1. 출력 DAC 피커에서 내장 스피커 · 헤드폰 단자 · AirPods(블루투스) · HDMI 모니터 같은 장치를 고릅니다. 이름 끝에 `· PCM Direct 만` 이 붙지 않습니다.
2. 출력 방식에서 **PCM** 을 고르고 재생을 시작합니다. 처음이면 `Mac 음량을 0이나 아주 낮게 내린 뒤 시작하고, 들으면서 천천히 올리세요.` 안내가 뜨니 Mac 음량을 낮춘 뒤 **낮췄어요, 시작** 을 누릅니다.
3. EQ · Ostrum · 크로스피드를 켜고 필터를 골라 듣습니다.

**잘 됐는지**: Fidenne 이 소리를 처리해서 보내며, 마지막에 macOS 가 시스템 믹서로 섞어 보내므로 비트 퍼펙트가 아닙니다. 출력 줄에 `시스템 믹서 경유 · macOS가 다시 처리` 이 보이고 비트 깊이 · 디더 줄은 흐립니다. 자세히: 설명서 [§7.1](MANUAL.md#71-출력-독립-제어--출력-방식).

**안 되면**: AirPods 마이크를 쓰는 앱이 열려 있으면 통화 음질이라 Fidenne 처리를 쉽니다 — 그 앱을 닫으면 저절로 다시 시작합니다. 장치 레이트가 다른 앱 때문에 바뀌어 멈추면 재생을 다시 누릅니다. 원음 데이터를 그대로 보내려면 외장 DAC 를 씁니다.

## 40. Audio Unit 플러그인 꽂기
1. 사이드바 **DSP › 플러그인** 페이지에서 **플러그인 추가** 를 눌러 목록에서 효과 플러그인을 고릅니다. 처음 보는 플러그인은 검사한 뒤 쓸 수 있습니다.
2. 카드의 **켜기** 를 누릅니다. 슬롯은 4 개까지입니다.
3. 선택: **편집기 열기** 로 플러그인 화면을 열어 값을 조절하고, ≡ 를 끌어 순서를 바꿉니다(⌥↑ · ⌥↓).

**잘 됐는지**: 다음 재생부터 카드에 `작동 중 · 지연 ○ ms` 가 보입니다. 자세히: 설명서 [§6.9](MANUAL.md#69-플러그인-페이지).

**안 되면**: 카드에 적힌 까닭(스테레오로 쓸 수 없음 · 샘플레이트를 받지 않음 · 처리가 늦음 …)을 보고 **다시 켜기** 나 **다시 불러오기** 를 누릅니다. 빼려면 **빼기**.

## 41. EQ 파일 가져오기(REW · EQ APO · AutoEq)
**준비물**: 필터 설정 텍스트(.txt, 2 MB 까지).
1. Playback Chain 의 EQ 패널에서 **내 EQ** 의 **가져오기…** 를 누르고 파일을 고르거나, 파일을 EQ 설정 칸에 끌어다 놓습니다.
2. **가져온 것** 과 **가져오지 않은 것** 을 읽습니다.
3. 이름을 확인하고 **내 EQ에 저장** 을 누릅니다.
4. **내 EQ** 에서 방금 저장한 EQ 를 고르면 적용됩니다.

**잘 됐는지**: `‘이름’ 으로 저장했습니다 — 내 EQ에서 고르면 적용됩니다.` 가 보입니다. 저장만 해서는 소리가 바뀌지 않습니다.

**안 되면**: `Preamp·Filter 줄을 찾지 못했습니다` 는 REW · Equalizer APO · AutoEq 필터 텍스트가 아니라는 뜻이고, 읽지 못하는 줄이 있으면 몇 번째 줄인지 알리며 파일 전체를 가져오지 않습니다. GraphicEQ 곡선은 DSP 페이지의 **EQ 프리셋 열기…** 으로 엽니다.

## 42. 홈에서 곡을 재생목록에 담고 묶고 기록에서 지우기
1. 스트리밍 페이지 첫 화면의 **오늘 들은 것** 에서 곡 타일을 끌어 **내 재생목록** 의 재생목록 타일에 놓습니다. 끌지 않으려면 타일의 ⋯ → **재생목록에 추가 ▸** 에서 목록을 고릅니다.
2. 선택: 같은 날의 곡을 묶으려면 타일의 ⋯ → **이 날의 묶음에 묶기 ▸**.
3. 선택: 보기 싫은 기록은 타일의 ⋯ → **기록에서 지우기**(또는 타일을 고르고 ⌫)를 누릅니다.

**잘 됐는지**: `‘이름’에 추가했어요` 또는 `기록에서 지웠어요` 토스트가 뜹니다. 되돌리려면 10 초 안에 **실행 취소** 나 ⌘Z 를 누릅니다. 서비스 재생목록에 쓴 것은 되돌리는 단추가 없습니다. 자세히: 설명서 [§3](MANUAL.md#3-스트리밍-페이지).

**안 되면**: 금지 커서는 받지 않는 곳입니다(이유가 한 줄 뜹니다). Spotify 목록은 처음 한 번 **허용…** 을 눌러야 하고, Apple Music 목록은 Music 앱이 켜져 있어야 합니다. 홈에서 지워도 청취 기록 통계에서는 지워지지 않습니다.

## 43. 단축어로 재생과 소리 처리 우회 부르기
1. 단축어 앱에서 새 단축어를 만들고 **Fidenne** 의 동작을 고릅니다 — **재생 / 일시정지** · **다음 곡** · **이전 곡** · **지금 재생 중인 곡** · **소리 처리 우회** · **EQ 프리셋 고르기**.
2. **소리 처리 우회** 는 켜기 / 끄기를 정하고, **EQ 프리셋 고르기** 는 저장해 둔 EQ 이름을 고릅니다.
3. 단축어를 실행합니다. Siri · Spotlight 에서는 `Play or pause in Fidenne` 처럼 부릅니다(영어 문구).

**잘 됐는지**: Fidenne 이 그 동작을 합니다(재생은 창의 단추와 같은 길입니다). **소리 처리 우회 끄기** 는 켜기가 끈 것만 되돌립니다. 자세히: 설명서 [§2.4](MANUAL.md#24-메뉴-막대-아이콘--메뉴).

**안 되면**: Apple Music · Spotify 를 제어하려면 시스템 설정의 자동화 허용이 필요하고, YouTube Music 은 연결된 탭이 있어야 합니다. 출력 장치 · 음량 · 출력 방식은 단축어로 바꿀 수 없습니다.

## 44. 가사에 발음 줄 켜고 줄 순서 바꾸기
1. 사이드바 **가사** 탭의 **표시 › 줄 순서 · 보이기** 에서 **발음** 줄의 눈 모양을 켭니다(기본은 꺼짐).
2. 선택: 줄을 끌어(또는 ⌥⌘↑ · ⌥⌘↓) 원문 · 발음 · 번역의 순서를 바꾸고, 눈 모양으로 줄마다 보이거나 숨깁니다. 하나는 보여야 합니다.
3. 선택: 발음이 틀리면 가사 탭에서 그 줄을 눌러 고치고 Return 을 누릅니다(Esc 는 취소).

**잘 됐는지**: 가사 화면 · 앨범 화면에 `발음 줄은 추정입니다` 와 함께 발음 줄이 정한 순서로 보입니다. 직접 고친 줄에는 `내가 고친 발음` 이 붙습니다. 발음은 macOS 가 읽은 추정이라 틀릴 수 있습니다.

## 45. 취침 타이머와 음량 키
1. 재생 메뉴(메뉴 막대 메뉴에도 있습니다)의 **취침 타이머** 에서 **30분** 같은 시간, **이 곡이 끝나면**, 또는 **직접 입력…**(1 ~ 720 분)을 고릅니다.
2. 끄려면 **타이머 끄기**.
3. 음량은 재생 메뉴의 **음량 올리기**(⌘↑) · **음량 내리기**(⌘↓) · **음소거**(⌥⌘↓)로 바꿉니다.

**잘 됐는지**: 메뉴 제목에 `취침 타이머 · ○분 남음` 이 보이고, 끝나면 재생이 일시정지합니다. 앱을 끄면 타이머도 사라집니다.

## 46. 화면을 영어 · 일본어로 쓰기
1. macOS 의 언어 순서(시스템 설정 › 일반 › 언어 및 지역)에서 영어나 일본어를 한국어보다 앞에 둡니다.
2. Fidenne 을 다시 시작합니다.

**잘 됐는지**: 사이드바와 설정이 영어 · 일본어로 보입니다. 앱 안에 따로 언어 스위치는 없고, 셋 어느 것도 아니면 한국어입니다. 번역은 AI 가 쓴 초안이라 어색한 문장이 있을 수 있고 원어민 검수 전입니다.
