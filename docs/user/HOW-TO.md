# Fidenne 할 일별 지시서 — "무엇을 하려면"

할 일마다 **단계 → 잘 됐는지** 한 줄입니다. 안 되면 [문제 확인 가이드](TROUBLESHOOTING.md), 페이지마다 무엇이 있는지는 [사용 설명서](MANUAL.md)(각 절 끝의 **자세히**), 처음 켠 날은 [설치 · 사용 가이드](GUIDE.md), 왜 그렇게 동작하는지는 [설명](EXPLANATIONS.md)에 있습니다.
화면 위치는 `페이지 › 구역 › 조작` 입니다. 페이지는 사이드바에서 고릅니다(⌘1 음악 · ⌘2 보관함 · ⌘3 청취 기록 · ⌘4 DSP · ⌘5 입출력 · 진단). 설정은 ⌘, 로 엽니다.
못 하는 것은 [알려진 한계](KNOWN_LIMITATIONS.md)에 있습니다.

## 1. Apple Music · Spotify 를 Fidenne 으로 듣기
1. `입출력 · 진단 › 입력과 출력 장치 › 입력` 에서 **Fidenne Inlet**(없으면 같은 칸의 **설치…**, 관리자 암호 한 번) 또는 설치 없이 시스템 소리를 받는 **Process Tap** 을 고릅니다. 다른 루프백 앱은 **+ 다른 입력 장치**.
2. 같은 칸의 출력 DAC 피커에서 DAC 를 고릅니다(안 보이면 ↻).
3. `입출력 · 진단 › 스트리밍 앱 자동 재생 › 엔진 시작 후` 에서 **자동 감지** · **Apple Music** · **Spotify** · **YouTube Music(브라우저)** 중 하나. 선택: 입력이 Fidenne Inlet 이면 **Apple Music 원본 레이트 자동 적용** 으로 원본 레이트를 따릅니다.
4. 하단 재생 막대의 **엔진 스위치**를 켜고(처음이면 macOS 가 묻는 오디오 녹음 · 자동화를 허용) 재생 앱에서 곡을 틉니다.

**잘 됐는지**: 막대 상태 글자가 "실행 중" 이고 **Playback Chain** 의 음원 · 입력 · 장치 줄이 고른 것과 같습니다. 자세히: 설명서 [§7.3](MANUAL.md#73-스트리밍-앱-자동-재생--입력과-출력-장치) · [§3](MANUAL.md#3-음악-페이지).

## 2. 특정 앱의 소리만 받기
1. 시스템 탭(Process Tap)은 이 판에서 **시스템 전체** 만 받습니다. 앱 하나의 소리만 받으려면 그 앱의 출력을 **Fidenne Inlet** 으로 보내고(시스템 설정 › 사운드 › 출력, 또는 그 앱의 출력 장치 설정), `입출력 · 진단 › 입력과 출력 장치 › 입력` 을 **Fidenne Inlet** 으로 둡니다.
2. 엔진이 돌고 있으면 껐다 켭니다 — 다음 시작부터 적용됩니다.

**잘 됐는지**: 그 앱의 원래 출력은 들리지 않고 엔진 소리만 들립니다. 자세히: 설명서 [§7.3](MANUAL.md#73-스트리밍-앱-자동-재생--입력과-출력-장치).

## 3. 이 Mac 의 음악 파일 듣기
1. `보관함` 에서 **폴더 추가…**(또는 **음악 폴더** 메뉴)로 음악 폴더를 고르고 색인이 끝나길 기다립니다(다시: **음악 폴더 › 다시 색인**).
2. 검색 칸으로 곡을 찾아 두 번 누르거나 ⋯ → **다음에 재생** / **대기열 끝에 추가**. 재생목록은 **새 재생목록 이름** → **만들기**.
3. 순서는 줄을 끌어 바꿉니다(여러 곡은 ⌘-클릭 · Shift-클릭, 재생은 Return).
4. 선택: YouTube Music 재생목록은 `음악 › YouTube Music › 내 재생목록` 맨 아래 **YouTube Music 보관함** 의 **YouTube Music 재생목록 가져오기…** 로 Google 테이크아웃 폴더를 고릅니다.

**잘 됐는지**: 막대에 곡이 뜨고 Playback Chain 의 소스가 파일입니다. 자세히: 설명서 [§4 보관함](MANUAL.md#4-보관함-페이지) · [§4.1](MANUAL.md#41-youtube-music-재생목록-가져오기).

## 4. 출력 장치(DAC) 바꾸기
1. `입출력 · 진단 › 입력과 출력 장치` 의 출력 DAC 피커(PCM Direct 면 `출력 방식 › 출력 DAC`)에서 고릅니다. 재생 중이면 앱이 출력을 다시 엽니다.
2. 같은 USB DAC 를 다른 포트로 옮기기 전에는 엔진을 멈춥니다.
3. 선택: DAC 가 잠깐 빠졌다 돌아올 때 이어 재생하려면 `입출력 · 진단 › DAC 형식 확인 › DAC가 30초 안에 다시 연결되면 이어서 재생` 을 켭니다.

**잘 됐는지**: Playback Chain 의 장치 줄이 새 장치 이름입니다. 자세히: 설명서 [§7.2](MANUAL.md#72-dac-형식-확인전-엔진-출력-형식) · [§7.3](MANUAL.md#73-스트리밍-앱-자동-재생--입력과-출력-장치).

## 5. 출력 형식 바꾸기 — DSD · PCM 정수 · PCM Direct
1. `입출력 · 진단 › 출력 방식` (또는 막대의 출력 방식 메뉴)에서 고릅니다 — **DSD (DoP)** · **PCM 352.8 kHz** · **PCM Direct**.
2. PCM 352.8 kHz 는 그 아래 **PCM 비트 깊이**(24 · 16-bit)와 **디더** 도 고릅니다.
3. PCM Direct 로 바꾸기 전에는 DAC 음량을 낮춥니다 — 엔진의 헤드룸이 적용되지 않습니다.
4. 정지 상태에서 바꾸는 것이 가장 확실합니다. 재생 중이면 "다음 시작부터 적용됩니다".

**잘 됐는지**: Playback Chain 의 출력 줄이 고른 형식이고 `DAC 형식 확인` 표에서 **확인됨**(✓). 이 DAC 가 받는 것을 미리 보려면 정지 후 **모두 확인**. 자세히: 설명서 [§7.1](MANUAL.md#71-출력-독립-제어--출력-방식) · [§7.2](MANUAL.md#72-dac-형식-확인전-엔진-출력-형식).

## 6. 필터 · DSD 변환을 고르고 사운드 프리셋으로 저장
1. `입출력 · 진단 › 필터 · 모듈레이터 · 출력 게인` 카드(막대의 출력 방식 메뉴 → **사운드 설정…** 도 여기로 옵니다)에서 처음이면 **어디서부터 들어볼까요?** 의 **추천 조합** 을 누릅니다. 직접은 **처리 방식** · **계열** · **길이**, 대가로 고르려면 **조건으로 고르기 · 비용 비교**.
2. DSD 변환은 **모듈레이터** · **출력 레이트** · **버퍼**(정지 상태에서만). PCM 헤드룸은 **자동 (권장)** 으로 둡니다.
3. "현재 사운드 프리셋 저장" 을 누릅니다 — 막대의 출력 방식 메뉴 "저장한 프리셋" 에 뜨고, 고르면 저장한 엔진 출력 방식(DSD 또는 PCM 깊이 · 352.8 kHz)으로 바뀝니다. PCM Direct 는 저장하지 않습니다.

**잘 됐는지**: Playback Chain 의 필터 · 출력 줄이 고른 것입니다. 자세히: 설명서 [§7.4](MANUAL.md#74-필터--모듈레이터--출력-게인-카드--dsd-경로의-소리-설정).

## 7. 헤드폰 측정 · 타깃 불러오기
1. `DSP › Equalizer` 의 **Auto EQ** 줄(밴드 열 바로 앞)에서 **Headphone ▾** 를 폅니다. 즐겨찾기한 헤드폰이면 바로 고릅니다.
2. 없으면 **헤드폰 검색…**(처음이면 **목록 받기**)에서 이름을 넣고 결과를 눌러 **적용** 합니다. 줄 앞 ☆ 로 즐겨찾기에 넣습니다.
3. 목표는 **Target ▾** 의 **타깃 곡선**(DF · DF t · Harman …) 또는 **목표 헤드폰 즐겨찾기**. 파일은 **측정 파일 열기…** · **타깃 파일 열기…**.

**잘 됐는지**: Response 그래프에 Headphone · Target 층이 그려지고 두 메뉴에 이름이 뜹니다(소리는 바뀌지 않습니다). 인터넷 목적지 squig.link 가 켜져 있어야 합니다([19](#19-인터넷에-나가는-것-끄기)). 자세히: 설명서 [§6.5](MANUAL.md#65-headphone---target--equalizer-의-auto-eq-줄--고급--파일--고역--생성형-ai-접힘).

## 8. 헤드폰에 맞춰 자동 EQ
1. 7번 절로 측정과 타깃을 정합니다.
2. `DSP › Equalizer › Auto EQ` 에서 **Bands** 로 밴드 수(기본 10)를 고르고 **Auto fit** 을 누릅니다. 결과는 바로 들립니다.
3. 약하게는 **Strength** 를 내리고, 좁은 굴곡이 남으면 Bands 를 12–16 으로 올려 다시 Auto fit.
4. 마음에 들면 머리의 **저장**(⌘S). 한 칸 전은 ⌘Z, 저장한 것으로는 **저장본으로 되돌리기**.

**잘 됐는지**: 머리가 "엔진 설정과 일치" · "✓ 저장됨" 이고 **보정 뒤** 선이 점선 **타깃** 에 붙습니다. 탐지기가 경고하면 10번 절. 자세히: 설명서 [§6.6](MANUAL.md#66-bands--strength--auto-fit-equalizer-의-auto-eq-줄--자동-맞춤이-한-일-접힘).

## 9. EQ 를 손으로 만들고 적용 · 저장
1. `DSP › Equalizer` 에서 **EQ On** 을 켭니다.
2. 밴드 열의 슬라이더나 그래프의 파란 점을 끌거나 종류 · Gain · Freq · Q 칸에 넣습니다(Return 으로 확정). 바꾸는 대로 바로 들립니다. 밴드는 **Add Band**, 31밴드는 **Graphic 31**, 텍스트 프리셋은 **Open EQ Preset…**.
3. 처음부터는 **초기화**, 저장본으로는 **저장본으로 되돌리기**, 한 칸은 ⌘Z.
4. **저장**(⌘S)을 누릅니다 — 들리는 EQ 가 화면의 Headphone · Target 과 함께 **지금 프리셋**(머리에 보이는 이름)에 저장되고 다음 실행에도 쓰입니다. Headphone · Target 만 바꿔도 저장이 켜집니다. 새 이름으로 남기려면 **다른 이름으로 저장…**. 이전 것은 **이전 저장본으로 되돌리기**.

**잘 됐는지**: 머리 "엔진 설정과 일치" · "✓ 저장됨", 앱을 다시 켜도 같은 밴드입니다. 자세히: 설명서 [§6.2](MANUAL.md#62-equalizer).

## 10. 과한 설정(부스트 · 클리핑) 고치기
1. Response 그래프 아래 탐지기에 "과한 설정 있음" 이 뜨면 **보정 제안…** 을 누릅니다.
2. 창은 **업계 관례**(Preamp 만 내림)로 열립니다. 선택: 넘친 밴드만 고치려면 **개선** 을 고릅니다. 바뀌는 밴드 표를 보고 **보정 적용**. 싫으면 탐지기의 **ⓘ › 보정 되돌리기**.
3. 클리핑만 막으려면 **ⓘ › 클리핑 막기 — Preamp 자동 낮춤** 을 켭니다(기본 꺼짐, Preamp 만 낮추고 밴드는 바꾸지 않음). 재생 중 잘리면 PCM 헤드룸이 **자동** 인지 보고, 아니면 `Equalizer › Clipping & Headroom` 의 **Apply Headroom N dB** 또는 **Turn Limiter On**.

**잘 됐는지**: 탐지기가 "과한 설정 없음", Clipping & Headroom 이 "이 재생에서 출력 단 클리핑 없음". 자세히: 설명서 [§6.2](MANUAL.md#62-equalizer) · [§6.1](MANUAL.md#61-response-그래프).

## 11. 저음 · 존재감 · 폭을 Ostrum 으로 다듬기
1. `DSP › Ostrum` 에서 **Ostrum On** 을 켭니다. 움직이는 것은 모두 바로 들립니다.
2. 머리의 **프리셋 ▾ → 자연스럽게** 로 시작합니다. 손으로는 **Tune** 을 정하고 **Mix** 를 올립니다(Mix 0 이면 Bass · Presence 가 들리지 않습니다).
3. Bass · Presence · Width 를 들으면서 맞춥니다. Harmonics 를 켰으면 **권장값으로 Headroom 맞추기**. Presence **Linear Phase** 는 **Restart Now** 로 바로 듣습니다.
4. 머리의 **저장**(⌘S). 싫으면 **저장본으로 되돌리기**. 여러 벌은 **프리셋 ▾ → 지금 설정을 내 프리셋으로 저장…**.

**잘 됐는지**: 머리에 `✓ 저장됨` · "적용됨 · 리비전 N" 이 뜨고 Response 그래프의 Ostrum 층이 0 dB 에서 벗어납니다. 자세히: 설명서 [§6.3](MANUAL.md#63-ostrum).

## 12. 헤드폰의 좌우 분리를 줄이기 — 크로스피드
1. `DSP › Crossfeed` 에서 **크로스피드 켜기** 를 켭니다.
2. **가볍게 · 보통 · 진하게** 를 눌러 보고, **양** 과 **주파수** 노브로 맞춥니다.
3. 마음에 드는 값은 **내 설정 › 지금 값을 저장…** 에 이름을 붙입니다.

**잘 됐는지**: 재생 중 M/S 창의 Side 가 내려갑니다(Mid 는 0.00 dB 그대로). 자세히: 설명서 [§6.4](MANUAL.md#64-crossfeed).

## 14. A/B 로 같은 음량 비교
이번 베타에서는 A/B 비교를 **숨겨 두었습니다** — DSP 페이지에 A/B 단추가 없습니다. 고친 뒤 다시 켭니다. 자세히: [알려진 한계](KNOWN_LIMITATIONS.md#베타-1-에서-뺀-것).

## 15. 차이가 정말 들리는지 가리고 시험하기 — ABX
이번 베타에서는 ABX 시험도 **숨겨 두었습니다**(A/B 와 같은 까닭). 자세히: [알려진 한계](KNOWN_LIMITATIONS.md#베타-1-에서-뺀-것).

## 16. 켬 · 끔을 자동으로 번갈아 듣기 — Auto Bypass · Loop
이번 베타에서는 Auto Bypass · Loop 비교도 **숨겨 두었습니다**. 켬 · 끔을 견주려면 DSP 페이지에서 그 기능의 켬 스위치를 직접 눌러 듣습니다. 자세히: [알려진 한계](KNOWN_LIMITATIONS.md#베타-1-에서-뺀-것).

## 17. 가사 보기
1. 곡을 재생하고 막대의 ⋯ → **가사 보기**.
2. 처음이면 **동의하고 찾기**(제목 · 아티스트 · 앨범 · 길이만 나갑니다). 싫으면 **보내지 않음** 후 LRC · TXT 파일을 연결합니다.
3. 타이밍은 시계 단추를 눌러 + / −, 글자 크기는 `설정 › 화면 › 가사 글자 크기`, 다른 판은 출처 줄의 **다른 판**으로 찾고, 판이 둘 이상이면 **가사 판**에서 고릅니다.

**잘 됐는지**: 가사 패널에 가사가 뜹니다. 자세히: 설명서 [§2.3](MANUAL.md#23-가사).

## 18. 청취 기록 보기 · 내보내기
1. `청취 기록` 에서 **최근** 기간과 **출처** 를 고릅니다.
2. **내보내기** → **JSON · 집계 기준 포함** 또는 **CSV · 1행 = 재생 1회**.
3. 기록을 멈추려면 **기록 설정과 집계 기준 › 이 Mac에 청취 기록 저장** 을 끕니다.

**잘 됐는지**: 고른 기간 · 출처의 재생이 그래프와 곡별 기록에 보입니다. 자세히: 설명서 [§5](MANUAL.md#5-청취-기록-페이지).

## 19. 인터넷에 나가는 것 끄기
1. `설정 › 개인정보 › 네트워크 목적지` 에서 목적지마다 끕니다.
2. 가사만 끄려면 `설정 › 개인정보 › 가사 인터넷 검색 › lrclib.net에서 가사 찾기`.

**잘 됐는지**: 전부 꺼도 소리 받기 · DSP · DSD 변환 · DAC 출력 · 로컬 재생은 됩니다. 자세히: 설명서 [§8](MANUAL.md#8-설정-창).

## 20. 문제가 생겼을 때 지원 파일 보내기
1. **도움말 → 문제 제보용 진단 만들기…**. 처음 실행할 때 «문제 제보용 진단 기록»에 동의했다면 이미 기록되고 있으니, 문제가 생긴 뒤 앱을 끄기 전에 바로 번들을 만듭니다. 꺼 두었다면 **진단 기록 시작** 을 눌러 두고, 다음에 문제가 생기면 그때 만듭니다.
2. **번들 만들고 내용 보기** 로 내용을 확인합니다(곡 제목 · 아티스트 · 서비스가 들어 있습니다).
3. **메일로 보내기** 로 메일 앱이 열리면 폴더를 압축해 붙입니다. 다른 메일(Gmail 등)을 쓰면 **메일 양식 복사** 로 주소 · 제목 · 양식을 복사해 붙여 넣습니다. 진단 번들은 메일로만 보내고 GitHub 이슈에는 올리지 않습니다.

**잘 됐는지**: **번들 폴더 열기** 의 폴더에 `support.json` · `manifest.json` · `tracks.json` · `README.txt` 가 있습니다. 자세히: 설명서 [§10](MANUAL.md#10-지원-파일-보내기).

## 21. 슬라이더 · 재생 위치를 두 손가락으로 조절
1. 포인터를 조작(재생 위치 · EQ 게인 · Ostrum 노브 · PCM 헤드룸 슬라이더 등) 위에 둡니다.
2. **⌘ 를 누른 채** 두 손가락으로 위로 쓸면 올라가고 아래로 쓸면 내려갑니다(느리게는 ⌥ 나 Shift 를 더합니다). 재생 위치는 손을 뗄 때 한 번 이동합니다.
3. EQ 는 남기려면 저장(⌘S). 그래프 점은 먼저 눌러 고른 뒤 씁니다.

**잘 됐는지**: 쓰는 동안 조작 옆 숫자가 바뀝니다. 안 되면 `설정 › 조작과 단축키 › 두 손가락 스크롤로 값 바꾸기` 를 봅니다. 자세히: 설명서 [§2.6](MANUAL.md#26-노브--슬라이더--eq-점-다루기).

## 22. 기능 · 그래프 설명을 자세히 읽기
1. 구역 제목 아래 한 줄 끝의 **ⓘ** 를 누릅니다(키보드는 Tab 후 스페이스). 그래프는 줄 끝의 **ⓘ**.
2. **언제 쓰나요? · 무엇을 넣나요? · 바꾸면 무엇이 달라지나요? · 대가** 를 읽고 모르는 낱말은 **용어 풀이**. **Esc** 로 닫습니다.

**잘 됐는지**: 풍선이 ⓘ 바로 아래에 뜹니다(커서만 올려서는 열리지 않습니다). 자세히: 설명서 [§2.5](MANUAL.md#25-설명--그래프-읽는-법--용어-풀이).

## 23. 새 버전이 나왔는지 확인하기
1. 앱 메뉴 **Fidenne › 업데이트 확인…** 을 누릅니다.
2. "최신입니다" 면 끝. 새 판이 있으면 Homebrew 로 설치했을 때는 **명령 복사** 로 터미널 명령을 복사하고, .dmg 로 설치했을 때는 **릴리스 페이지 열기** 에서 새 .dmg 를 받습니다. 앱이 스스로 받아 설치하지 않습니다. 아직 공개된 릴리스가 없으면 그렇다고 알립니다.
3. 선택: `설정 › 개인정보 › 네트워크 목적지` 맨 아래에 **새 버전을 하루에 한 번 자동으로 확인** 이 보이면 켤 수 있습니다(기본 꺼짐).

**잘 됐는지**: 결과 창의 "지금 판" 이 설정 창 맨 위 줄의 판 번호와 같습니다. 자세히: 설명서 [§8](MANUAL.md#8-설정-창).

## 24. 소리 내기 전 음량 안내 · 출력 감시 켜고 끄기
1. 처음 재생하면 뜨는 **음량을 낮추고 시작하세요** 에서 DAC · 앰프 음량을 낮추고 **낮췄어요, 시작**. 천천히 올립니다.
2. 매번 뜨는 것이 번거로우면 `설정 › 소리 안전 › 켤 때마다 음량 안내` 를 끕니다(처음 쓰는 DAC 는 한 번 뜹니다).
3. `설정 › 소리 안전 › 음악에 없는 신호가 나오면 음소거` 는 켜 둡니다.

**잘 됐는지**: 재생이 시작되고 창 머리에 음소거 줄이 없습니다. 자세히: 설명서 [§1](MANUAL.md#1-처음-켤-때--처음-설정-다섯-단계) · [§8](MANUAL.md#8-설정-창).

## 25. YouTube Music(Chrome)을 Fidenne 에서 보고 조작하기
1. `설정 › 개인정보 › YouTube Music › Chrome · Edge 확장과 연결` 을 켜고 **설치 안내…** 에서 **Chrome** 이나 **Edge** 를 고릅니다.
2. 안내 창의 순서대로 합니다 — **주소 복사** → 주소창에 붙여 넣고 Return → **개발자 모드** 켬 → **압축해제된 확장 프로그램을 로드합니다**(Edge 는 **Load unpacked**) → **경로 복사** → 파일 창에서 ⌘⇧G · ⌘V · Return · **열기**.
3. 열려 있던 YouTube Music 탭을 ⌘R 로 새로 고치고 곡을 틉니다.
4. 쓰지 않는 탭을 재우는 브라우저에는 `music.youtube.com` 을 예외로 둡니다 — Chrome: 설정 → 성능 → 메모리 절약 → **항상 활성 상태를 유지할 사이트**, Edge: 설정 → 시스템 및 성능 → 리소스 절약 → **이 사이트를 절전 모드로 전환하지 않음**.

**잘 됐는지**: 안내 창 아래 줄이 `브라우저 1개 연결됨` 이고 막대에 그 곡과 "YouTube Music (브라우저)" 가 보입니다. 앱을 업데이트한 뒤에는 `chrome://extensions`(Edge `edge://extensions`)의 **Fidenne for YouTube Music** 카드에서 ↻ 를 한 번 누르고 탭을 ⌘R 합니다. 자세히: 설명서 [§8.1](MANUAL.md#81-youtube-music-쓰기-chrome-확장).

## 26. 음악 페이지에서 YouTube Music 곡 틀기
1. 음악 페이지 검색 칸 앞의 서비스 단추에서 **YouTube Music** 을 고릅니다. "연결 안 됨" 이면 25번 절을 합니다.
2. **내 재생목록** 에서 목록을 열어 **전체 재생**(또는 곡 하나). 목록이 없으면 YouTube Music 에서 그 화면을 한 번 엽니다 — 몇 초 안에 `브라우저에서` 로 나타납니다.
3. 찾으려면 **YouTube Music 에서 검색** 칸에 적고 Return.

**잘 됐는지**: 상태 줄이 `Chrome 에서 재생 중` 이고 곡과 이전 · 재생 · 다음 단추가 보입니다. 자세히: 설명서 [§8.1](MANUAL.md#81-youtube-music-쓰기-chrome-확장) · [§3](MANUAL.md#3-음악-페이지).

## 27. 한 번에 찾아서, 보관함에 없는 곡을 Apple Music 보관함에 넣고 틀기
1. 음악 페이지에서 서비스를 **Apple Music** 으로 두고 검색 칸에 적고 Return. 결과는 **Apple Music**(내 보관함) → **Apple Music 카탈로그** → **로컬 보관함** 순입니다.
2. 카탈로그 줄에서 **보관함에 추가** 를 누르고 처음 뜨는 확인 창에서 **추가**.
3. 줄이 `추가했습니다 · 보관함에 나타나는 중` 으로 바뀌었다가 단추가 **재생** 으로 바뀌면 누릅니다. Spotify 결과는 맨 위 **Spotify** 탭.

**잘 됐는지**: 추가한 곡이 Music 앱 보관함에도 보입니다. 자세히: 설명서 [§3](MANUAL.md#3-음악-페이지).

## 28. Music 앱에서 튼 곡을 Fidenne 대기열로 이어 듣기
1. Music 앱에서 곡을 틉니다. Fidenne 하단 재생 캡슐의 표지를 눌러 큰 재생 화면을 열면 **다음 재생** 에 이어지는 곡이 뜹니다.
2. 순서를 Fidenne 이 정하게 하려면 곡 줄의 ⋯ 에서 **다음에 재생** · **대기열 끝에 추가**, 또는 막대의 셔플 · 반복을 씁니다.
3. 단추 셋이 뜨면 **이 앨범 이어 듣기** · **Fidenne 목록으로 돌아가기** · **Apple Music 자동 재생에 맡기기** 중 고릅니다.

**잘 됐는지**: 곡이 끝날 때 다음 재생의 다음 곡이 이어집니다. 자세히: 설명서 [§2.2](MANUAL.md#22-하단-재생-막대).

## 29. Spotify 를 처음 연결하기(내 키)
1. 설정의 Spotify 칸에서 **개발자 대시보드 열기** 를 눌러 Spotify 개발자 대시보드에서 앱을 하나 만듭니다.
2. 그 앱의 Redirect URI 에 칸에 보이는 주소를 넣습니다(옆 **복사** 단추).
3. 대시보드의 **Client ID** 를 Fidenne 의 칸에 붙여 넣습니다(Client Secret 은 넣지 않습니다).
4. **키 확인** 후 **Spotify 연결** 을 눌러 로그인 창에서 허용합니다.

**잘 됐는지**: 음악 페이지 서비스 목록에서 Spotify 로 검색하면 결과가 나오고 설정에 **재생 권한 갱신** · **연결 해제** 가 있습니다. 키가 없어도 Spotify 앱 곡의 소리 처리는 됩니다. 자세히: 설명서 [§3](MANUAL.md#3-음악-페이지).

## 30. 베타를 받고 문제를 알리기
1. 릴리스 페이지(`https://github.com/fidenne/fidenne/releases`)에서 서명 · 공증된 `.dmg` 를 받습니다(Apple 실리콘 Mac, macOS 26 이상).
2. 20번 절로 지원 파일을 만들고, 메일 **fidenne.support@gmail.com** 으로 보냅니다(**메일로 보내기** 나 **메일 양식 복사** 가 주소 · 제목 · 양식을 채워 줍니다).
3. DAC 와 출력 방식 · 언제 무엇을 하다가 무엇이 들렸나 보였나를 함께 적습니다. 앱 버전과 macOS 버전은 양식과 번들에 저절로 들어 있습니다. 보안 문제는 공개 이슈 대신 메일로 보냅니다.

**잘 됐는지**: 메일에 위 내용과 지원 파일이 들어 있습니다. 앱은 아무것도 대신 보내지 않습니다. 자세히: 설명서 [베타 안내와 제보 경로](MANUAL.md#베타-안내와-제보-경로).
