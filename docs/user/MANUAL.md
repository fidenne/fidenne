# Fidenne 사용 설명서

## 한 페이지 요약

**Fidenne 은 무엇인가요** — Apple Music · Spotify · YouTube Music 의 소리나 이 Mac 의 음악 파일을 받아 EQ · Ostrum · 크로스피드와 필터로 다듬고, **유선 USB 외장 DAC**(필수)로 보내는 macOS 앱입니다. Apple 실리콘 Mac 과 **macOS 26 이상**이 필요합니다.

**다섯 페이지** (사이드바, ⌘1–⌘5)

- **음악** — 서비스를 골라 검색하고 틀고, 첫 화면에서 이어 듣습니다. ([§3](#3-음악-페이지))
- **보관함** — 이 Mac 의 음악 폴더를 읽어 곡 · 앨범 · 재생목록으로 봅니다. ([§4](#4-보관함-페이지))
- **청취 기록** — 들은 기록을 기간 · 출처별로 보고 내보냅니다. ([§5](#5-청취-기록-페이지))
- **DSP** — Response 그래프, Equalizer(Auto EQ 포함), Ostrum, Crossfeed. ([§6](#6-dsp-페이지))
- **입출력 · 진단** — 출력 방식, 입력과 출력 장치(DAC), 필터 · DSD 변환, 지금 소리가 지나는 길. ([§7](#7-입출력--진단-페이지))

**출력 방식 셋** (`입출력 · 진단 › 출력 방식`, [§7.1](#71-출력-독립-제어--출력-방식))

- **PCM Direct** — Fidenne 은 소리를 처리하지 않습니다. 재생 앱 → macOS → DAC 로 바로 나갑니다. 곡마다 레이트를 맞추지 않고 시작할 때 한 번 정하며, 레이트가 다르면 macOS 가 변환합니다.
- **DSD (DoP)** — Fidenne 이 처리해 DSD 로 DAC 에 보냅니다.
- **PCM 352.8 kHz** — Fidenne 이 처리해 352.8 kHz PCM(24 · 16-bit)으로 보냅니다.
- DSD · PCM 352.8 kHz 는 EQ · Ostrum · 크로스피드를 끄면 톤을 바꾸는 처리는 없지만, 그 형식에 필요한 변환(업샘플링 필터 · DSD 변조기 · 디더 · 헤드룸)은 걸립니다.

**음량 주의** — 처음 재생할 때는 DAC · 앰프 음량을 낮추고 시작해, 들으면서 천천히 올립니다([§1](#1-처음-켤-때--처음-설정-다섯-단계)).

**도움이 필요하면** — 할 일별 순서는 [할 일별 지시서](HOW-TO.md), 첫 설치는 [설치 · 사용 가이드](GUIDE.md), 안 될 때는 [문제 확인 가이드](TROUBLESHOOTING.md), 궁금할 때 읽는 문답은 [설명](EXPLANATIONS.md), 아직 못 하는 것은 [알려진 한계](KNOWN_LIMITATIONS.md). 문제를 알리는 길은 [§10](#10-지원-파일-보내기)과 [베타 안내와 제보 경로](#베타-안내와-제보-경로)입니다. **〔실험〕** 은 앱이 스스로 "실험" 이라고 표시하는 선택지입니다.

## 0. 한눈에

소리가 지나는 길: 재생 앱의 소리(Fidenne Inlet 또는 시스템 탭으로 받음)나 이 Mac 의 음악 파일 → Fidenne → DSD(DoP) 또는 PCM 352.8 kHz → DAC. **PCM Direct** 는 재생 앱 → macOS → DAC 이고 Fidenne 을 거치지 않습니다.

### Fidenne이 하는 것 · 하지 않는 것

각 음악 서비스의 약관과 정책에 맞추어 만들었고, 그 내용이 바뀌면 따라 고칩니다. Fidenne이 무엇으로 무엇을 하는지 적었습니다. 처음 설정 다섯 단계 가운데 네 번째와 같은 글이고, 앱 메뉴 › **Fidenne이 하는 것 · 하지 않는 것** 에서 다시 볼 수 있습니다.

**하는 것**

- macOS가 앱에 열어 둔 오디오 기능(CoreAudio · 오디오 캡처)으로 재생 앱의 소리를 받아, 실시간으로 다듬어 고른 DAC로 보냅니다.
- Music · Spotify 앱이 스스로 내놓는 AppleScript로 지금 곡을 읽고, 재생 · 일시정지 · 곡 이동을 전합니다.
- Apple Music 보관함과 카탈로그는 Apple이 주는 MusicKit(Apple Music API)으로, 허용했을 때만 읽습니다.
- YouTube Music은 직접 설치하는 Chrome · Edge 확장이 열린 탭의 곡 정보를 이 Mac 안에서 알려 줍니다.
- Spotify 검색 · 재생목록 · 재생 조종(Spotify Web API)은 본인 Spotify 개발자 앱의 키를 넣었을 때만 켜집니다.
- 청취 기록은 재생 앱이 AppleScript로 보여 주는 지금 곡(제목 · 아티스트 · 앨범 · 곡 길이)과 들은 시간으로 셉니다 — 로컬 파일은 파일 태그로. 이 Mac에만 두고 밖으로 보내지 않습니다.

**하지 않는 것**

- 소리를 저장하거나 파일로 만들지 않습니다. 녹음 기능이 없습니다.
- 음악 서비스 구독을 대신하거나 우회하지 않습니다. 곡은 각 서비스의 앱과 내 계정으로 재생됩니다.
- Fidenne이 운영하는 서버가 없습니다. 서비스 로그인 정보는 그 서비스로만 갑니다.
- Spotify 검색 결과를 다른 서비스의 결과와 한 화면에 섞지 않습니다.
- Spotify Web API가 준 정보를 서비스 사이 곡 연결 · 청취 통계 · 다른 서비스로 보내기에 쓰지 않습니다.
- 광고와 판매가 없습니다. 분석 · 광고 SDK를 넣지 않았습니다.

### Fidenne 이 쓰는 것

Fidenne 은 Apple · Spotify · Google 과 관계없는 개인이 만든 무료 앱입니다. Apple Music 은 Apple Inc., Spotify 는 Spotify AB, YouTube Music 은 Google LLC 의 상표입니다.

- **Apple Music** — Music 앱을 macOS 자동화로 조작합니다. 보관함 목록은 Apple 의 Apple Music 연동으로 읽고, 들은 곡(Apple Music · Spotify · YouTube Music)의 다른 표기와 같은 곡은 Apple Music 카탈로그에 물어, 가사 찾기와 같은 곡 잇기에 앱이 켜져 있는 동안 메모리에서만 씁니다(카탈로그의 답은 저장하지 않음). 곡마다 원본 레이트를 맞추려고 Music 의 오디오 기록 줄을 읽습니다(저장하지 않음).
- **Spotify** — Spotify 앱을 macOS 자동화로 조작합니다. 검색 · 재생목록 화면은 사용자가 직접 만든 Spotify 개발자 키가 있을 때만 씁니다(선택).
- **YouTube Music** — 브라우저 확장이 열린 페이지의 곡 정보를 읽고 재생 · 멈춤 같은 조작을 전합니다. 사이트를 혼자 돌아다니지 않고, 사람이 누른 한 번에 그 한 페이지만 엽니다. 광고는 건드리지 않습니다. 실험 기능입니다.
- **가사** — LRCLIB(lrclib.net). 가사 칸 아래에 `가사 제공 LRCLIB` 줄이 보입니다. 가사의 저작권은 각 권리자에게 있습니다.
- **헤드폰 측정** — squig.link 의 공개 측정 데이터를 받아 보정에 씁니다. 측정 데이터는 각 측정자의 것이며, 앱은 측정자 이름과 원본 그래프 링크를 함께 보여 줍니다.
- **곡 검색 · 추천 차트** — Apple 의 공개 검색 · 차트. 검색은 4 초에 한 번까지 보내고, 결과와 그림은 앱을 끌 때까지 메모리에만 둡니다(이 Mac 에 남기지 않음).
- **소리** — macOS 오디오로 받아 이 Mac 안에서만 처리합니다. 녹음하거나 밖으로 보내지 않습니다.
- **보관** — 앨범 표지(Spotify 표지 포함)는 빠른 표시를 위해 이 Mac 의 캐시 폴더에, 가사는 앱 데이터 폴더에 임시로 둡니다. 둘 다 마지막으로 쓴 뒤 30 일이면 지웁니다.

자세한 목록은 [개인정보](../../PRIVACY.md).

**창의 차례** — 사이드바는 음악 · 보관함 · 청취 기록 · DSP · 입출력 · 진단 순서이고, 단축키 ⌘1… 이 이 순서를 따릅니다. 맨 아래 톱니 모양 **설정…** 줄은 설정 창을, **GitHub** 줄은 공개 저장소 페이지를 엽니다. 사이드바 머리에는 Fidenne 이름만 보이고, 버전과 빌드 번호는 앱 메뉴 › Fidenne 에 관하여와 설정 › 일반에 있습니다. 창은 마지막 크기 · 자리와 마지막으로 본 페이지로 다시 열립니다.

## 1. 처음 켤 때 — 처음 설정 다섯 단계

처음 실행하면 "Fidenne 처음 설정" 창이 뜹니다. 단계마다 **뒤로 / 다음** 으로 오갑니다.

1. **소리가 나갈 DAC** — 출력 장치를 고릅니다. "나중에 고르기" 도 됩니다. 장치가 안 보이면 DAC 를 꽂고 새로고침합니다.
2. **소리를 가져오는 방법**
   - **Fidenne Inlet**(권장, 처음부터 골라져 있음) — 재생 앱의 원본 레이트를 그대로 받습니다. 설치되어 있지 않으면 **설치…** 를 누릅니다. macOS 가 관리자 암호를 한 번 묻고, 오디오 서비스를 다시 시작해 잠깐 모든 소리가 끊깁니다. 설치는 나중에 입출력 페이지에서도 됩니다.
   - **시스템 탭** — 설치 없이 바로 됩니다. 48 kHz 로 받습니다.
   - 다른 루프백 앱을 이미 쓰고 있으면 나중에 입출력 페이지의 **+ 다른 입력 장치** 에서 고릅니다.
3. **macOS가 물어볼 것들** — 권한은 지금 묻지 않고, 그 기능을 처음 쓸 때 macOS 가 묻습니다(시스템 오디오 · 마이크 · 자동화 · 미디어 보관함). 화면에 각 권한을 언제 묻고 거절하면 무엇이 안 되는지 적혀 있습니다.
4. **Fidenne이 하는 것 · 하지 않는 것** — Fidenne 이 무엇으로 무엇을 하고 무엇을 하지 않는지 읽습니다([§0](#fidenne이-하는-것--하지-않는-것)과 같은 글).
5. **라이선스와 인터넷 연결** — 약관 전문 아래에 확인 칸 넷이 있습니다: **전체 동의** · **[필수] 이용 약관에 동의합니다** · **[선택] 인터넷 연결 기능 사용** · **[선택] 문제 제보용 진단 기록(이 Mac에만 저장)**. 필수 칸을 눌러야 **시작** 이 눌립니다. 선택 칸을 켜지 않아도 재생은 되고, 인터넷을 쓰는 기능만 꺼집니다. **동의하지 않고 종료** 는 앱을 끕니다. 선택은 나중에 설정 › 개인정보에서 바꿉니다.

**잘 됐는지** — 같은 창에 사이드바와 페이지가 뜨고, 다음 실행부터는 처음 설정이 다시 뜨지 않습니다.

**처음 재생할 때 — 음량 안내.** 앱을 켤 때마다 처음 재생을 누르면 소리를 내기 **전에** "음량을 낮추고 시작하세요" 한 장이 뜹니다. DAC · 앰프 음량을 0 이나 아주 낮게 내리고 **낮췄어요, 시작**(Return), 그다음 들으면서 천천히 올립니다. **취소**(Esc)면 아무것도 시작하지 않습니다. 처음 쓰는 DAC 로 시작할 때도 "○○을 처음 씁니다" 로 한 번 뜹니다. 이 안내를 끄는 곳은 설정 › **소리 안전** 하나이고, 꺼도 처음 쓰는 DAC 에서는 한 번 묻습니다.

**출력 감시.** 음악에서 나올 수 없는 신호(한쪽 끝에 멈춘 소리 · 큰 직류 · 들리지 않는 초고역의 큰 신호)가 나오면 그 재생의 나머지를 음소거하고 창 머리에 "출력을 음소거했습니다 — …" 를 띄웁니다. 멈췄다 다시 재생하면 돌아옵니다. 평소 소리는 바꾸지 않습니다.

**인터넷.** 인터넷을 쓰는 기능은 설정 › 개인정보 › **네트워크 목적지** 에서 하나씩 켜고 끕니다. 전부 꺼도 소리 받기 · DSP · DSD 변환 · DAC 출력 · 파일 재생은 그대로 되고, 소리는 어떤 경우에도 밖으로 나가지 않습니다.

## 2. 늘 보이는 것 — 머리 · 하단 재생 막대 · 메뉴

### 2.1 페이지 머리

페이지 이름 옆 **Playback Chain** 단추를 누르면 소리가 지나는 차례(**음원 → 캡처 → 변환 → 대역 → DSP → 필터 → 출력 → 장치**)가 지금 값으로 한 줄씩 보입니다.

- 머리의 점과 낱말이 전체 상태입니다: **실행 중 · 처리됨**(Fidenne 이 처리) · **실행 중 · 처리 없음**(PCM Direct) · **멈춤** · **준비 중** · **오류**.
- **음원** 줄은 지금 소리를 내는 앱, **캡처** 줄은 받는 길과 레이트입니다(빠진 소리가 있으면 붉게). **변환** 줄은 원곡과 받는 레이트가 같은지 말합니다. 다르면 붉게 `44.1 kHz → 48 kHz · 재생 앱이나 macOS 가 바꿈`. Spotify 는 원곡 레이트를 알려 주지 않아 `없음으로 추정` 으로 적습니다.
- **대역** 줄은 들어온 소리가 어느 높이에서 끊겼는지 잽니다(예: `16.0 kHz 위로 소리가 거의 없음`). 왜 끊겼는지는 말하지 않습니다 — 손실 압축일 수도, 원본 마스터의 특성일 수도 있습니다.
- **DSP** 줄의 칩(**EQ · Ostrum · Crossfeed**)을 누르면 그 자리에서 켜고 끕니다. 줄 끝에 `›` 가 있는 줄(과 칩의 `›`)은 누르면 그 설정으로 갑니다.
- 출력 장치가 없거나 끊기면 그 줄이 붉어지고 **다시 찾기** · **다시 연결** 이 뜹니다.

문제가 생기면 창 머리에 빨간 안내 띠가 뜹니다(예: `DAC 연결이 끊겨 재생을 멈췄습니다. 다시 연결한 뒤 재생을 누르세요.`). DAC 가 돌아오면 스스로 닫히고, ×로 닫을 수도 있습니다.

### 2.2 하단 재생 막대

막대는 모든 페이지에 떠 있습니다. 차례: 서비스 표지(누르면 그 앱이, YouTube Music 은 그 브라우저가 앞으로 옵니다) · **출력 방식 메뉴** · 재생 조작(하트 — Fidenne 보관함의 **좋아요한 곡**에 담기, 서비스 앱의 좋아요와는 따로 · 셔플 · 이전 · 재생/일시정지 · 다음 · 반복, 재생 위치) · ⋯ · **엔진 스위치**.

- **출력 방식 메뉴** — PCM Direct · 사운드 프리셋(추천 목록) · 저장한 프리셋 · "사운드 설정…". 저장한 프리셋을 고르면 그 출력 방식으로 바뀝니다.
- **⋯** — 곡 메뉴([§2.7](#27-곡-메뉴---와-우클릭))와 "출력 설정…"(입출력 페이지의 필터 카드를 엽니다).
- **엔진 스위치** — Fidenne 처리(엔진)를 켜고 끕니다. 스위치 색이 상태입니다(초록 실행 중 · 주황 준비 중 · 빨강 오류). 엔진이 꺼진 채 오류가 있으면 옆에 빨간 ! 가 뜨고, 누르면 입출력 · 진단 페이지가 열립니다.
  - **엔진 스위치는 곡을 틀지 않고, 재생 단추는 엔진을 끄지 않습니다.** 일시정지는 재생 앱만 멈추고, 엔진이 꺼져 있을 때 **재생** 은 엔진을 켜고 곡을 틉니다.
  - 켤 때 무엇을 틀지는 입출력 페이지의 **엔진 시작 후** 가 정합니다([§7.3](#73-스트리밍-앱-자동-재생--입력과-출력-장치)).
- 셔플 · 반복은 Fidenne 에서 재생한 목록에서만 씁니다. 다른 앱의 대기열은 그 앱에서 다룹니다.
- 브라우저나 다른 앱에서 새로 소리가 나면 막대가 **`시스템 소리 — 출처를 모름`** 이라고 쓰고, 그동안은 청취 기록 · 가사를 세지 않습니다.
- 다른 기기(휴대폰 등)에서 Spotify 를 틀면 막대는 **`Spotify — 다른 기기에서 재생 중`** 만 씁니다. 조작은 그 기기에서 합니다. 막대 뒤로 지나가는 내용이 글자를 가리면 설정 › 일반 › **재생 캡슐** 에서 재질을 바꿉니다.

**큰 재생 화면** — 막대의 앨범 표지를 누르면 열립니다. 세 칸입니다: 표지와 재생 조작 · **다음 재생** 과 **가사** · **Playback Chain**(손잡이 `›` 나 **⌥⌘P** 로 접고 폄). **⌘F** 는 이 화면 위에서 검색하고, 서비스 이름(`Apple Music ↗` 등)은 지금 곡을 그 서비스에서 엽니다. 닫기는 ×, 표지 다시 누르기, **Esc**.

**다음 재생과 Apple Music** — Apple Music 은 다음 곡 목록을 다른 앱에 알려 주지 않습니다.

- Fidenne 에서 Apple Music 목록을 틀면 Music 보관함의 **‘Fidenne 재생 대기열’** 재생목록에 다음 곡들을 넣고 거기서 틉니다. 곡 사이에 다른 곡이 끼지 않게 하려는 것입니다. 처음 쓰기 전에 한 번 묻고(**계속** · **끄고 계속**), iCloud 보관함을 켜 두었으면 다른 기기의 Music 에도 이 재생목록이 보입니다. 끄는 곳은 설정 › 개인정보 › Apple Music 입니다.
- Music 앱에서 직접 튼 곡은 Fidenne 이 그 곡이 어느 재생목록 · 앨범에서 왔는지 읽어 다음 곡을 보여 줍니다. 알 수 없으면 **이 앨범 이어 듣기** · **Fidenne 목록으로 돌아가기** · **Apple Music 자동 재생에 맡기기** 가 뜹니다.
- Music 이 스스로 다른 곡을 틀면 **`Apple Music 자동 재생이 고른 곡`** 이 뜹니다. Music 의 자동 재생(∞)을 끄면 Fidenne 목록대로 이어집니다.

**Apple Music 을 Fidenne 에서 재생 조작한다면, Music 앱에서 꺼 둘 것**

- **자동 재생(∞)** — Music 의 다음 재생 목록 위 ∞ 단추. 켜져 있으면 Music 이 다른 곡을 끼워 넣어 순서가 바뀝니다.
- **셔플 · 반복** — Music 쪽은 끄고, 필요하면 Fidenne 막대의 셔플 · 반복을 씁니다.
- **곡 전환(AutoMix · 크로스페이드)** — Music › 설정 › 재생. 곡과 곡이 겹치면 곡이 바뀌는 때가 흐려져 곡 넘김 · 레이트 맞추기가 어긋날 수 있습니다.
- 소리를 먼저 바꾸는 것(**사운드 체크** · **이퀄라이저** · **사운드 향상기**)도 끄는 것을 권합니다. Fidenne 이 다듬기 전에 소리가 바뀝니다.

**YouTube Music 목록을 Fidenne 에서 틀 때** — YouTube Music 다음 트랙 칸 맨 위 **자동재생** 스위치를 꺼 두기를 권합니다. 켜 두어도 Fidenne 이 자동재생이 연 곡을 멈추고 목록의 다음 곡을 틀지만, 꺼 두면 곡이 가장 깔끔하게 바뀝니다.

### 2.3 가사

곡을 틀면 가사 칸에 가사가 뜹니다. 인터넷 가사(lrclib.net)는 처음 한 번 동의해야 합니다 — "동의하고 찾기" / "보내지 않음". 보내는 것은 곡 제목 · 아티스트 · 앨범 · 길이뿐입니다.

| 조작 | 하는 일 |
|---|---|
| **가사 파일 연결** | LRC · TXT 파일을 이 곡에 연결합니다(해제 가능). |
| **가사 타이밍**(시계 단추) | 시계 단추를 누르면 열립니다. 가사가 빠르면 +, 늦으면 −. 이 곡에만 적용되고 기억합니다. |
| **글자 연결** | 시간이 없는 가사 파일의 글자를 지금 가사의 시간에 맞춥니다. |
| **한국어 번역** | 원문 줄 밑에 한국어 줄을 붙입니다. 한국어 가사 판이 없으면 macOS 번역으로 채웁니다. |
| **가사 판** | 판이 둘 이상일 때 나타나고, 찾은 판(원문 · 로마자 · 영어 · 한국어 등)을 고릅니다. 다른 판은 출처 줄의 **다른 판**으로 찾습니다. |
| 새로고침(↻) | 한 번 더 찾습니다. |

- 글자 크기는 설정 › 화면 › **가사 글자 크기**(작게 · 보통 · 크게)입니다.
- 곡 표기가 앱마다 달라도(한국어 아티스트 이름 · "- Remastered" 등) 제목 · 길이 · 아티스트나 앨범이 맞으면 찾습니다. 제목과 길이만 같은 다른 사람의 곡은 보여 주지 않습니다.

### 2.4 메뉴 막대 아이콘 · 메뉴

- **메뉴 막대 아이콘**(파형) — 상태 · 시작 · 정지 · 재생/일시정지 · 창 열기 · 출력 장치 · **EQ 프리셋 ▸**(최근 다섯, 고르면 바로 들림) · 종료. 시작 · 정지는 엔진 스위치와 같습니다.
- **아이콘 숨기기** — **시스템 설정 › 메뉴 막대 › 메뉴 막대에서 허용** 에서 Fidenne 을 끕니다. 숨겨도 창 · Dock · 단축키는 그대로입니다.
- **앱 메뉴** — "Fidenne 에 관하여"(상표 안내 포함), **업데이트 확인…**. 업데이트 확인은 누를 때만 공개 저장소를 한 번 읽어 "최신입니다" 또는 새 버전을 알립니다(아직 공개된 릴리스가 없으면 그렇다고 알립니다). 새 버전이면 Homebrew 명령 복사 또는 릴리스 페이지 열기를 고릅니다. 앱이 스스로 받아 설치하지 않습니다.
- **도움말 메뉴** — **조작법 보기** · **문제 제보용 진단 만들기…**([§10](#10-지원-파일-보내기)). **진단 메뉴** — 진단 기록 시작/중지 · **지원용 진단 내보내기…** · **저장된 진단 삭제…**.
- 되돌릴 수 없는 삭제(저장된 진단 · 재생목록 · 단축키 "모두 기본값으로")는 한 번 묻습니다. 빨간 단추는 Return 으로 눌리지 않습니다.
- **단축키** — 목록은 설정 › **조작과 단축키** 에 있습니다. 키마다 바꾸기 · 지우기 · 기본값. macOS 단축키와 겹치면 알려 줍니다. Fidenne 창이 앞에 있을 때만 동작합니다(미디어 키는 예외).
  **⌘S** 는 화면에 있는 Equalizer 나 Ostrum 을 저장하고, **⌘F** 는 보관함 · 청취 기록에서는 그 페이지의 검색 칸으로, 다른 페이지에서는 음악 검색 칸으로 갑니다.
  EQ · Ostrum 켜고 끄는 키는 바로 들리지만 저장하지 않습니다.

### 2.5 설명 · 그래프 읽는 법 · 용어 풀이

- 구역 제목 아래 한 줄이 그 기능이 하는 일입니다. 줄 끝의 **ⓘ** 를 누르면 풍선이 떠서 언제 쓰나요? · 무엇을 넣나요? · 바꾸면 무엇이 달라지나요? · 대가 를 보입니다. **Esc** 나 바깥을 누르면 닫힙니다.
- 설명 안 **용어 풀이 (n)** 은 그 부분의 용어를, **용어집 전체 보기** 는 앱의 용어집 전부를 보입니다. 그래프마다 바로 아래에 가로 · 세로 축과 선 이름이 늘 보입니다. 그 줄 끝 **ⓘ** 에 선마다의 뜻, 읽는 법, 이 그래프로 알 수 없는 것이 있습니다.
- 앱의 숫자는 측정에서 옮긴 것이고, 어느 설정이 소리를 좋게 한다는 판정은 하지 않습니다.

### 2.6 노브 · 슬라이더 · EQ 점 다루기

Equalizer 와 Ostrum 을 처음 열면 조작 옆에 **EQ 다루기** · **노브 다루기** 팁이 한 번 뜹니다. 다시 보려면 **도움말 › 조작법 보기**, 또는 설정 › 조작과 단축키 › **팁 다시 보기**.

| 조작 | 하는 법 |
|---|---|
| 노브(Ostrum) | 원을 그리듯 돌리거나 위아래로 곧게 끕니다(위 = 커짐). **Shift** · **⌥** 는 미세 조정. **더블클릭** 이나 ⌥-클릭은 기본값. 숫자를 누르면 직접 입력 |
| EQ 슬라이더 | 누르거나 끌어 올리고 내립니다. **더블클릭** · ⌥-클릭은 0 dB |
| EQ 숫자 칸 | 눌러서 입력하고 **Return**. 옆 화살표는 한 칸씩. ⌥-클릭은 기본값 |
| 그래프의 점(EQ) | 끌면 주파수와 게인이 함께 바뀝니다. **Shift** · **⌥** 는 열 배 천천히. 점을 누르면 고른 점이 되고, 옆의 작은 고리를 옆으로 끌면 Q. 빈 곳을 두 번 누르면 밴드가 생깁니다 |
| 재생 위치 · 다른 슬라이더 | 누르거나 끕니다 |

- **두 손가락 스크롤** 은 늘 페이지를 움직입니다. 값은 포인터를 조작 위에 두고 **⌘ 를 누른 채** 쓸 때만 바뀝니다(위로 쓸면 오름). ⌘ 와 함께 ⌥ · Shift 를 누르면 천천히 바뀝니다. 바꾸는 방식은 설정 › 조작과 단축키 › **두 손가락 스크롤로 값 바꾸기**(⌘ 누른 채 · 조작 위에서 시작하면 · 끔)에서 고릅니다.
- **트랙패드 햅틱** — 설정 › 조작과 단축키에서 **끔 · 양끝 알림 · 일반**. Force Touch 트랙패드로 끌 때 한 칸마다 가볍게 울립니다.
- **⌘Z / ⇧⌘Z** — DSP 페이지에서 바꾼 것을 한 칸씩 되돌리고 다시 합니다(한 번 끈 것 전체가 한 칸). 되돌린 값도 바로 들립니다.

### 2.7 곡 메뉴 — ⋯ 와 우클릭

곡이 한 줄로 보이는 곳(음악 · 다음 재생 · 보관함 · 청취 기록)에서 줄 끝 **⋯** 나 **우클릭** 은 같은 메뉴를 엽니다. 그 줄에서 할 수 없는 항목은 보이지 않습니다.

1. **재생** · **다음에 재생** · **대기열 끝에 추가**
2. **재생목록에 추가 ▸** · **가사 보기** · **곡 정보** · **Apple Music에서 열기** · **재생 앱에서 보기** · **Finder에서 보기** · **링크 복사**(열 곳이 둘 이상이면 **다른 앱에서 열기 ▸** 로 묶임)
3. **재생목록에서 빼기…**(한 번 묻고, 파일은 그대로) · **대기열에서 빼기**

Spotify 곡에는 **Spotify에서 열기** · **링크 복사** 가 있습니다. 여러 곡을 한꺼번에 고르는 메뉴는 아직 없습니다.

## 3. 음악 페이지

Apple Music · Spotify · YouTube Music 을 한 곳에서 검색하고 여는 곳입니다.

- **서비스 고르기** — 검색 칸 앞의 서비스 단추에서 **Apple Music** · **Spotify** · **YouTube Music** 을 고릅니다. YouTube Music 은 [§8.1](#81-youtube-music-쓰기-chrome-확장)의 확장이 있어야 합니다.
- **검색** — 결과는 한 화면에 차례로 보입니다: 내 Apple Music(보관함 · 재생목록) → Apple Music 카탈로그(보관함에 없는 곡) → 이 Mac 의 파일. 맨 아래 **YouTube Music 에서 ‘검색어’ 찾기 ↗** 는 YouTube Music 탭에서 같은 검색을 엽니다.
  - **Spotify 결과는 따로** 보입니다 — 결과 머리의 **Spotify** 탭을 누르고, **Apple Music · 로컬** 탭으로 돌아옵니다. Spotify 가 자기 콘텐츠를 다른 서비스 결과 옆에 두지 말라고 하기 때문입니다.
  - **보관함에 추가** — 카탈로그 곡 · 앨범을 Apple Music 보관함에 넣습니다. 처음 한 번 확인 창이 뜹니다(보관함이 바뀌고, iCloud 보관함이면 다른 기기에도 보임). 나타나기까지 시간이 걸려 "보관함에 나타나는 중" 이 보이다가 **재생** 으로 바뀝니다.
- **곡 누르기** — **다음에 재생** / **지금 재생**. 목록 위 **전체 재생** · **셔플** 은 목록을 한 바퀴 중복 없이 돕니다. Apple Music 의 긴 목록은 처음에 **재생 준비 중…** 이 잠깐 보일 수 있고, 섞어 들으려면 재생 전에 **셔플** 을 켭니다.
- **첫 화면** — **이어 듣기**, **오늘 들은 것**(지난날이면 **최근 들은 것**), **내 재생목록**, **오랜만에**. 이어 듣기 카드의 ▶ 는 그 카드의 서비스와 곡을 틀고, 저장된 위치가 있으면 그 자리에서 잇습니다. **목록 열기** 는 그 곡을 들은 목록을 엽니다.

**Spotify 연결(선택)** — 키 없이도 Spotify 앱에서 곡을 고르면 Fidenne 이 소리를 다듬고 지금 곡을 보여 줍니다. 검색 · 재생목록 · 재생 조종은 **내 Spotify 개발자 앱의 키** 가 있을 때만 켜지고, 그 약관은 사용자가 직접 동의한 것입니다.

1. Spotify 설정 칸의 **개발자 대시보드 열기** 를 눌러 앱을 하나 만듭니다.
2. 그 앱의 Redirect URI 에 칸에 보이는 주소를 넣습니다(옆 **복사** 단추).
3. 대시보드의 **Client ID** 를 칸에 붙여 넣습니다. Client Secret 은 넣지 않습니다.
4. **키 확인** 을 누르고, 맞으면 **Spotify 연결** 을 누릅니다. 브라우저의 Spotify 로그인 창이 뜹니다.

연결 뒤에는 "재생 권한 갱신" · "연결 해제" 가 보입니다. **Spotify 대기열 따르기 · Jam용** 을 켜면 Fidenne 이 Spotify 공동 대기열을 덮어쓰지 않습니다.

**잘 됐는지** — 곡을 누르면 하단 막대에 곡 이름과 서비스 표지가 뜨고 재생 위치가 움직입니다.

## 4. 보관함 페이지

이 Mac 의 음악 파일을 듣는 곳입니다. 읽는 형식: WAV · AIFF · FLAC · ALAC · AAC · MP3 · Opus(macOS 가 읽을 수 있을 때). `.ogg` · `.oga` 는 아직 재생하지 않습니다.

1. 처음에는 **폴더 추가…** 를 누르고 음악 폴더를 고릅니다.
2. 색인이 끝나면 **노래 · 앨범 · 아티스트 · 재생목록** 에서 곡을 찾습니다.
3. 줄을 누르면 그 곡부터 재생합니다.

**잘 됐는지** — 곡 줄에 표지 · 제목 · 형식(예: FLAC · 96 kHz · 24비트) · 길이가 보이고, 누르면 하단 막대에 그 곡이 뜹니다.

- **음악 폴더** 메뉴 — 폴더 추가… · **다시 색인** · 목록에서 폴더 빼기 ▸(목록에서만 빼고 디스크의 파일은 그대로).
- **노래** — 검색 칸(⌘F)이 지금 목록을 거릅니다. 재생할 수 없는 파일은 형식 자리에 까닭(`손상된 파일` 등)이 보입니다. **앨범 · 아티스트** 는 파일 태그로 묶습니다.
- **재생목록** — 이름을 넣고 만듭니다. 안에서 전체 재생 · 셔플 · 삭제…(재생목록만 지우고 파일은 그대로). "파일을 찾을 수 없음" 은 폴더가 빠졌거나 파일이 옮겨진 것입니다.
- **여러 곡 고르기 · 순서 바꾸기**(재생목록 · 다음 재생) — ⌘-클릭 · Shift-클릭으로 고르고, 줄을 끌어 다른 줄 위에 놓으면 옮깁니다. **Return** 은 고른 첫 곡을 재생합니다.
- **다음 재생** — 하단 막대의 목록 단추가 지금 곡과 이어지는 곡을 보입니다. 같은 레이트의 곡은 끊김 없이 잇고, 레이트가 바뀌는 곳에서는 잠깐 끊깁니다.
- 파일은 늘 Fidenne 으로 재생합니다. 출력 방식이 PCM Direct 여도 파일은 Fidenne 의 PCM 출력으로 나갑니다.

**YouTube Music 재생목록** 은 이 페이지가 아니라 `음악 › YouTube Music › 내 재생목록` 에 모입니다. 가져오는 길은 둘입니다 — 브라우저에서 목록 화면을 열기([§8.1](#81-youtube-music-쓰기-chrome-확장)), Google 테이크아웃 파일([§4.1](#41-youtube-music-재생목록-가져오기)). Fidenne 은 YouTube Music 사이트를 스스로 돌아다니며 읽지 않습니다. 가져온 곡 줄에서 할 수 있는 것:

- **종류** — 곡마다 노래 · `뮤직비디오` · `음악 영상` · `음악 아님` · `종류 모름` 가운데 하나로 봅니다. 기본으로 **`음악 아님` 만 빠집니다**.
- **넣기 · 빼기** — 줄 끝 단추로 바꿉니다. **걸러진 것 보기** 를 켜면 빠진 곡도 보입니다. 고른 것은 다시 가져와도 그대로 남습니다.
- **곡 메뉴** — **YouTube Music에서 열기** · **링크 복사** · 재생목록에 넣기/빼기. 이 곡들은 YouTube Music 탭에서 재생됩니다.

### 4.1 YouTube Music 재생목록 가져오기

YouTube Music 의 재생목록과 보관함 노래를 **Google 테이크아웃** 파일로 가져옵니다. Fidenne 은 인터넷에 묻지 않고 받은 파일만 읽습니다.

1. 브라우저에서 `takeout.google.com` 을 열고 로그인합니다.
2. **모두 선택 해제** → **YouTube 및 YouTube Music** 만 체크합니다.
3. 그 줄의 **모든 YouTube 데이터 포함됨** 을 눌러 **재생목록** 과 **음악** 만 남깁니다.
4. **다음 단계** → 한 번 내보내기 · `.zip` → **내보내기 만들기**. 준비되면 메일의 링크에서 받습니다.
5. 받은 zip 을 Finder 에서 두 번 눌러 풉니다.
6. Fidenne `음악 › YouTube Music › 내 재생목록` 맨 아래 **YouTube Music 보관함** 을 펼치고 **YouTube Music 재생목록 가져오기…** → 푼 `Takeout` 폴더를 통째로 고릅니다.

**잘 됐는지** — `재생목록 N개 · M곡 · …` 한 줄이 뜨고 목록이 내 재생목록에 보입니다.

- 폴더째 고르면 곡 이름이 붙습니다. 재생목록 파일만 고르면 `이름 모르는 항목` 으로 보입니다.
- 같은 목록을 다시 가져오면 바꿔 씁니다. **삭제…** 는 Fidenne 에 가져온 목록만 지웁니다.

## 5. 청취 기록 페이지

이 Mac 에서 들은 기록을 보는 곳입니다. 자동으로 올리지 않고, 직접 내보낼 수만 있습니다.

- **기간** — 1일 · 1주 · 1개월 · 6개월 · 1년. **출처** — 전체 · Apple Music · Spotify · 로컬. **그래프** — 재생 추이 · 어디서 들었나요 · 자주 들은 아티스트 · 장르와 템포.
- **1회의 기준** — Fidenne 이 열린 동안 실제로 30 초, 또는 곡 길이의 절반(짧은 쪽) 재생된 것. 앱이 닫힌 동안의 기록은 없습니다.
- **곡별 기록** — 곡 · 아티스트 · 앨범으로 거릅니다(⌘F). Apple Music 과 Spotify 에서 들은 같은 곡은 한 줄로 합쳐 서비스별 횟수를 보이고, 무엇을 근거로 합쳤는지 적습니다. 비슷하기만 한 곡을 골라 잇는 "연결 후보" 화면은 이번 베타에서 숨겨 두었습니다.
- **로컬 파일** — 태그(제목 · 아티스트 · 앨범)만 남기고 파일 경로 · 폴더 이름 · 파일 이름은 남기지 않습니다.
- **내보내기** — JSON · CSV(고른 출처만). **지우기** — 접힘 **기록 설정과 집계 기준** 의 **청취 기록 지우기** → **모두 지우기**. 되돌릴 수 없습니다. **이 Mac에 청취 기록 저장** 을 끄면 더 기록하지 않습니다.
- 장르 · BPM 은 재생 앱이 준 값만 씁니다. 없는 값은 짐작하지 않습니다.

## 6. DSP 페이지

소리를 다듬는 곳입니다. 머리에 지금 입력 레이트(멈춰 있으면 마지막 재생 기준)가 보입니다. 위에서부터 **Response 그래프**, 그 아래 탭 **Equalizer · Ostrum · Crossfeed**, 그 아래 고른 탭의 세부가 있습니다.

- **바꾸면 바로 들리고, 저장(⌘S)해야 다음 실행에도 남습니다.** EQ · Ostrum 모두 같습니다. 다른 페이지에 다녀와도 편집은 그대로입니다.
- 단추 · 칸 이름은 영어, 안내와 경고 문장은 한국어입니다. DSP 는 Fidenne 이 처리하는 출력(DSD · PCM 352.8 kHz)에서만 들립니다. PCM Direct 에서는 거치지 않습니다.

### 6.1 Response 그래프

선은 **타깃**(주황 점선, 목표) · **내 헤드폰**(회색, 측정) · **보정 뒤**(가장 진한 선 = 내 헤드폰 + EQ + Ostrum) · **EQ 곡선**(파란 선, 밴드 점이 이 선 위)이고, **더 보기** 메뉴에 EQ + Ostrum · Ostrum 이 있습니다. EQ 를 맞춘다는 것은 **보정 뒤** 를 **타깃** 에 붙이는 것입니다.

- 그래프 아래 범례에서 선을 켜고 끕니다. 카드 머리의 **View** 에서 **Original** / **Target flat**(타깃을 0 dB 수평선으로) 을 고릅니다.
- 곡선은 EQ 의 Preamp 와 Ostrum 의 Headroom · Output 을 빼고 그립니다(모양을 비교하려고). 소리에는 그대로 걸리고, 그래프 아래 접힘 **그래프 읽는 법 · 주석** 첫 줄이 그 값을 말합니다.
- EQ + Ostrum 선은 EQ(엔진 계산, 왼쪽 채널) + Ostrum 가운데 소리의 크기입니다. 크로스피드는 가운데를 바꾸지 않아 넣지 않습니다.
- 재생하지 않아도 그립니다(멈춰 있으면 마지막 재생 레이트 기준). 카드 머리 **Reference**(기준점 1 kHz 등) · **Range**(자동 · ±12 · ±18 · ±24 dB)는 그림만 바꾸고 소리는 바꾸지 않습니다.
- **스펙트럼** — 그래프 뒤에 지금 소리의 대역별 크기가 옅게 깔립니다. 범례 아래 **Spectrum** 줄에서 **DSP 뒤** · **앞뒤 겹쳐** · **DSP 앞**, 해상도 · 평활 · 피크 홀드를 고릅니다. 재생 중에만 움직입니다.
- **과한 설정 탐지기**(그래프 아래 한 줄) — EQ · Ostrum · 크로스피드를 더한 곡선이 지나치게 올리거나(+6.2 dB 넘음), 0 dB 를 넘거나, 너무 가파르면 그래프에 빨간 구간을 그립니다. 막지는 않습니다.
  - 밴드를 고치는 보정은 **보정 제안…** 에서 **보정 적용** 을 누를 때만 일어납니다. 창은 **업계 관례**(Preamp 만 내림)로 열리고, **개선**(넘친 부스트 · 가파른 옆면을 만드는 밴드만 가장 작게 고침)은 직접 고를 때만 씁니다(업계 관례로 없앨 수 없는 것이 있을 때는 개선으로 열립니다). 바뀌는 밴드 표를 보고 **보정 적용** 을 눌러야 바뀝니다. 개선은 곡선을 깎으므로 원하는 소리와 달라질 수 있습니다. **보정 되돌리기** 로 한 번 돌아갑니다.
  - 자동으로 하는 것은 **클리핑 막기 — Preamp 자동 낮춤**(기본 꺼짐) 하나입니다. 켜면 합이 0 dB 를 넘을 때 Preamp 만 필요한 만큼 낮추고, 밴드는 바꾸지 않습니다.

### 6.2 Equalizer

머리: **Equalizer** ⓘ · **EQ On** · **프리셋 ▾** · **저장본으로 되돌리기** · **초기화** · **저장**(⌘S).

1. 그래프의 점을 끌거나 밴드 열의 슬라이더 · 숫자 칸으로 밴드를 바꿉니다. 바로 들립니다.
2. 마음에 들면 **저장**(⌘S)을 누릅니다.

**잘 됐는지** — 머리 아래 줄이 `✓ 저장됨 · 다음 실행에도 이 EQ 로 시작합니다` 입니다. 저장 전이면 주황 `● 저장 안 됨 — 저장(⌘S)해야 다음 실행에도 남습니다`.

- **프리셋 ▾** — 이름 붙인 EQ 를 남기고 다시 고릅니다.
  - **최근** 다섯과 **모든 프리셋**. 고르면 바로 들리고 다음 실행에도 이 EQ 로 시작합니다. 그 프리셋에 맞춘 헤드폰 · 타깃과 강도가 Auto EQ 줄에 함께 들어오고, **Bands** 는 그 EQ 의 밴드 수가 됩니다(강도를 남기지 않은 프리셋은 100 %).
  - 프리셋을 고른 상태에서 저장(⌘S)하면 **그 프리셋에도** EQ 와 헤드폰 · 타깃을 덮어씁니다. 헤드폰 · 타깃만 바꿔도 저장이 켜집니다.
  - **다른 이름으로 저장…** 은 지금 EQ 를 저장하고 새 이름으로 남깁니다(지금 프리셋은 그대로, 100 개까지). **프리셋 관리…** 는 이름 바꾸기 · 지우기, **이전 저장본으로 되돌리기** 는 저장할 때마다 그 앞에 있던 EQ(최근 20 개)입니다.
- **저장본으로 되돌리기** 는 마지막으로 저장한 EQ 로, **초기화** 는 모든 밴드와 Preamp 를 0 dB(평평)로 돌립니다. 둘 다 바로 들립니다.
- 저장하지 않은 EQ 가 들리는 채로 앱을 끄면 한 번 묻습니다 — 저장하고 종료 · 저장하지 않고 종료 · 취소.
- **밴드 열** — 맨 앞 **Preamp**, 그다음 밴드마다 켬 칸과 번호 · 게인 슬라이더 · 종류(PK · LS · HS · LP · HP · BP · NO · AP · G) · 채널(L+R · L · R) · Gain · Freq · Q 칸. 열 위에 **Open EQ Preset…** · **Graphic 31** · **Add Band** · **Delete Band** · **Reset Band**. 밴드는 32 개까지이고, **Open EQ Preset…** 은 AutoEq · Equalizer APO 형식 파일을 엽니다.
- **Clipping & Headroom**(밴드 열 아래) — 이 재생에서 클리핑이 났는지, 리미터, **Apply Headroom N dB** 제안 단추가 있습니다.
- **EQ Backend** — **파라메트릭**(기본, 지연 없음) / **최소위상 FIR** / **선형위상 FIR**(지연 약 0.2 초, 다음 재생 시작부터). 선형위상이면 **Linear Phase Length** 로 길이를 고릅니다. 어느 쪽이 더 좋게 들리는지는 확인한 적이 없습니다.
- 엔진이 그 레이트에서 EQ 를 만들지 못하면 주황 줄로 알리고 EQ 없이 재생합니다(저장한 EQ 는 그대로). EQ 를 끈 직후 잠깐(0.1–0.3 초) 조금 작게 들렸다 커지는 것은 큰 소리를 막으려는 것입니다.

### 6.3 Ostrum

저음 · 존재감 · 폭 · 배음을 함께 다듬는 Fidenne 의 톤 셰이퍼입니다. 노브는 바꾸면 바로 들리고, 남기려면 머리의 **저장**(⌘S)을 누릅니다.

1. **Ostrum On** 을 켭니다.
2. **프리셋 ▾** 에서 추천 시작값 하나를 고르거나, **Mix** 가 0 일 때 뜨는 **자연스럽게 시작** 을 누릅니다.
3. 노브를 조금씩 움직이며 듣고, 마음에 들면 저장합니다.

**잘 됐는지** — 패널 맨 위 줄이 "적용됨 · 리비전 N" 이고 Composite Response 그래프가 바뀝니다.

**프리셋 ▾** — 추천 시작값 **자연스럽게**(가장 옅게, 처음에 권함) · **선명한 OST·보컬** · **저음 중심·전자음악** · **야간·피로 적게**(가장 약하게). 아직 들어 보고 확정한 값이 아닌 제안입니다. **지금 설정을 내 프리셋으로 저장…** 으로 내 프리셋을 남기고, 같은 메뉴에서 고르기 · 이름 바꾸기 · 지우기를 합니다.

| 노브 · 칸 | 하는 일 |
|---|---|
| **Mix** | 전체 양. 0 이면 Bass · Presence 가 들리지 않습니다. 가장 먼저 올립니다 |
| **Bass** | Sound · Compression · Tune. **Split Bass** 는 깊은 저음과 그 위 저역을 따로 다룹니다. **Topology** 는 Blend(기본) / Manual 〔실험〕 |
| **Presence** | 고역을 올리는 양(Intensity)과 방식(Off · Analog · Min Phase · Linear Phase). Linear Phase 는 다음 재생부터, 또는 **Restart Now** |
| **Width** | 좌우 차이의 크기 |
| **Harmonics** | 배음을 더합니다(Curve · Amount) |
| **Headroom · Output** | 전체 레벨. **권장 Headroom** 이 뜨면 **권장값으로 Headroom 맞추기** 를 누릅니다. 옆의 **바뀔 때마다 자동으로**(기본 꺼짐)를 켜면 노브가 권장값을 따라갑니다 |

- **Tune** 은 Presence 의 기준 주파수입니다. Mix 를 올리려면 Tune 을 1.1–22 kHz 안에 둡니다. 그렇지 않으면 노브 옆에 주황 줄로 알려 줍니다(엔진이 설정을 받지 않을 때도 까닭과 바꿀 것을 한 문장으로 말합니다). Tune 노브는 왼쪽이 낮은 Hz 입니다.
- **Neutral Tune** 을 켜면 Bass · Presence 를 빼고 Width · Harmonics · Output 만 씁니다. 각 칸 옆 **ⓘ** 에 언제 쓰는지와 대가가 있습니다.
- Bass 압축이 누르는 동안 그래프에 옅은 보라 빗금과 `압축 중 −x dB` 가 보입니다.

### 6.4 Crossfeed

헤드폰에서 좌우가 너무 갈라져 들릴 때 반대쪽 소리를 조금 섞습니다.

1. **크로스피드 켜기** 를 켭니다.
2. **가볍게 · 보통 · 진하게** 가운데 하나를 고릅니다(섞는 양이 적은 순).
3. 더 다듬으려면 노브 둘을 돌립니다 — **양(Feed)** 은 얼마나 섞나(−15 … −1 dB, −1 쪽이 많이), **주파수(Cutoff)** 는 어느 높이까지 섞나(300–2 000 Hz).

**잘 됐는지** — 고른 단추가 눌린 채로 보이고, 작은 M/S 그래프(재생 중)에서 Side 선이 내려갑니다.

- **내 설정** 메뉴에서 지금 값을 이름 붙여 저장 · 불러오기 · 지우기를 합니다(스무 개까지). 노브 아래 **ⓘ** 에 "머리 안에 갇힌 듯할 때 · 좌우가 너무 좁을 때 어느 쪽으로 돌릴지" 가 있습니다.
- Ostrum 의 Width 와 같이 켜면 "폭을 두 곳에서 조절 중" 이 뜹니다. 둘이 같은 대역에서 서로를 일부 지웁니다.

### 6.5 Headphone ▾ · Target ▾ (Equalizer 의 Auto EQ 줄) · 고급 — 파일 · 고역 · 생성형 AI (접힘)
<a id="65-①-headphone--②-target-equalizer-의-auto-eq-탭--measurement--target-files-접힘"></a>

헤드폰 측정에 맞춰 EQ 를 자동으로 만드는 곳입니다. Equalizer 안 밴드 열 앞의 **Auto EQ 줄** 을 누르면 펼쳐집니다.

1. **Headphone ▾** 에서 내 헤드폰을 고릅니다. 목록에 없으면 **헤드폰 검색…**.
2. **Target ▾** 에서 목표를 고릅니다 — 측정자의 타깃 곡선(DF · DF t · Harman …) 또는 다른 헤드폰.
3. 줄 끝 **Auto fit** 을 누릅니다([§6.6](#66-bands--strength--auto-fit-equalizer-의-auto-eq-줄--자동-맞춤이-한-일-접힘)).

**잘 됐는지** — 접힌 줄이 `Auto EQ   내 헤드폰 → 목표 · 밴드 10` 처럼 보입니다.

- 헤드폰 · 목표를 골라도 EQ 는 바뀌지 않습니다. 바뀌는 것은 Auto fit 을 누를 때입니다.
- **헤드폰 검색…** — squig.link 의 측정 목록을 받아 이 Mac 에서 찾습니다(검색어는 나가지 않음). 처음에는 **목록 받기** 를 누르고, 한 번 받은 목록은 30 일 동안 다시 받지 않습니다. 줄을 누르면 확인 칸이 열리고, **적용**(Return)을 눌러야 바뀝니다. **☆** 는 즐겨찾기입니다(내 헤드폰 · 목표 헤드폰 따로).
- 내 헤드폰과 목표의 측정기가 다르면 상태 줄이 그렇게 말하고 **측정기 차이 보정**(기본 켬)으로 맞춥니다. 측정기 관계를 알 수 없는 목표는 목록에서 숨깁니다. 헤드폰에 이어폰 목표처럼 종류가 다르면 노란 줄로 알리고 막지는 않습니다.
- **고급 — 파일 · 고역 · 생성형 AI**(접힘):
  - **파일로 열기** — **Open measurement…** · **Open target…** 으로 내가 가진 측정 · 타깃 파일(2열 Hz · dB 텍스트)을 엽니다.
  - **Treble (Auto fit)** — 고역을 어디까지 보정할지(전부 · 경계 위 보정 안 함 · 6–8 kHz 위 절반 등). Auto fit 을 누를 때 적용됩니다.
  - **생성형 AI로 다듬기** — 지금 설정을 **AI에 줄 글 복사** 하거나 파일로 내보내, 쓰는 생성형 AI(ChatGPT · Claude 등)에서 다듬은 뒤 답을 붙여 넣고 **붙여 넣은 답 가져오기**. 앱은 아무것도 보내지 않습니다.

### 6.6 Bands · Strength · Auto fit (Equalizer 의 Auto EQ 줄) · 자동 맞춤이 한 일 (접힘)
<a id="66-③-auto-fit-equalizer-의-auto-eq-탭--auto-fit--refinement-접힘"></a>

- **Bands** — 밴드 수. **8 · 10 · 12 · 16** 단추나 슬라이더(1–32). 10 이 기본입니다. 맞춘 뒤 4–8 kHz 에 좁은 굴곡이 남으면 12–16 으로 올려 다시 맞춰 봅니다.
- **Strength** — 보정 강도(0–100 %, 기본 100 %). 낮추면 모든 밴드의 게인이 같은 비율로 줄어듭니다.
- **Auto fit** — 누르면 맞춘 밴드가 밴드 열에 들어가 **바로 들립니다**. 남기려면 저장(⌘S). 맞출 수 없으면 단추가 꺼지고 까닭이 주황으로 나옵니다.
- **자동 맞춤이 한 일**(접힘) — 밴드마다 한 문장(예: "3 kHz 부근 4.0 dB 줄임 — 중고역 …")과 오차 수치가 있습니다. 소리가 좋다는 판정은 아닙니다.
- Ostrum 이 켜져 있으면 Auto fit 은 EQ 만 맞추므로 **보정 뒤** 선이 타깃에서 벗어나 보일 수 있습니다.

### 6.7 A/B 단추의 패널 — A/B · ABX · Auto Bypass · Loop · 음량 맞춤(Level-matched Comparison)

A/B · ABX · Auto Bypass · Loop 비교는 **이번 베타에서 숨겨 두었습니다** — DSP 페이지에 A/B 단추가 보이지 않습니다. 고친 뒤 다시 켭니다([알려진 한계](KNOWN_LIMITATIONS.md)).

## 7. 입출력 · 진단 페이지

### 7.1 출력 독립 제어 · 출력 방식

페이지 맨 위 **출력 방식** 에서 셋 가운데 하나를 고릅니다. 고른 것 아래 한 줄이 무엇을 거치는지 말합니다.

- **PCM Direct** — Fidenne 은 소리를 처리하지 않습니다. 재생 앱 → macOS → DAC 로 바로 나갑니다. 곡마다 샘플레이트를 맞추지 않습니다(소리가 Fidenne 을 거치지 않아 곡(입력) 레이트에 맞춰 출력 레이트를 바꿀 수 없기 때문입니다) — DAC 와 곡의 레이트가 다르면 macOS 가 변환합니다. 시작할 때 한 번만 DAC 레이트를 정합니다(Spotify 는 44.1 kHz, DAC 가 DSD · 352.8 kHz 처럼 일반 PCM 이 아닌 레이트에 남아 있으면 곡 레이트, 모르면 44.1 kHz).
- **DSD (DoP)** · **PCM 352.8 kHz** — EQ · Ostrum · 크로스피드를 끄면 톤을 바꾸는 처리는 없습니다. 다만 그 형식에 필요한 변환(업샘플링 필터 · DSD 변조기 · 디더 · 헤드룸)은 걸리고, 고른 필터와 변조기에 따라 소리의 성격이 달라질 수 있습니다. PCM 352.8 kHz 는 그 아래에서 **비트 깊이**(24 · 16-bit)와 **디더** 를 고릅니다.
- PCM Direct 로 바꾸기 전에 DAC 음량을 확인합니다 — Fidenne 의 헤드룸이 걸리지 않아 더 크게 들릴 수 있습니다.

고른 출력 방식은 다음 실행에도 남습니다. 다만 DSD · PCM 352.8 kHz 는 그 DAC 에서 그 형식이 확인된 적이 있을 때만 되살리고, 아니면 **PCM Direct 로 시작** 하며 그렇다고 한 줄로 알립니다. 앱을 켜기만 해서는 소리가 시작되지 않습니다.

- **출력 DAC** — 고르기 · 새로고침 · 다시 연결. 352.8 kHz 를 받지 않는 장치(내장 스피커 · AirPods · 대부분의 동글)는 이름 끝에 `· PCM Direct 만` 이 붙습니다. 그 장치로는 DSP 와 보관함 재생을 쓸 수 없습니다. 같은 USB DAC 를 다른 포트에 꽂아도 알아봅니다. 확실하지 않으면 **같은 장치로 쓰기** / **다른 장치로 쓰기** 를 한 번 묻습니다.

### 7.2 DAC 형식 확인(전 "엔진 출력 형식")

내 DAC 가 어떤 형식(DSD128 · DSD256 · PCM 24 · 16-bit)을 받는지 보여 주는 표입니다. 형식마다 **확인됨**(✓) · **엔진이 거절함**(⚠ + 이유) · **확인 전** · **모름** 으로 보이고, DAC 마다 기억합니다.

- **모두 확인** — 재생을 멈춘 채 누르면 아직 확인하지 않은 형식을 차례로 설정해 보고 되돌립니다. 소리는 나지 않지만 DAC 가 딸깍거리거나 표시가 잠깐 바뀔 수 있습니다.
- DAC 가 고른 형식을 받지 않으면 다른 레이트로 낮추지 않고 시작하지 않습니다.
- **처음 DoP 를 보낼 때 한 번 묻습니다** — `<DAC 이름>로 DSD(DoP)를 처음 보냅니다`. 표의 확인됨은 DAC 가 DoP 를 푼다는 뜻이 아니고, 못 푸는 DAC 는 큰 잡음을 냅니다.
  음량을 낮추거나 헤드폰을 벗고, DAC 설명서에 DoP 지원이 있으면 **DoP를 받는 DAC · 시작**, 모르겠으면 **PCM 24-bit로 재생**. DAC 표시등에 DSD 가 뜨는지 보고, 잘못 골랐으면 표 아래 DoP 줄의 **다시 묻기**.
- 일부 DAC 는 DSD · PCM 정수 출력에서 **macOS 음량이 최대** 여야 합니다. 낮춰 두었으면 `DAC 음량이 최대가 아니어서…` 로 알립니다 — 소리 크기는 DAC 의 노브로 줄입니다.
- **DAC가 N초 안에 다시 연결되면 이어서 재생** — 같은 DAC 만 기다립니다. "기다리지 않기" 로 끕니다.
- 다른 앱이 DAC 를 쓰고 있어도 시작해 봅니다. 그 앱이 물러나지 않으면 `다른 앱(…)이 DAC에서 물러나지 않아…` 를 한 번 보이고 다시 시도하지 않습니다. 그동안 다른 앱의 소리는 Mac 스피커로 옮겨질 수 있습니다.
- `DAC 재생 통로가 macOS 안에서 멈췄습니다…` 가 뜨면 USB 케이블을 뽑았다 다시 꽂거나 Fidenne 을 다시 시작합니다([문제 확인 가이드](TROUBLESHOOTING.md)).

### 7.3 스트리밍 앱 자동 재생 · 입력과 출력 장치

**엔진 시작 후** — 엔진을 켤 때 무엇을 할지 고릅니다. **자동 감지** 는 곡을 새로 틀지 않고 재생 중인 앱을 따라갑니다(브라우저 소리는 이것으로 두고 브라우저에서 틉니다). **Apple Music** · **Spotify** 는 그 앱의 지금 항목을, **YouTube Music(브라우저)** 은 열린 탭에 ▶ 를 보냅니다. **자동재생 안 함** 은 엔진만 켭니다. Music 과 Spotify 가 동시에 재생되면 나중에 튼 쪽을 따라가고 다른 쪽을 일시정지합니다.

**입력** — 소리를 받는 길입니다. 고른 입력은 다음 실행에도 이어집니다.

- **Fidenne Inlet**(권장) — 재생 앱의 원본 레이트를 그대로 받습니다. 같은 칸에서 **설치… / 업데이트… / 제거…**. 설치 · 제거 때 macOS 가 관리자 암호를 묻고 잠깐 모든 앱의 소리가 끊깁니다 — 듣지 않을 때 합니다. 알림음은 Fidenne Inlet 으로 가지 않습니다. 재생 중에 이 장치의 레이트가 바뀌면 1–3 초 조용했다가 새 레이트로 이어집니다. "옛 이름으로 설치되어 있습니다" 가 보이면 다시 설치합니다(선택은 그대로).
- **시스템 탭**(목록 이름 **Process Tap**) — 설치 없이 이 Mac 의 모든 앱 소리를 48 kHz 로 받습니다. 받는 동안 그 소리는 Fidenne 으로만 나고, 엔진을 끄면 곧바로 원래대로 들립니다. 처음 쓸 때 macOS 가 오디오 녹음 허용을 묻습니다 — 거부하면 조용합니다(시스템 설정 › 개인정보 보호 및 보안 › 화면 및 시스템 오디오 녹음). 앱 하나의 소리만 받으려면 그 앱의 출력을 Fidenne Inlet 으로 보내고 입력을 Fidenne Inlet 으로 고릅니다.
- **+ 다른 입력 장치** — 이미 쓰는 다른 루프백 장치를 고릅니다(출력과 2 채널 입력이 함께 있는 장치만, **✕** 로 지움).

**Apple Music 원본 레이트** — Apple Music 곡의 원본 레이트에 맞춰 입력 레이트를 바꿉니다. 들은 곡의 레이트를 이 Mac 에 기억해, 다음에는 처음부터 맞는 레이트로 나옵니다. 처음 듣는 곡은 레이트를 알 때까지 첫 소리를 잠깐(보통 1 초 안, 길어야 2 초) 내지 않습니다. Spotify 는 원본 레이트를 알려 주지 않아 44.1 kHz 로 맞춥니다.

### 7.4 필터 · 모듈레이터 · 출력 게인 (카드) — DSD 경로의 소리 설정
<a id="74-필터--모듈레이터--출력-게인-접힘--dsd-경로의-소리-설정"></a>

DSD · PCM 352.8 kHz 로 내보낼 때의 소리 설정입니다. 카드에 지금 **필터** · **출력** · **게인** 이 한 줄씩 보이고, **자세히** 를 펼치면 ①–③ 이 있습니다.

**어디서부터 들어볼까요?** 카드의 **추천 조합 N개** 는 목적별 추천입니다. 카드마다 "들어 볼 것" 이 적혀 있고, 카드에 적힌 것만 바뀝니다. 재생 중에 고르면 잠시 멈췄다 이어집니다.

1. **필터** — 처리 방식(기본 SRC · 장탭 확장 · 초장탭) · 계열 · 길이. 〔실험〕 배지가 붙은 필터는 주의점을 말합니다. 장탭 · 초장탭은 소리를 늦추므로 영상과 어긋날 수 있다고 **지연 ○○ ms** 를 보입니다 — 영상을 볼 때는 기본 SRC 와 버퍼 **저지연** 이 가장 덜 어긋납니다. 접힘 **조건으로 고르기 · 비용 비교** 에서 최대 지연 · CPU 로 걸러 고를 수도 있습니다. 20 Hz–18 kHz 응답은 모든 필터가 사실상 같고, 다른 것은 20 kHz 위와 시간 응답입니다.
2. **DSD 변환** — 모듈레이터 **7차 · 기본** / 5차 · 보호형, 출력 레이트 DSD128 / DSD256. DSD256 은 그 DAC 에서 확인된 뒤에 기본이 됩니다.
   - **버퍼** — 저지연 · 표준 · **안정(기본)**. 음질은 같고, 조작이 들리기까지의 시간과 끊김에 대한 강함만 다릅니다. 멈춘 상태에서 바꾸고 다음 재생부터 적용됩니다.
   - **실험 · 디더 N 차** 〔실험〕 — 멈춘 상태에서 바꾸고 다음 재생부터(청취로는 확인하지 않음).
3. **PCM 헤드룸** — **자동 (권장)** 이 기본입니다. EQ · Ostrum 이 올린 만큼 전체를 내려 클리핑을 막습니다. 슬라이더 · 단추로 바꾸면 **수동** 이 되고, **자동으로 되돌리기** 로 돌아갑니다. 앱을 다시 켜면 자동입니다. DAC 볼륨과 다릅니다 — 들리는 음량은 DAC 에서 맞춥니다.

- **현재 사운드 프리셋 저장** — ① 필터 · ② DSD 변환(실험 디더 포함) · ③ 헤드룸을 한 프리셋으로 저장합니다. 저장한 프리셋은 하단 막대의 출력 방식 메뉴에서도 고릅니다.
- **현재 선택 가이드** — 고른 필터가 무엇을 바꾸고, 어디를 들어 보고, 무엇을 감수하는지와 주파수 응답 그래프가 있습니다.
- 7차 변조기가 불안정해 안정화가 걸렸으면 횟수와 함께 "보호형 5차로 바꾸기" · "DSD256 으로 바꾸기" 를 제안합니다.

### 7.5 Playback Chain · 실제 동작 · 진단

- **Playback Chain** 카드 — 창 머리의 것([§2.1](#21-페이지-머리))과 같습니다. "출력은 안전하게 정지했습니다." 가 뜨면 **DAC 다시 연결** 을 누릅니다.
- **실제 동작 · 진단**(접힘) — 요청한 레이트와 실제 레이트, 남은 헤드룸, 출력 지연 추정, 빠진 소리 · 끊김 횟수. 지연은 소프트웨어 추정이고 DAC 의 아날로그 출력을 잰 것이 아닙니다.

### 8.1 YouTube Music 쓰기 (Chrome 확장)

YouTube Music 은 Mac 앱이 없어 Chrome(또는 Edge)에서 듣습니다. 소리는 Fidenne Inlet 이 받아 Fidenne 으로 가고, 확장은 **곡 정보와 조작** 을 더합니다 — 하단 막대에 곡이 보이고, 막대의 재생 · 정지 · 다음 · 이전이 그 탭을 조작합니다. **실험 기능** 이며, YouTube Music 이 화면을 바꾸면 동작이 멈출 수 있습니다.

**처음 한 번 — 확장 설치(개발자 모드)**

1. 설정 › **일반** 의 **YouTube Music (실험 기능)** 을 켭니다.
2. 설정 › **개인정보** › **YouTube Music** 에서 **Chrome · Edge 확장과 연결** 을 켭니다.
3. 같은 곳의 **설치 안내…** 를 누릅니다. 작은 안내 창 머리에서 **Chrome** 또는 **Edge** 를 고릅니다.
4. **① 주소 복사** → 브라우저 주소창에 붙여 넣고 Return(`chrome://extensions` · `edge://extensions`).
5. **② 개발자 모드** 를 켭니다.
6. **③** 새로 생긴 **압축해제된 확장 프로그램을 로드합니다**(Edge 는 **Load unpacked**)를 누릅니다. 안내 창의 **경로 복사** → 폴더 고르는 창에서 **⌘⇧G** → **⌘V** → Return → **열기**.
7. **④** 열려 있던 YouTube Music 탭을 새로 고칩니다(⌘R).
8. **탭 절전 예외** — 브라우저가 쓰지 않는 탭을 재우면 YouTube Music 이 응답하지 못합니다. Chrome 은 설정 › 성능 › 메모리 절약 › **항상 활성 상태를 유지할 사이트**, Edge 는 설정 › 시스템 및 성능 › 리소스 절약 › **이 사이트를 절전 모드로 전환하지 않음** 에 `music.youtube.com` 을 더합니다.

**잘 됐는지** — 안내 창 맨 아래 줄이 **브라우저 1개 연결됨** 이고, music.youtube.com 에서 곡을 틀면 하단 막대에 그 곡이 뜹니다.

**쓰기**

- **음악 페이지에서 틀기** — 서비스를 **YouTube Music** 으로 고르면 가져온 재생목록 · 검색 칸이 보입니다. 곡을 누르면 YouTube Music 탭에서 그 곡부터 틉니다. Chrome 이 꺼져 있으면 Fidenne 이 뒤에서 띄웁니다.
- **브라우저가 첫 재생을 막으면** — `브라우저가 첫 재생을 막았습니다 · 탭에서 ▶ 한 번` 이 뜹니다. **브라우저에서 ▶ 한 번** 을 누르고 그 탭에서 ▶ 를 한 번 누르면, 그다음부터는 막대의 단추가 듣습니다. 브라우저는 사람이 누르지 않은 페이지가 스스로 소리를 내지 못하게 하기 때문입니다. Edge 는 `edge://settings/content/mediaAutoplay` 에서 music.youtube.com 을 **허용** 에 넣으면 이 한 번이 필요 없을 수 있습니다(확인 전).
- **재생목록 담기** — YouTube Music 에서 재생목록 화면을 열면 보이는 곡이 Fidenne 의 **내 재생목록** 에 `12곡 · 브라우저에서 · …` 처럼 저장됩니다. 긴 목록은 끝까지 스크롤하면 이어서 담깁니다. **목록 지우기** 는 Fidenne 에서만 지웁니다.
- **우클릭으로 담기** — music.youtube.com 의 곡 메뉴(⋮) 맨 밑 **Fidenne에 추가 ›**, 또는 브라우저 우클릭 메뉴의 **이 곡 Fidenne에 추가 ›** 로 곡 하나를 **Fidenne 좋아요 (♥)** · Fidenne 재생목록 · **새 재생목록…**(‘재생목록 N’ 으로 만들어지고 이름은 앱에서 바꿉니다)에 담고, 재생목록에서는 **이 목록 Fidenne에 추가** 로 목록 통째를 담습니다.
- **보관함** — YouTube Music 의 보관함(좋아요한 곡 · 재생목록 · 앨범 · 아티스트) 화면을 직접 열면 그 목록을 받아 옵니다. **다음 재생** 에는 Fidenne 이 튼 목록, 아니면 탭의 「다음 트랙」 목록이 보입니다.
- **음량 · 음질** — Playback Chain 의 음원 줄에서 페이지 음량이 100 % 가 아니면 주황입니다 — YouTube Music 의 음량 막대를 끝까지 올립니다. 음질 — Premium 이면 YouTube Music 의 프로필 사진 › **설정** › **재생 및 제한사항** › **오디오 품질** 을 **높음** 으로 둡니다. 광고 중에는 곡 정보를 보이지 않고 "광고 중" 이라고만 합니다.
- **앱을 업데이트한 뒤** — `chrome://extensions` 의 **Fidenne for YouTube Music** 카드에서 새로 고침(↻)을 한 번 누릅니다. `브라우저의 확장이 옛 판…` 줄이 남으면 **확장 폴더 열기** 를 누르고 다시 ↻.
- 오가는 것은 곡 이름 · 아티스트 · 앨범 · 길이 · 위치 · 대기열 · 앨범 그림 등이고, 이 Mac 안에서만 오갑니다. 웹 스토어에는 아직 없습니다(개발자 모드 설치만). Safari 는 지원하지 않습니다.

### 8.2 YouTube Music 앱 창 — 지금은 없다

Fidenne 창 안에서 YouTube Music 에 로그인해 듣는 방식은 지금 없습니다. YouTube Music 은 [§8.1](#81-youtube-music-쓰기-chrome-확장)의 확장으로 씁니다. 그 창으로 로그인한 적이 있으면 남은 웹 저장소를 Fidenne 을 끈 뒤 터미널에서 `rm -rf ~/Library/WebKit/*/WebsiteDataStore/5c0f7e2a-3b1d-4e8f-9a6c-2d7b8e1f4a90` 로 지우고, Google 계정의 "내 기기" 에서 로그아웃합니다.

## 10. 지원 파일 보내기

문제가 생겼을 때 무엇이 일어났는지 담은 진단 번들을 만들어 보냅니다.

1. **도움말 › 문제 제보용 진단 만들기…** 를 누릅니다(설정 › 일반 › 도움말에도 같은 단추가 있습니다).
2. 처음 실행할 때 «문제 제보용 진단 기록»에 동의했다면 이미 기록되고 있으니, 문제가 생긴 뒤 앱을 끄기 전에 바로 번들을 만듭니다. 꺼 두었다면 **진단 기록 시작** 을 눌러 두고, 다음에 문제가 생기면 그때 만듭니다.
3. **번들 만들고 내용 보기** 로 들어갈 내용을 확인합니다.
4. **메일로 보내기** 를 누르면 메일 앱이 주소 · 제목 · 양식을 채워 열립니다. 다른 메일(Gmail 등)을 쓰면 옆의 **메일 양식 복사** 로 같은 내용을 복사해 붙여 넣습니다. 번들은 직접 붙입니다. 앱 버전과 macOS 버전은 양식과 번들에 저절로 들어 있습니다.

**잘 됐는지** — 메일 앱에 새 메일이 열리고, **번들 폴더 열기** 로 번들 파일이 보입니다.

- 번들에는 숫자와 상태, 그 시간대에 들은 곡(제목 · 아티스트 · 서비스, 최근 200곡까지)이 들어갑니다. 파일 경로 · 장치 이름 · 계정은 들어가지 않습니다.
- **진단 번들은 메일로 보내 주세요 — GitHub 이슈에는 올리지 마세요.** 올릴지, 어디에 올릴지는 내가 정하고 앱은 아무것도 보내지 않습니다. 보내 주신 제보와 번들은 AI 도구(Anthropic 의 Claude 등)로 읽을 수 있습니다([개인정보](../../PRIVACY.md)). 진단 메뉴의 **지원용 진단 내보내기…** 도 같은 번들을 만듭니다.
- 무엇을 함께 적으면 좋은지는 [문제 확인 가이드 §9](TROUBLESHOOTING.md#9-그래도-안-되면--무엇을-모아-보내나).
