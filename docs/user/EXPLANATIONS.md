# Fidenne 설명 — 왜 이렇게 동작하나

- 조작하다 말고 읽는 글이 아니라 **궁금할 때** 읽는 글이다. 무엇이 어디 있나는 [사용 설명서](MANUAL.md), 무엇을 하려면은
  [할 일별 지시서](HOW-TO.md), 막혔으면 [문제 확인 가이드](TROUBLESHOOTING.md).
- 여기 글은 설명서에 섞여 있던 것을 **줄이지 않고 옮긴 것**이다(2026-09-25 설명서 정돈). 설명서의 그 자리에는 이리로 오는 링크가 남아 있다.

## 1. 과한 설정 탐지기의 한도가 AutoEq 숫자와 다른 까닭

탐지기 자체는 [설명서 §6.1](MANUAL.md#61-response-그래프) 의 **과한 설정 탐지기** 항목.

### 1.1 기울기 한도가 18 dB/oct 가 아닌 까닭

AutoEq 의 18 dB/oct(max slope)는 필터를 맞추기 **전** 보정 곡선에 거는 한도이고
맞춘 필터에는 걸지 않는다 — AutoEq 가 쓰는 필터 한 단(Q 6 · +6 dB)만 해도 옆면이 약 32 dB/oct 다. 전에는 탐지기가 이 18 을 맞춘 EQ 에 걸어
**앱 자신의 Auto fit 결과를 경고했다**(실제 헤드폰 100 개로 잰 AutoEq 맞춤의 절반 남짓, 사용자 화면의 "635 Hz 21 dB/oct"). 지금은 필터 한 단으로는
나오지 않는 좁은 부스트(예: Q 8 · +6 dB)만 경고한다. Auto fit 결과도 드물게(100 개 가운데 1–6 개) 경고되는데, 그때는 AutoEq 의 보정 곡선 자체가
그만큼 가파른 곳이다(딥 옆 — AutoEq 가 기울기를 제한하지 않는 자리). Auto fit 자체와 소리는 바뀌지 않았다.

그 뒤 그 "드문 경고" 가 사용자 화면(Arashi → Susvara, 4.9 kHz 51 dB/oct)에 떴고 보정 창은 고치지 못했다. 옆면은 −4 dB 의 딥에서 +2.6 dB 로
솟는 곳이었다 — 가파른 것은 **컷**이었다. 그래서 지금은 합친 곡선만이 아니라 **부스트 부분만의 곡선도** 그만큼 가파를 때만 경고한다. 그 사례는 경고되지 않고,
Auto fit 결과의 경고는 100 개 가운데 0–1 개로 줄었다(Q 8 · +6 dB 같은 좁은 부스트는 여전히 경고). 경고가 뜨면 **보정 제안… 의 개선**이 그 옆면을 만드는
밴드의 Q 나 게인을 가장 작게 낮춰 고친다.

### 1.2 부스트 한도가 +6.2 dB 이고 10 kHz 위는 평균인 까닭

AutoEq 의 +6 dB(max gain)도 맞추기 **전** 보정 곡선을 자르는
한도다. AutoEq 는 자른 뒤 곡선을 한 번 더 다듬어 스스로 +6.14 까지 넘기고, 맞춘 필터의 합성 곡선에는 한도를 걸지 않으며(넘친 만큼 Preamp 로 덮는다), 10 kHz 위는
평균만 맞춘다. 전에는 탐지기가 +6.0 을 맞춘 EQ 의 모든 점에 걸어 실제 헤드폰 100 개로 잰 **Auto fit 결과의 절반 남짓을 경고했다**(최대 +8.65 dB — 대부분 20 kHz 끝의
셸프 넘침). 지금은 AutoEq 가 곡선을 실현할 때 두는 여유 0.2 dB 를 넘고, 10 kHz 위는 대역 평균으로 넘을 때만 경고한다 — 100 개 가운데 필터 10(기본) 18 개 · 16 은 5 개 ·
32 는 0 개(맞춤 잔차가 여유를 넘는 곳, 0.58 dB 이하). 사용자 화면의 DF 곡선은 전에도 지금도 경고 없음. 클리핑은 PCM 헤드룸 자동과 최대 이득 판정이 맡는다.
**보정 제안… 의 개선**은 넘친 곳을 +6.0 까지 내린다. Auto fit 자체와 소리는 바뀌지 않았다.

## 2. 이득 조절이 셋인 까닭 — PCM 헤드룸 · EQ Preamp · Ostrum Headroom

[설명서 §7.4](MANUAL.md#74-필터--모듈레이터--출력-게인-접힘--dsd-경로의-소리-설정) 의 **PCM 헤드룸** 옆 ⓘ 풍선이 보이는 내용이다.

**"이득 조절이 왜 셋인가요? — 각각 무엇을 막나요?"** 옆 ⓘ 풍선: 셋 다 전체 크기를 내리지만 자리가 달라 하는 일이 다르다.
- **PCM 헤드룸** — 모든 DSP 뒤, 변조기 앞. **막는 것: 클리핑**(변조기 입력 한계 7차 0.92 · 5차 0.78, PCM 풀스케일). 실제로 파형이 잘리는 곳은 여기 하나다. 기본 자동.
- **EQ Preamp** — EQ 맨 앞(Ostrum 앞). 막는 값이 아니라 **EQ 의 레벨**: AutoEq 같은 EQ 파일이 가져오는 값이고, 뒤의 Ostrum · Harmonics 에 들어가는 크기도 정한다. 앱 안 계산은 부동소수라 여기서는 잘리지 않는다.
- **Ostrum Headroom** — Ostrum 안, Harmonics 앞. **막는 것: Harmonics 과구동**(배음 곡선의 동작점). 권장 Headroom 이 뜨면 직접 옮기고 스스로 움직이지 않는다.
- 하나로 합치지 않은 까닭: Ostrum 이 켜져 있으면 Preamp −6 dB 가 출력 봉우리를 4.3–7.4 dB 만 내리고(가짜 장치 측정) Ostrum Headroom 은 Harmonics 의 동작점을 바꾼다 — 앞의 것으로 클리핑을 막으면
  Ostrum 소리가 바뀐다. 자동 PCM 헤드룸은 앞의 둘이 남긴 부스트만큼만 내리므로(Preamp −6 dB 인 AutoEq 파일이면 −3 dB 그대로) 두 번 내리지 않는다. 보통은 셋 다 손대지 않는다.

## 3. 바뀐 것 — 전에는 어땠나

설명서가 지금 동작만 말하도록, 절마다 붙어 있던 "전에는 …" 문장을 여기로 모았다. 설명서 절 차례대로다.

- [설명서 §2.2](MANUAL.md#22-하단-재생-막대)
  - **출력 설정… · 사운드 설정…**: 전에는 DSP 페이지를 열어 누른 곳과 설정이 있는 곳이 달랐다.
- [설명서 §2.5](MANUAL.md#25-설명--그래프-읽는-법--용어-풀이)
  - **ⓘ 풍선**: 예전에는 설명이 본문 안에서 접힘으로 펼쳐져 ⓘ 를 누르면 그 밑의 조작이 밀렸다. 지금은 풍선이라 밀리지 않는다.
- [설명서 §6](MANUAL.md#6-dsp-페이지)
  - **마지막 알림 줄**: 전에는 탭 아래 창 밖에 떴다.
  - **선택된 조작의 색**: 전에는 라이트에서 검정 · 다크에서 흰색이었다.
  - **다른 페이지에 갔다 와도 그대로**: 전에는 페이지를 떠나면 이것이 전부 사라지고 Equalizer 가 엔진 설정(적용하지 않았으면 빈 EQ)으로 다시 실렸다. 엔진 설정은 그때도 **Apply to Engine** 을 눌러야만 바뀌었다.
- [설명서 §6.1](MANUAL.md#61-response-그래프)
  - **층**: 예전의 "타깃 + 기울기 −1 dB/oct" 층은 뺐다.
  - **Composite Response 의 Headroom · Output**: 전에는 Ostrum 탭의 Composite Response 그래프만 Headroom · Output 을 넣어 그려 같은 곡선이 한 쪽에서 두 높이였다.
  - **Auto fit 단추 자리**: 전에는 그래프 옆이었다 — 그 옆의 "Open measurement…" · 타깃 단추는 파일 접힘을 펼치기만 해서 뺐다.
  - **Auto fit 이 못 맞출 때**: 전에는 Auto fit 이 접힌 구역을 펼치기만 해서(창 밖) 눌러도 아무 일이 없어 보였다.
  - **기울기 초과 경고**: 전에는 경고가 보정을 약속하고 시트가 "EQ 로 줄일 것이 없습니다" 로 답했다.
- [설명서 §6.2](MANUAL.md#62-equalizer)
  - **Preamp 권고**: 전에는 권고가 밴드 부스트의 합이라 자동 맞춤 EQ 에 −24 dB 를 권했다.
  - **FIR 백엔드의 머리 줄**: 전에는 FIR 이 돌기 시작하면 백엔드 칸이 달라 "편집 중 · 아직 적용하지 않음" 에 멈췄다.
  - **FIR 백엔드의 첫 소리**: 전에는 시작할 때마다 FIR 을 준비하는 동안(48 kHz 에서 표준 길이 약 0.4 s, ×4 약 1.5 s) EQ 없이 원음이 나갔다 — 고친 결함이다.
- [설명서 §6.3](MANUAL.md#63-ostrum)
  - **노브 스크롤 미세 조정**: 전에는 스크롤이 Shift 만 읽었다.
  - **노브 세로 끌기**: 전에는 회전만 읽어 곧게 끌면 값이 0.00 에 남았다.
  - **엔진 보고 줄**: 전에는 아무것도 받지 않은 엔진에 대해 "요청 리비전 0이 아직 적용되지 않았습니다(적용된 것은 1)" 라고 적었다.
  - **Topology Manual 의 그래프**: 전에는 엔진은 Manual 로 소리를 내는데 그래프는 Blend 곡선을 그렸다 — 고쳤다.
- [설명서 §6.5](MANUAL.md#65-①-headphone--②-target-equalizer-의-auto-eq-탭--measurement--target-files-접힘)
  - **목표로 · 적용이 안 됐을 때**: 전에는 까닭이 찾기 창 안에만 있어 닫으면 사라졌다.
  - **Target file type 의 이름**: 전 이름은 "Target type" 이었고 지금 타깃을 바꾸는 칸으로 읽혔다.
- [설명서 §6.6](MANUAL.md#66-③-auto-fit-equalizer-의-auto-eq-탭--auto-fit--refinement-접힘)
  - **+6 dB 넘는 밴드 표시**: 2026-09-25 에 뒤집었다 — 전에는 +6 dB 를 넘는 밴드를 주황으로 "AutoEq 가 만들지 않는 크기" 라 적었다.
  - **LLM 프롬프트의 기울기 한도**: 전에는 프롬프트의 기울기 한도가 18 dB/oct 였다.
- [설명서 §6.7](MANUAL.md#67-ab-단추의-패널--ab--abx--auto-bypass--loop--음량-맞춤level-matched-comparison)
  - **A/B 거부의 까닭**: 전에는 "엔진이 비교를 시작하지 않았습니다. 재생은 그대로입니다." 에서 끝났다.
  - **FIR 백엔드의 A/B**: 전에는 FIR 에서 늘 `코드 3` 으로 거절했다.
- [설명서 §7.1](MANUAL.md#71-출력-독립-제어--출력-방식)
  - **PCM Direct 가 레이트를 모를 때**: 전에는 시작하지 않고 "DAC 연결 대기" 에 머물렀다.
- [설명서 §7.3](MANUAL.md#73-스트리밍-앱-자동-재생--입력과-출력-장치)
  - **시스템 전체 탭**: 예전 시스템 전체는 원래 출력을 막지 않았다.
- [설명서 §7.4](MANUAL.md#74-필터--모듈레이터--출력-게인-접힘--dsd-경로의-소리-설정)
  - **현재 선택 가이드**: 예전의 "설계 특성" · "이렇게 비교해 보세요" 는 무엇이 바뀌나요 · 어디를 들어보나요 두 줄과 같은 문장이라 뺐다.
  - **필터 주파수 응답 그래프**: 전에는 따라감 필터 28–33 에 그래프가 없었다.
