# 궁금할 때

앱을 쓰다가 "왜 이렇게 되지?" 싶을 때 읽는 글입니다. 무엇이 어디에 있는지는 [사용 설명서](MANUAL.md), 무엇을 하려면 어떻게 하는지는
[할 일별 지시서](HOW-TO.md), 막혔을 때는 [문제 확인 가이드](TROUBLESHOOTING.md)를 보세요.

<a id="11-기울기-한도가-18-dboct-가-아닌-까닭"></a>
## 과한 설정 경고는 왜 뜨나요?

DSP 페이지의 과한 설정 탐지기가 지금 설정으로 소리가 너무 커지거나 곡선이 너무 가파르게 솟는 곳을 찾으면 경고합니다.
경고만으로는 소리가 바뀌지 않습니다.

AutoEq 가 내놓는 곡선도 이 한도를 조금 넘을 때가 있습니다. 그래서 한도를 AutoEq 숫자 그대로 쓰지 않고, 필터 한 개로는
만들 수 없는 좁은 부스트나, 합친 곡선과 부스트만의 곡선이 모두 가파른 곳에서만 경고합니다.
경고가 뜨면 **보정 제안…** 에서 고칠 방법을 고를 수 있습니다.

<a id="12-부스트-한도가-62-db-이고-10-khz-위는-평균인-까닭"></a>
## 부스트 경고는 어디서부터 뜨나요?

맞춘 EQ 곡선이 +6.2 dB 를 넘는 곳에서 뜹니다. +6 dB 에 AutoEq 가 곡선을 만들 때 두는 여유(0.2 dB)를 더한 값입니다.
10 kHz 보다 높은 곳은 점 하나가 아니라 대역의 평균으로 따집니다. 그 위쪽은 필터가 정확히 따라가기 어려운 자리이기 때문입니다.

클리핑(소리가 잘리는 것)은 이 경고가 아니라 PCM 헤드룸이 막습니다.

## EQ 보정은 어떻게 이루어지나요?

자동으로 하는 것은 **클리핑 막기 — Preamp 자동 낮춤** 하나이고, 기본은 꺼져 있습니다. 켜면 EQ · Ostrum · 크로스피드를 더한 소리가 0 dB 를
넘을 때 Preamp 만 필요한 만큼 낮춥니다. 밴드는 건드리지 않고 곡선 모양도 그대로입니다.

밴드를 고치는 보정은 **보정 제안…** 에서 **보정 적용** 을 누를 때만 일어납니다. 창은 **업계 관례**로 열립니다. Preamp 만 내리고
곡선 모양은 그대로 둡니다. 옆의 **개선**을 고르면 넘친 부스트나 가파른 옆면을 만드는 밴드만 가장 조금 고칩니다.
개선은 곡선의 모양을 바꾸므로 창에 경고가 붙고, 적용할지는 직접 정합니다. 적용한 뒤에도 **보정 되돌리기** 로 한 번 돌아갈 수 있습니다.

## Preamp 는 왜 내려가나요?

EQ 로 어떤 대역을 올리면 전체 소리가 커져 잘릴 수 있습니다. Preamp 는 그만큼 전체를 미리 낮춰 두는 값입니다.
AutoEq 같은 EQ 파일은 이 값을 함께 가져옵니다. 그래서 EQ 를 켜면 소리가 조금 작아질 수 있습니다.

모양을 비교하기 좋도록 DSP 그래프는 Preamp 를 뺀 곡선으로 그립니다. 소리에는 Preamp 가 그대로 걸려 있습니다.

<a id="2-이득-조절이-셋인-까닭--pcm-헤드룸--eq-preamp--ostrum-headroom"></a>
## 음량을 낮추는 설정이 왜 셋인가요?

셋 다 전체 크기를 내리지만 놓인 자리가 달라 막는 것이 다릅니다.

- **PCM 헤드룸**: 모든 처리의 맨 뒤에서 **클리핑**을 막습니다. 기본은 자동입니다.
- **EQ Preamp**: EQ 의 맨 앞에서 EQ 의 레벨을 정합니다. "Preamp 는 왜 내려가나요?" 의 그 Preamp 입니다.
- **Ostrum Headroom**: Ostrum 안에서 Harmonics 가 지나치게 걸리지 않게 합니다. 권장 값이 뜨면 직접 옮깁니다. 옆의 **바뀔 때마다 자동으로**(기본 꺼짐)를 켰을 때만 노브가 권장 값을 따라갑니다.

하나로 합치면 한쪽을 위해 내릴 때 다른 쪽 소리가 달라지기 때문에 나누어 두었습니다. 자동 PCM 헤드룸은 앞의 둘이 이미 내린 만큼을
빼고 남은 부스트만 내리므로 같은 양을 두 번 내리지 않습니다. 보통은 셋 다 손대지 않아도 됩니다.

## PCM Direct 와 엔진 출력은 무엇이 다른가요?

**PCM Direct** 는 Fidenne 이 소리를 처리하지 않습니다. 재생 앱의 소리가 macOS 를 거쳐 DAC 로 나가고, DAC 의 샘플레이트는
곡마다 맞추지 않고 시작할 때 한 번 정합니다(Spotify 는 44.1 kHz). 곡과 다르면 macOS 가 바꿉니다. EQ · Ostrum · 크로스피드는 거치지 않습니다.

**엔진 출력**(DSD 또는 PCM 352.8 kHz)은 Fidenne 엔진이 소리를 처리해서 DAC 로 보냅니다. EQ 등을 모두 꺼도 그 형식에 필요한 변환
(업샘플링 · 변조 · 디더 · 헤드룸)은 걸리므로, 고른 필터와 변조기에 따라 소리의 성격이 달라질 수 있습니다.

## 왜 DAC 가 352.8 kHz 를 받아야 하나요?

엔진의 PCM 출력은 352.8 kHz(44.1 kHz 의 8배)로 고정되어 있습니다. 이 형식을 받지 못하는 장치로는 엔진 출력을 보낼 수 없습니다.
내장 스피커 · AirPods · 대부분의 동글 · 모니터가 그런 장치이고, 출력 장치 목록에 이름 끝에 표시됩니다.

DAC 를 아직 고르지 않았거나 확인되지 않았으면 PCM Direct 로 시작합니다. DAC 가 DSD 를 받으면 DSD 로도 보낼 수 있습니다.

## Fidenne Inlet 은 왜 따로 설치하나요?

Fidenne Inlet 은 음악 앱이 "스피커"처럼 소리를 보낼 수 있는 가상 오디오 장치입니다. macOS 에서 이런 장치는 앱이 아니라
시스템 오디오 서비스가 불러오기 때문에, 앱 안에 둘 수 없고 시스템 폴더(`/Library/Audio/Plug-Ins/HAL`)에 있어야 합니다.
그래서 설치할 때 관리자 암호를 한 번 묻고, 오디오 서비스를 다시 시작하면서 잠깐 모든 소리가 끊깁니다. 다른 가상 오디오 장치도 같은 방식으로 설치합니다.

설치하는 것은 Inlet 하나뿐이고, 설치 직전에 Fidenne 의 서명이 맞는지 다시 확인합니다. 지우려면 **입출력 · 진단 › 입력과 출력 장치** 에서 **제거…** 를 누릅니다.

설치하고 싶지 않으면 처음 설정에서 **시스템 탭** 을 고릅니다. 설치 없이 되지만 macOS 가 소리를 48 kHz 로 바꿔서 넘겨줍니다.
Inlet 은 재생 앱의 원래 샘플레이트를 그대로 받기 때문에 권장합니다.
