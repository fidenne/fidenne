1 · 처음 설정

소리가 나갈
DAC를 고릅니다

사이드바 입출력 · 진단(⌘5)에서 출력 DAC와 출력 방식을 고릅니다.

PCM DirectFidenne이 손대지 않고 macOS가 DAC로 보냅니다. 소리 다듬기는 꺼집니다.
DSD (DoP)처음 골라져 있습니다. 엔진이 필터와 DSD 변환을 거쳐 보냅니다.
PCM 352.8 kHz엔진이 처리한 소리를 정수 PCM으로 보냅니다.

소리 다듬기는 352.8 kHz 이상 받는 2채널 외장 DAC에서만 돕니다.
