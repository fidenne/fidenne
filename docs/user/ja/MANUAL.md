# Fidenne ユーザーマニュアル

[한국어](../MANUAL.md) | [English](../en/MANUAL.md) | 日本語

## 1ページ要約

**Fidenne とは** — いつも聴いている再生アプリのサウンドを DSP で整え、外付け DAC へ送る Mac アプリです。EQ・Ostrum・クロスフィードとフィルター、DAC に合った出力方式を選び、Playback Chain で音が通る経路を確認します。利用しているサービスアプリを Fidenne から操作し、曲情報や歌詞を一緒に表示します（再生は各サービスアプリが行います）。この Mac 内の音楽ファイルも処理できます。**Apple シリコン Mac と macOS 15 以上**が必要で、**外付け DAC** を推奨します（Fidenne は内蔵スピーカー・AirPods・HDMI にもサウンドを処理して送ります）。

**サイドバー** — **ストリーミング**（⌘1）・**ローカル**（⌘2）・**再生履歴**（⌘3）・**DSP** グループ（**EQ** は ⌘4）・**入出力 · 診断**（⌘5）・**歌詞** です。DSP グループには EQ・Ostrum・プラグイン・クロスフィード・コンボリューション・DSP アシスタントがそれぞれのページとして並んでいます。

- **ストリーミング** — サービスを選んで検索・再生し、最初の画面から続きを聴きます。（[§3](#3-ストリーミングページ)）
- **ローカル** — この Mac の音楽フォルダを読み込み、曲・アルバム・プレイリストとして表示します。（[§4](#4-ローカルページ)）
- **再生履歴** — 聴いた履歴を期間・出典別に確認して書き出します。（[§5](#5-再生履歴ページ)）
- **DSP** — EQ（AutoEQ を含む）・Ostrum・クロスフィード・コンボリューション（IR）・プラグイン（Audio Unit エフェクト）・DSP アシスタントページ。（[§6](#6-dsp-페이지)）
- **入出力 · 診断** — 出力方式、入力と出力デバイス（DAC）、フィルター・DSD 変換、現在音が通っている経路。（[§7](#7-入出力--診断ページ)）

**3つの出力方式**（`入出力 · 診断 › 出力方式`、[§7.1](#71-出力の独立制御--出力方式)）

- **PCM Direct** — Fidenne はサウンドを処理しません。再生アプリ → macOS → DAC へそのまま送られます。曲ごとにレートを合わせることはせず開始時に一度決定し、レートが異なる場合は macOS が変換します。
- **PCMオーバーサンプリング** — Fidenne がフィルターで引き上げて整数 PCM（24・16-bit）で送ります。対応レートは 44.1・48 kHz 系列のレート（44.1 ~ 768 kHz）で、新しい設定では音源レートを維持します。設定値と実際の出力レートは Playback Chain で確認します。
- **DSD (DoP)** — Fidenne が処理して DSD として DAC に送ります。
- DSD・PCMオーバーサンプリングは、EQ・Ostrum・クロスフィード・コンボリューションをオフにすればトーンを変える処理は行われませんが、その形式に必要な変換（アップサンプリングフィルター・DSD 変調器・ディザ・ヘッドルーム）は適用されます。

**音量の注意** — 初めて再生するときは DAC・アンプの音量を下げてから開始し、聴きながらゆっくり上げてください（[§1](#1-初回起動時--初期設定-5-ステップ)）。

**ヘルプが必要なとき** — タスク別の手順は [操作手順ガイド](HOW-TO.md)、初期インストールは [インストール・使用ガイド](GUIDE.md)、うまく動かないときは [トラブルシューティングガイド](TROUBLESHOOTING.md)、疑問に答える Q&A は [解説](EXPLANATIONS.md)、まだ対応していない機能は [既知の制限事項](KNOWN_LIMITATIONS.md)。問題を報告する方法は [§10](#10-サポートファイルの送信) と [ベータ案内と報告経路](#ベータ版のご案内と報告先) をご覧ください。**〔実験〕** はアプリ自身が「実験」と表示している選択肢です。

## 0. ひと目でわかる概要

音が通る経路：再生アプリのサウンド（Fidenne Inlet またはシステムタップで取得）やこの Mac の音楽ファイル → Fidenne（EQ・Ostrum・クロスフィード・コンボリューション/IR） → DSD（DoP）または PCM（44.1 ~ 768 kHz） → DAC。Fidenne は内蔵スピーカー・3.5 mm 端子・AirPods・HDMI にも EQ・Ostrum・クロスフィード・フィルターを適用した PCM サウンドを処理して送ります。最後に macOS がシステムミキサーでミックスして送るため、ビットパーフェクトではありません（**システムミキサー経由・ビットパーフェクト非対応**）。**PCM Direct** は再生アプリ → macOS → DAC であり、Fidenne を通りません。

### Fidenneが行うこと・行わないこと

各音楽サービスの規約とポリシーに合わせて作成しており、その内容が変われば追随して修正します。Fidenne が何を使って何を行うかをまとめました。初期設定 5 ステップの 4 番目と同じ内容で、アプリメニュー › **Fidenneが行うこと・行わないこと** からいつでも見直すことができます。

**行うこと**

- macOS がアプリに公開しているオーディオ機能（CoreAudio・オーディオキャプチャ）で再生アプリのサウンドを受け取り、リアルタイムで整えて選択した DAC に送ります。
- ミュージック・Spotify アプリが自ら公開している AppleScript で現在の曲を読み取り、再生・一時停止・曲の移動を伝えます。
- Apple Music ライブラリとカタログは、Apple が提供する MusicKit（Apple Music API）で、許可された場合のみ読み取ります。
- YouTube Music は、アプリに含まれる Safari 拡張機能および手動でインストールする Chrome・Edge 拡張機能が、開いているタブの曲情報をこの Mac 内で伝えます。
- Spotify の検索・プレイリスト・再生操作（Spotify Web API）は、ご自身の Spotify デベロッパアプリのキーを入力した場合のみ有効になります。
- 再生履歴は、再生アプリが AppleScript で示す現在の曲（タイトル・アーティスト・アルバム・曲の長さ）と聴いた時間で集計します（ローカルファイルはファイルタグから）。この Mac 内のみに保存し、外部へ送信しません。

**行わないこと**

- サウンドを保存したりファイル化したりしません。録音機能はありません。
- 音楽サービスのサブスクリプションを代行したり回避したりしません。曲は各サービスのアプリとご自身のアカウントで再生されます。
- 各サービスの広告をブロックしたりスキップしたりしません。再生回数の集計と広告は各サービス側のままです。
- Fidenne が運営するサーバーはありません。サービスのログイン情報はそのサービスにのみ送信されます。
- Spotify の検索結果を他のサービスの結果と同一画面に混在させません。
- Spotify Web API が提供した情報を、サービス間の曲の関連付け・再生統計・他サービスへの送信には使いません。
- 広告や販売はありません。分析・広告 SDK は組み込んでいません。

### Fidenne が利用するもの

Fidenne は Apple・Spotify・Google とは無関係の個人が作成した無料アプリです。Apple Music は Apple Inc.、Spotify は Spotify AB、YouTube Music は Google LLC の商標です。

- **Apple Music** — ミュージックアプリを macOS のオートメーションで操作します。ライブラリの一覧は Apple の Apple Music 連携で読み取り、聴いた曲（Apple Music・Spotify・YouTube Music）の異なる表記や同一曲の照合は Apple Music カタログに問い合わせ、歌詞検索や同一曲の紐付けのためアプリが起動している間だけメモリ上に保持します（カタログの応答は保存しません）。曲ごとに元のレートに合わせるため、ミュージックのオーディオ履歴行を読み取ります（保存しません）。
- **Spotify** — Spotify アプリを macOS のオートメーションで操作します。検索・プレイリスト画面は、ユーザーが自ら作成した Spotify デベロッパキーがある場合のみ使用します（任意）。
- **YouTube Music** — ブラウザ拡張機能が開いているページの曲情報を読み取り、再生・停止などの操作を伝えます。サイトを自動で巡回することはなく、ユーザーがクリックした 1 回につきその 1 ページだけを開きます。広告には干渉しません。実験的機能です。
- **歌詞** — LRCLIB（lrclib.net）。歌詞欄の下に `歌詞提供 LRCLIB` の行が表示されます。歌詞の著作権は各権利者に帰属します。
- **ヘッドホン測定** — squig.link の公開測定データを取得して補正に使用します。測定データは各測定者のものであり、アプリは測定者名と元のグラフへのリンクを併記します。
- **曲を検索・おすすめチャート** — Apple の公開検索・チャート。検索は 4 秒に 1 回まで送信し、結果と画像はアプリを終了するまでメモリ上のみに保持します（この Mac には残しません）。
- **サウンド** — macOS オーディオで受け取り、この Mac 内でのみ処理します。録音したり外部へ送信したりしません。
- **保管** — 通常のアルバムアートと歌詞の検索キャッシュは、最後の使用から 30 日後に削除します。Spotify のアートワークと情報は取得日から 30 日間のみ保持し、歌詞タブに保存した歌詞と翻訳は手動で削除するまで残ります。

詳しい一覧は [プライバシー](../../../PRIVACY.ja.md) をご覧ください。

**ウィンドウの構成** — サイドバーは ストリーミング・ローカル・再生履歴・DSP・入出力 · 診断・歌詞 の順です。⌘1・⌘2・⌘3・⌘4・⌘5 はそれぞれ ストリーミング・ローカル・再生履歴・EQ・入出力 · 診断 を開きます。サイドバーの表示順序を変更してもショートカットは変わりません。一番下の歯車アイコン **設定…** 行は設定ウィンドウを、**GitHub** 行は公開リポジトリページを開きます。サイドバーのヘッダには Fidenne の名前のみが表示され、バージョンとビルド番号はアプリメニュー › Fidenneについて および 設定 › 一般 にあります。ウィンドウは前回のサイズ・位置と最後に開いていたページで再び開きます。

## 1. 初回起動時 — 初期設定 5 ステップ

初めて起動すると「Fidenneの初期設定」ウィンドウが開きます。各ステップは **戻る / 次へ** で行き来します。

1. **音の出力先のDAC** — 出力デバイスを選びます。「あとで選ぶ」も可能です。デバイスが表示されない場合は DAC を接続して更新します。
   USB DAC は **USB モードを UAC 2.0** にし、**DAC 自体の EQ はオフ** にして使用します。UAC 1.0 は 96 kHz までのため DSD を伝送できず、DAC の EQ は PCM を再計算する仕組みのため DSD（DoP）をそのまま通せず、受信可能なレートが下がります（例：FiiO K15 は EQ をオンにすると 192 kHz まで）。その場合、DSD および選択した PCM 352.8 kHz 出力が開始されません（PCM は出力レートをその DAC が受け取れる低いレートに変更すれば再生できます）。EQ は Fidenne の EQ を使えば DSD と併用できます。Fidenne は内蔵スピーカー・3.5 mm 端子・Bluetooth・HDMI にもこの設定なしでサウンドを処理して送り、最後に macOS がシステムミキサーでミックスして送ります（[§7.1](#71-出力の独立制御--出力方式)）。
2. **音の取り込み方法**
   - **Fidenne Inlet**（推奨、最初から選択されています） — 再生アプリの元のレートをそのまま受け取ります。インストールされていない場合は **インストール…** をクリックします。macOS が管理者パスワードを一度求め、オーディオサービスを再起動するため一時的にすべての音が途切れます。インストールは後から入出力ページでも行えます。
   - **システムタップ** — インストールなしですぐに使えます。48 kHz で受け取ります。
   - 別のループバックアプリをすでに使っている場合は、後から入出力ページの **＋ 他の入力デバイス** から選びます。
3. **macOSが尋ねること** — 権限は今すぐには求められず、その機能を初めて使うときに macOS が尋ねます（システムオーディオ・マイク・オートメーション・メディアライブラリ）。画面には各権限がいつ尋ねられ、拒否すると何が使えなくなるかが書かれています。初期設定が終わるまではミュージックや Spotify に何も送信しないため、それらのアプリのオートメーション許可ダイアログや、ミュージックアプリが勝手に起動することも設定完了後に発生します。
4. **Fidenneが行うこと・行わないこと** — Fidenne が何を使って何を行い、何を行わないかを読みます（[§0](#fidenneが行うこと行わないこと) と同じ内容です）。
5. **ライセンスとインターネット接続** — 規約全文の下にチェックボックスが 4 つあります：**すべてに同意**・**[必須] 利用規約に同意します**・**[任意] インターネット接続機能を使う**・**[任意] 問題報告用の診断記録（このMacにのみ保存）**。必須項目にチェックを入れると **開始** が押せるようになります。任意の項目をオンにしなくても再生はでき、インターネットを使う機能のみがオフになります。**同意せずに終了** はアプリを終了します。選択は後から 設定 › プライバシー で変更できます。

**確認方法** — 同じウィンドウにサイドバーとページが表示され、次回起動時からは初期設定は再び表示されません。

**初回再生時 — 音量の案内。** アプリを起動するたびに最初の再生を押すと、音を出す**前に**「音量を下げてから開始してください」というシートが 1 枚表示されます。DAC・アンプの音量を 0 または非常に低い位置まで下げて **下げました、開始**（Return）を押し、聴きながらゆっくり上げていきます。**キャンセル**（Esc）なら何も開始しません。初めて使う DAC で開始するときも「○○を初めて使用します」と一度表示されます。この案内をオフにする場所は 設定 › **サウンドの安全** だけで、オフにしても初めて使う DAC では一度確認が出ます。

**出力監視。** 音楽ではあり得ない信号（片端に張り付いた音・大きな直流成分・聴こえない超高域の過大な信号）が出ると、その再生の残りをミュートし、ウィンドウ上部に「出力をミュートしました — …」と表示します。停止して再生し直すと元に戻ります。通常の音質は変えません。

**インターネット。** インターネットを使う機能は 設定 › プライバシー › **ネットワークの送信先** で一つずつオン・オフできます。すべてオフにしても、音の取り込み・DSP・DSD 変換・DAC 出力・ファイル再生はそのまま動作し、サウンドがいかなる場合も外部へ送信されることはありません。

**起動が 2 回連続で完了しなかった場合** — 3 回目の起動時に `起動時の復旧` ウィンドウが開きます。**安全に開始** は今回 1 回だけエンジン・キャプチャ・ブラウザ拡張・自動再生連携をオフにして起動し（`安全に開始中` と表示されます）、設定は消去しません。次回起動時は通常に戻ります。**診断を作成…** は保存してある診断から送付用データを作成し、**このまま開始** は通常どおり起動します。正常起動後の強制終了・手動終了・アップデート再起動は失敗としてカウントしません。

## 2. 常に表示されるもの — ヘッダ・下部再生バー・メニュー

### 2.1 ページヘッダ

ページ名の横にある **Playback Chain** ボタンをクリックすると、音が通る順序（**音源 → キャプチャ → 変換 → 帯域 → DSP → フィルター → 出力 → デバイス**）が現在の値で 1 行ずつ表示されます。

- ヘッダの点と言葉が全体の状態です：**実行中 · 処理済み**（Fidenne が処理）・**実行中 · 処理なし**（PCM Direct）・**停止**・**準備中**・**エラー**。
- **音源** 行は現在音を出しているアプリ、**キャプチャ** 行は受信経路とレートです（音抜けがあると赤字になります）。**変換** 行は原曲と受信レートが一致しているかを示します。異なる場合は赤字で `44.1 kHz → 48 kHz · 再生アプリまたはmacOSが変換` と表示されます。Spotify は原曲レートを通知しないため `なしと推定` と記載します。
- **帯域** 行は入力された音がどの高さで途切れているかを計測します（例：`16.0 kHz より上に音がほとんどありません`）。なぜ途切れているかは判断しません（非可逆圧縮の場合も、オリジナルマスターの特性の場合もあります）。
- **DSP** 行のチップ（**EQ・Ostrum・Crossfeed**）は 1 つのボタンです。クリックするとその場で設定パネルが開き、もう一度クリックすると折りたたまれます。オン・オフの切り替えはパネル最上段、名前の横の**スイッチ**で行います（チップの点は状態表示に過ぎません）。PCM Direct の場合やエンジンが値を返さない場合はスイッチが薄く表示され、理由が併記されます。行末に `›` がある行はクリックするとその設定へ移動します。
- 出力デバイスがないか切断されると、その行が赤くなり **再検索**・**再接続** が表示されます。
- ステップを複数展開してウィンドウが画面より長くなると吹き出し内がスクロールし、直前に開いたステップが見える位置に追従します。リストの名前が長い場合（ヘッドホン・デバイス）、ポインタを乗せている間はスクロールして最後まで表示されます。

問題が起きるとウィンドウ上部に赤い案内バーが表示されます（例：`DACの接続が切れたため、再生を停止しました。再接続してから再生を押してください。`）。DAC が戻ると自動で閉じ、× で閉じることもできます。

### 2.2 下部再生バー

バーはすべてのページに表示され、ウィンドウ幅にかかわらず 1 行で高さも同じです：サービスアイコン・アルバムアート・曲（タイトル・ハート / アーティスト・アルバム）・再生ボタン（シャッフル・前へ・再生/一時停止・次へ・リピート） | ⋯・音量（スピーカー）・**次に再生**。ウィンドウを狭くするとアートワークが正方形になり、さらに狭くするとシャッフル・リピートがバーから外れて ⋯ メニュー内に入ります。エンジンスイッチと出力方式はバーではなくページヘッダ右端の **Playback Chain** ピルにあります（下記）。

- **再生位置** — 曲と再生ボタンの下にあるラインです。クリックまたはドラッグして移動します。ポインタを乗せるとラインが太くなり直上の行が薄くなり、ラインの両端の上に現在時間と残り時間が表示されます。
- **ハート** — Fidenne ライブラリの**お気に入りの曲**に入れます。サービスアプリのお気に入りとは別管理です。
- **サービスアイコン** — 現在音を出しているアプリです。名前なしでアイコンのみ表示され、ポインタを乗せると名前が出ます。クリックすると現在の曲をそのサービスで開きます（YouTube Music はそのブラウザタブ）。Spotify アプリがこの Mac にない場合は、アプリアイコンの代わりに Spotify の公式アイコンが表示されます（ライトモードでは黒、ダークモードでは白）。
- **Playback Chain ピル**（ページヘッダ右端） — 文字は `アプリ → 出力方式 → DAC`（狭いと DAC・アプリから省略されます）、点はエンジン状態です（緑 オン・灰 オフ・赤 エラー）。クリックするとウィンドウが開きます：最上部に **エンジン** スイッチ・**出力設定**（おすすめサウンドプリセット・保存したプリセット・手動設定）・音が通るステップ・**入出力・診断を開く**。保存したプリセットを選ぶとその出力方式に切り替わります。**Option** を押しながらクリックするとウィンドウを開かずにエンジンをオン・オフします。
- **⋯** — 曲メニュー（[§2.7](#27-曲メニュー---と右クリック)）に **スリープタイマー** と「出力設定…」（入出力ページの出力設定）が付きます。狭いウィンドウでは最上部にシャッフル・リピートもあります。
- **次に再生** — 次に再生・歌詞欄を開閉します。
- **前の曲** — Apple Music・Spotify で Fidenne のリストを聴いている最中に曲を 3 秒以上聴いていた場合は、前の曲ではなくこの曲の先頭に戻り、最初の 3 秒以内に押すと前の曲へ移動します（リストの最初の曲なら先頭に戻ります）。
- **DAC 音量** — バーのスピーカーボタンを押すとミュートし、もう一度押すと元に戻ります。ポインタを乗せると上にスライダーが表示されます。ボタンとスライダーは DAC 本体の音量を読み取って変更します（Fidenne が独自に作った音量ではありません）。デバイスから読み取った値のみが表示され、変更できない場合は `DAC音量を変更できませんでした。デバイスから読み取った値を表示します` と表示されます。スピーカーが薄い場合はポインタを乗せて理由を確認します — `DSD・整数出力中は、DAC本体のノブで調整します`（このとき Fidenne は DAC 音量の制御を引き継ぎ最大に保ちます）・`このDACは本体のノブで調整します`・`このDACの音量プロパティは読み取り専用です`・`出力の状態を確認している間は、音量を調整できません`。詳細：[トラブルシューティングガイド](TROUBLESHOOTING.md#dac-音量と-dsddop--整数-pcm)
- **エンジンスイッチ** — Playback Chain ウィンドウ最上部の **エンジン** 行にあります。Fidenne の処理（エンジン）をオン・オフします。ピルの点が状態です（緑 実行中・灰 オフ・赤 エラー）。エンジンがオフのままエラーがあると、バー右端に赤い ! が表示され、クリックすると入出力・診断ページが開きます。
  - **エンジンスイッチは曲を再生せず、再生ボタンはエンジンをオフにしません。** 一時停止は再生アプリのみを止め、エンジンがオフのときに **再生** を押すとエンジンをオンにして曲を再生します。
  - オンにしたときに何を再生するかは、入出力ページの **エンジン開始後** で決まります（[§7.3](#73-ストリーミングアプリの自動再生--入力と出力デバイス)）。
- シャッフル・リピートは Fidenne から再生したリストでのみ使用します。他のアプリのキューはそのアプリ側で操作します。
- 曲リストの **#**・**タイトル**・**アルバム**・**時間** ヘッダをクリックするとその列で昇順、もう一度クリックすると降順、さらにもう一度クリックすると元の順序になります（並べ替え中のヘッダに ↑ ↓）。ヘッダ枠のどこをクリックしても構いません。**#** はリストの元の順序に戻ります。リストの **並べ替え** メニューと同じ状態であり、再生は画面の順序に従い、アプリを終了するとリセットされます。
- ブラウザや他のアプリから新しく音が出ると、バーに **`システムサウンド — 出典不明`** と表示され、その間は再生履歴・歌詞を集計しません。
- 他のデバイス（スマートフォンなど）で Spotify を再生すると、バーには **`Spotify — 他のデバイスで再生中`** とだけ表示されます。操作はそのデバイスで行います。バーの後ろを通過するコンテンツで文字が読みにくい場合は、設定 › 一般 › **再生カプセル** でマテリアルを変更します（macOS 26 — macOS 15 ではカプセルが常に不透明なため隠れません）。

**大きい再生画面** — バーのアルバムアートをクリックすると開きます。3 カラム構成です：アートワークと再生操作・**次に再生** と **歌詞**・**Playback Chain**（ハンドル `›` または **⌥⌘P** で開閉）。**⌘F** はこの画面上で検索し、サービス名（`Apple Music ↗` など）は現在の曲をそのサービスで開きます。閉じるには ×、アートワークの再クリック、または **Esc**。

**アルバムモードのページ** — 大きい再生画面は上下に切り替える **今すぐ再生**・**動画**・**情報** の 3 ページです。**⌘** を押しながら 2 本指でスワイプまたはホイールを回すか、**⌥⌘↑**・**⌥⌘↓**、ページドット列の ▲・▼ で切り替えます。⌘ なしのスワイプとホイールはページ内のコンテンツをスクロールします。最後のページの次は最初のページです。最後に見たページは次回開いたときも記憶されます。動画・情報ページは **設定 › 外観 › アルバムモードのページ** で順序を変えたり非表示にしたりできます（今すぐ再生は常に最初）。動画・情報ページでアートワーク位置のボタン（**アルバムモードを終了**）を押すとアルバムモードを閉じます。

- **情報ページ** — 現在の曲のアルバム・リリース・ジャンル・トラック・長さ・音質を表示し、展開すると **クレジット** と音が通る経路が表示されます。サービスやファイルが通知する項目のみ表示され、曲が切り替わるときに事前読み込みします。再生バーの ⓘ からも開けます。
- **動画ページ** — 動画を探して再生し、曲に合わせることに特化した内蔵ブラウザです。**動画を検索、またはアドレスを入力** 欄にリンクを貼るか、動画ファイルをドラッグ＆ドロップするか、検索語を入力します。動画は消音状態で音楽の再生位置に合わせて進み、ページで **速度**・**動画の開始点** を選び、**動画のみを表示** で動画だけを大きく表示します。**この曲の動画として保存** は Apple Music・YouTube Music・ローカル曲に使った動画をこの Mac 内にのみ記憶し、次回その曲で自動的に開きます（Spotify の曲には紐付けません）。曲名で検索するには **設定 › 外観 › 動画** の **検索サイトを追加** で名前とアドレス（`{검색어}` を 1 回含む）を先に登録します。初期状態では登録されたサイトはありません。記憶した動画は同じ設定画面の **曲に記憶した動画を消去** で削除します。
- **動画のみを表示（大きい表示）** — 動画ページの **動画のみを表示** をクリックするとウィンドウが macOS フルスクリーンに入り、動画だけが大きく表示されます。再生カプセル・動画の角のボタングループ（**アドレスと履歴** の虫眼鏡と **動画のみの表示を終了**）・ページドット・アドレスバーが同時に現れ、同時に隠れます。ポインタを動かすと現れ、その上に静止している間は残ります。隠さないようにするには **設定 › 外観 › 動画** の **大きい表示では再生カプセルとボタンを自動で隠す** をオフにします。虫眼鏡はアドレスバーを開き、もう一度押すと閉じます（開いてもキーボード入力は奪わないため、欄をクリックするか ⌘L で入力します）。終了するには **Esc**（アドレスバーが開いている場合はそちらが先に閉じます）または **動画のみの表示を終了** をクリックします。入るたびに数秒間 `Escキーで動画のみ表示を終了します` が表示され、横の **今後表示しない** を押すと以降表示されません。フルスクリーンを手動で終了すると、動画のみを表示はウィンドウ内で継続します。
- **大きい表示の歌詞** — 動画ページで歌詞をどう表示するかを選びます：**歌詞欄(歌詞・次の曲)**（動画の横）・**映像の上に字幕**・**オフ**。**設定 › 外観 › 動画** と動画設定（歯車）ポップオーバーが同じ値を表示し、選ぶとすぐ適用されます。**オフ** ならフルスクリーンでも動画の横にアプリの歌詞は出ません。再生カプセルの歌詞ボタンは開いているそのページでのみ変更し、ページを閉じると設定値に戻ります。ヒント：ノートブックのような狭い画面では **映像の上に字幕** の方が動画をより大きく表示できます — 歌詞欄は幅を占有し、動画は元のアスペクト比を維持するためです。
- **動画の設定（歯車）** — 再生カプセルの歯車（**動画の設定**）から **この曲の動画として保存**（保存すると **この曲の動画として保存済み** の塗りつぶされたブックマークに変わり、もう一度押すとこの曲の保存のみ解除されます — ページと再生はそのまま）、**動画を今の曲の位置に合わせる**（表示中の動画を曲の現在位置へ移動して追従させる）、**追従**（**落ち着いて**：わずかなズレは 30 秒ほど様子を見てから合わせることで動画が飛びにくくなります / **すぐに**：即座に合わせます）、**大きい表示の歌詞**、**この曲の歌詞を翻訳**、**新しい動画は再生位置に追従して開始** を選びます。**速度** 行は **曲と一緒に再生・停止** をオフにしたときのみ表示されます（オンにしておくと 1 倍速で固定）。

**次に再生と Apple Music** — Apple Music は次の曲リストを他のアプリに通知しません。

- Fidenne から Apple Music のリストを再生すると、ミュージックライブラリの **「Fidenne 재생 대기열」** と **「Fidenne 再生キュー 2」** プレイリストを交互に使用します。現在の曲とリストの残りの曲を順番に入れます。初めて使う前に一度確認が出ます（**続ける**・**オフにして続ける**）。iCloud ライブラリをオンにしていれば他のデバイスのミュージックにも表示されます。オフにする場所は 設定 › プライバシー › Apple Music の **曲の切り替えにFidenneのプレイリストを使う** です。
- ミュージックアプリで直接再生した曲は、Fidenne がその曲がどのプレイリスト・アルバムから来たかを読み取って次の曲を表示します。分からない場合は **このアルバムの続きを聴く**・**Fidenneのリストに戻る**・**Apple Musicの自動再生に任せる** が表示されます。
- ミュージックが自動で別の曲を再生すると **`Apple Music 自動再生が選んだ曲`** と表示されます。Fidenne のリスト全体がミュージックのプレイリストに入っているため、リストが終わる前であれば自動再生（∞）がオンでもこのようなことは起きません。それでも発生する場合は自動再生（∞）をオフにします。

**Apple Music を Fidenne から再生操作する場合、ミュージックアプリでオフにしておくこと**

- **自動再生（∞）** — ミュージックの「次に再生」リスト上の ∞ ボタン。Fidenne リストが終わった後にのみ曲を選びます（「現在のプレイリストが終了したら Apple Music の自動再生で続きを聴く」をオンにしていればそのとき続きを聴きます）。
- **シャッフル・リピート** — ミュージック側はオフにし、必要であれば Fidenne バーのシャッフル・リピートを使います。
- **曲の切り替え（AutoMix・クロスフェード）** — ミュージック › 設定 › 再生。曲と曲が重なると曲の切り替わりが曖昧になり、曲送りやレート合わせがズレることがあります。
- 音を事前に加工するもの（**サウンドチェック**・**イコライザ**・**サウンドエンハンサー**）もオフにすることを推奨します。Fidenne が整える前に音が変わってしまいます。

### 2.3 歌詞

曲を再生すると歌詞欄に歌詞が表示されます。インターネット歌詞（lrclib.net）は最初に一度同意が必要です — 「同意して検索」 / 「送信しない」。送信するのは曲のタイトル・アーティスト・アルバム・長さだけです。

| 操作 | 動作 |
|---|---|
| **歌詞ファイルを関連付ける** | LRC・TXT ファイルをこの曲に関連付けます（解除可能）。 |
| **歌詞のタイミング**（時計ボタン） | 時計ボタンを押すと開きます。歌詞が早ければ +、遅ければ −。この曲にのみ適用され記憶されます。 |
| **テキストを関連付ける** | タイムスタンプのない歌詞ファイルのテキストを、現在の歌詞のタイミングに合わせます。 |
| **韓国語翻訳** | 原文の行の下に韓国語の行を付けます。韓国語歌詞のバージョンがなければ翻訳で埋めます。翻訳は有効にした AI 歌詞翻訳 → Mac 内の Apple モデル → macOS 翻訳 → 原文の順で試行します（サイドバー **歌詞タブ** の **翻訳の手順**、[§8](#8-設定ウィンドウ)）。 |
| **発音行** | 原文の下に読み方を文字で表示します。サイドバー **歌詞タブ** の **表示 › 行の順序・表示** で **発音** 行の目のアイコンをオンにすると表示されます（初期状態はオフ）。韓国語画面では日本語・中国語歌詞の発音がハングルで、それ以外の画面言語ではローマ字（日本語）・ピンイン（中国語）・ローマ字表記（韓国語）で表示されます。韓国語画面で韓国語歌詞には発音行はありません。発音は macOS が読み取った**推定**のため（`発音の行は推定です`）、漢字の読みや音便が誤ることがあります。歌詞タブで行をクリックして手動で修正すると（Return で保存、Esc でキャンセル）`自分で直した発音` として残ります。 |
| **行の順序** | 原文 → 発音 → 翻訳が基本で、項目をドラッグするか ⌥⌘↑・⌥⌘↓ で順序を変えます。目のアイコンで行ごとに表示・非表示を切り替えられ、少なくとも 1 つは表示する必要があります。この順序は歌詞画面・アルバム画面に適用され、歌詞タブは翻訳を修正する場所のため翻訳列が常に表示されます。 |
| **歌詞のバージョン** | バージョンが 2 つ以上あるときに現れ、見つかったバージョン（原文・ローマ字・英語・韓国語など）を選びます。他のバージョンは出典行の **他のバージョン** から探します。 |
| 更新（↻） | もう一度検索します。 |

- 文字サイズはサイドバー **歌詞タブ** の **表示** で決めます（小・標準・大）。
- **発音の表記・読みの表示** — **歌詞 › 表示** の **発音の表記** でアプリ言語に従う・ハングル・ローマ字・かなを選びます（かなは日本語歌詞）。**読みの表示** を **文字の上** または **両方** にすると、日本語歌詞の漢字の上に小さなかなで読みが付きます。発音行がオンのときのみ適用され、初期値の **行で** は従来どおりです。どちらも推定です。
- **フローティング歌詞** — 他のアプリを使っている間、現在の行と次の行を小さなウィンドウで表示します。**再生メニュー › フローティング歌詞**（**⇧⌘L**）またはサイドバー **歌詞タブ** の **フローティング歌詞** でオン・オフします。同じ場所で **常に手前に表示** と **背景の不透明度** を選び、角をドラッグしてサイズを変えます。発音・翻訳行は歌詞タブの行の順序に従います。
- **歌詞サーバーが拒否したとき** — `歌詞サーバー（LRCLIB）がリクエストを一時的に拒否しました。短時間にリクエストが多い場合に発生します。約 N 分間は再リクエストしません — 設定で歌詞検索をオフにしてからオンに戻すとすぐ再開します。` と表示されます。待つか、LRC・TXT ファイルを関連付けます。
- **歌詞タブ** — サイドバー一番下の行です。聴いた曲の歌詞と翻訳をまとめて閲覧する場所です。最上部のチップ（**すべて・Apple Music・Spotify・YouTube Music・ローカル**、YouTube Music チップは 設定 › 一般 の **YouTube Music（実験的機能）** をオンにしたときのみ表示されます）でリストをサービス別に絞り込み、検索は選んだチップ内で行います（検索はその曲の別バージョンのタイトル・アーティストも対象です）。曲を選ぶと原文と翻訳が行ごとに並んで表示され、翻訳行はクリックして修正できます。その下に設定が 4 グループあります — **表示**（文字サイズ・翻訳行・翻訳言語・口調・追加指示）・**翻訳の手順**（AI プロバイダ → Mac 内の Apple モデル → macOS 翻訳、折りたたまれた **AIプロバイダ設定** にキーと上限）・**歌詞の出典**・**保管**。歌詞と翻訳はこの Mac に残り、アプリが自動で削除することはありません。以前保存しておいた歌詞も、その曲を再び再生するとこのタブに載ります — 記録番号がなかった昔の lrclib.net の歌詞は、その曲が再生中のときに歌詞インターネット検索がオンになっていれば（歌詞ウィンドウが閉じていても、どのサービスの曲であっても）、一度番号を問い合わせて保存済みの翻訳と一緒にリストに表示します。
- **翻訳を削除** — AI で作成した翻訳は歌詞の下の **この翻訳を削除** で 1 曲ずつ、設定の **AI翻訳をすべて削除…** でまとめて削除します。
- **以前の翻訳** — **AI翻訳を再試行** で翻訳が変わると、変わる前の翻訳は **以前の翻訳** に残ります。以前の翻訳を選んで（`以前の翻訳に戻しますか？`）戻し、取り消すでキャンセルできます。手動で直した行も一緒に変わり、AI プロバイダを使った場合はすでに消費したリクエスト費用は戻りません。
- 曲の表記がアプリごとに異なっても（韓国語アーティスト名・「- Remastered」など）、タイトル・長さ・アーティストまたはアルバムが一致すれば見つかります。タイトルと長さだけが同じ他人の曲は表示しません。

### 2.4 メニューバーアイコン・メニュー

- **メニューバーアイコン**（波形） — 状態・開始・停止・再生/一時停止・ウィンドウを開く・出力デバイス・**EQ プリセット ▸**（最近 5 つ、選ぶとすぐ聴こえます）・終了。開始・停止はエンジンスイッチと同じです。
- **スリープタイマー** — 再生メニュー・メニューバーメニュー・再生バーのメニューから **15分・30分・45分・60分・この曲が終わったら・直接入力…**（1 ~ 720 分）のいずれかを選びます。終了時に一時停止を一度押したのと同じように止まり（音はそのサービスの一時停止と同様にフェードアウトします）、再開したりプレイリストを消したりしません。残り時間がある間はメニュータイトルに `スリープタイマー · ○分残り` が表示され、**タイマーをオフ** で解除します。手動で一時停止や再生をしてもタイマーは継続し、アプリを終了すると消えます。3 サービスとローカルで共通です。
- **音量・ミュート** — 再生メニューの **音量を上げる**（⌘↑）・**音量を下げる**（⌘↓）・**ミュート**（⌥⌘↓）。音量バーは Esc で閉じます。
- **ショートカットとリンク** — ショートカットアプリ・Siri・Spotlight から Fidenne の 6 つのアクションを呼び出せます：**再生/一時停止**・**次の曲**・**前の曲**・**現在再生中の曲**（タイトル・アーティスト・出典をテキストで返す）・**サウンド処理をバイパス**（オン / オフ）・**EQプリセットを選ぶ**。**サウンド処理のバイパスをオンにする** はオンになっていた EQ・Ostrum・クロスフィードのみをオフにし、保存した設定は変えません。**オフにする** はそのときオフにしたものだけを元に戻します（アプリを再起動すると記憶がないため戻すものがないと応答します）。`fidenne://play-pause`・`fidenne://next`・`fidenne://previous`・`fidenne://bypass?on=1`・`fidenne://preset?name=名前` リンクも同じ動作をします。出力デバイス・音量・出力方式・エンジン開始/停止・設定・削除はショートカットにもリンクにもなく、それ以外のリンクは受け付けません。同じリンクを 1 秒以内に 2 回受け付けず、10 秒間に 10 回を超えません。アプリが終了していればショートカットがアプリを起動します。
- **アイコンを隠す** — **システム設定 › メニューバー › メニューバーで許可** から Fidenne をオフにします。隠してもウィンドウ・Dock・ショートカットキーはそのまま使えます。
- **アプリメニュー** — 「Fidenneについて」（商標案内を含む）、**アップデートを確認…**。アップデート確認は公開リポジトリを一度読み込み、「最新です」または新バージョンを通知します（まだ公開されたリリースがなければその旨を通知します）。新バージョンなら変更点が数行一緒に表示されます。初回起動時に GitHub 接続をオンにしていれば、押さなくても 4 時間ごと（起動時とスリープ解除時にも）自動でチェックして新版を通知します。アプリが背面にいる場合は新バージョンごとに一度通知バナーが出て、クリックするとアップデートウィンドウが開きます（ネットワークの送信先一番下のスイッチでオフにできます）。新バージョンはアップデートウィンドウでインストールを選んだときのみダウンロードします。取得した版は署名を確認した後にのみインストールし、Fidenne を再起動します。アップデートの確認とダウンロードは github.com が `release-assets.githubusercontent.com` へリダイレクトする場合があり、このリダイレクトはアップデートツール（Sparkle）が直接追従します。詳細：[プライバシー](../../../PRIVACY.ja.md)。
- **ヘルプメニュー** — **操作のヒントを表示**・**問題報告用の診断を作成…**（[§10](#10-サポートファイルの送信)）。**診断メニュー** — 診断記録の開始/停止・**サポート用の診断を書き出す…**・**保存した診断を削除…**。
- 元に戻せない削除（保存した診断・プレイリスト・ショートカット「すべてデフォルトに戻す」）は一度確認が出ます。赤いボタンは Return では押されません。
- **ショートカット** — 一覧は 設定 › **操作とショートカット** にあります。キーごとに変更・削除・デフォルト。macOS のショートカットと重なると通知します。Fidenne ウィンドウが前面にあるときのみ動作します（メディアキーは例外）。
  **⌘S** は画面に表示されている Equalizer や Ostrum を保存し、**⌘F** はライブラリ・再生履歴ではそのページの検索欄へ、他のページでは音楽検索欄へ移動します。
  EQ・Ostrum をオン・オフするキーはすぐ音に反映されますが保存はしません。

### 2.5 説明・グラフの見方・用語解説

- セクション見出しの下の 1 行がその機能の役割です。行末の **ⓘ** をクリックすると吹き出しが開き、いつ使うのか・何を入力するのか・変えると何が変わるのか・トレードオフ を表示します。**Esc** または外側をクリックすると閉じます。
- 説明内の **用語解説 (n)** はその部分の用語を、**用語集をすべて表示** は IR（インパルス応答）・コンボリューション（畳み込み）・トゥルーステレオを含むアプリの用語集すべてを表示します。グラフごとにすぐ下に横軸・縦軸と線の名前が常に表示されています。その行末の **ⓘ** に各線の意味、読み方、このグラフから分からないことが書かれています。
- アプリ内の数値は測定から転記したものであり、どの設定が音を良くするかという判定は行いません。

### 2.6 ノブ・スライダー・EQ ポイントの操作

EQ と Ostrum を初めて開くと、操作部の横に **EQ の操作**・**ノブの操作** のヒントが一度表示されます。もう一度見るには **ヘルプ › 操作のヒントを表示**、または 設定 › 操作とショートカット › **ヒントを再表示**。

| 操作対象 | 操作方法 |
|---|---|
| ノブ（Ostrum） | 上下・左右にドラッグします（上 = 大きくなる）。ノブをクリックした状態で矢印キー（← ↓ 減らす、→ ↑ 増やす）でも調整できます。**Shift**・**⌥** で微調整。**ダブルクリック** または ⌥-クリックで初期値。数値をクリックすると直接入力できます。 |
| EQ スライダ | クリックまたはドラッグで上下します。**ダブルクリック**・⌥-クリックで 0 dB。 |
| EQ 数値欄 | クリックして入力し **Return**。横の矢印は 1 ステップずつ。⌥-クリックで初期値。 |
| グラフ上のポイント（EQ） | ドラッグすると周波数とゲインが同時に変わります。**Shift**・**⌥** で 10 倍ゆっくり。ポイントをクリックすると選択状態になり、横の小さな輪を横にドラッグすると Q。空き領域をダブルクリックするとバンドが追加されます。 |
| 再生位置・その他のスライダー | クリックまたはドラッグします。 |

- **2 本指スクロール** は常にページをスクロールします。値はポインタを操作部の上に置き **⌘ を押しながら** スワイプしたときのみ変わります（上にスワイプで増加）。⌘ と一緒に ⌥・Shift を押すとゆっくり変わります。マウスは ⌘ を押しながらホイールを回します（横置きのスライダーは ⌘ + Shift + ホイール）。変更方式は 設定 › 操作とショートカット › **2本指のスクロールで値を変更**（⌘ を押しながら・操作部の上から始めたら・オフ）から選びます。
- **トラックパッドの触覚フィードバック** — 設定 › 操作とショートカット で **オフ・両端のみ・一般**。Force Touch トラックパッドでドラッグするときに 1 ステップごとに軽く振動します。
- **ストリーミングページの戻る・進む** — ‹ › ボタン・⌘[ ⌘]・トラックパッド横スワイプと **マウスのサイドボタン**（戻る・進む）は同じ移動です。サイドボタンは Fidenne ウィンドウが前面にあるときのみ動作します。
- **⌘Z / ⇧⌘Z** — DSP ページで変更した内容を 1 ステップずつ元に戻し・やり直します（1 回ドラッグした全体が 1 ステップ）。元に戻した値もすぐ音に反映されます。

### 2.7 曲メニュー — ⋯ と右クリック

曲が 1 行で表示される場所（音楽・次に再生・ライブラリ・再生履歴）で、行末の **⋯** または **右クリック** は同じメニューを開きます。その行で実行できない項目は表示されません。

1. **再生**・**次に再生**・**キューの最後に追加**
2. **プレイリストに追加 ▸**・**歌詞を表示**・**曲の情報**・**Apple Musicで開く**・**再生アプリで表示**・**Finderで表示**・**リンクをコピー**（開く先が 2 つ以上ある場合は **他のアプリで開く ▸** にまとまります）
3. **プレイリストから削除…**（一度確認し、ファイルはそのまま）・**キューから削除**

Spotify の曲には **Spotifyで開く**・**リンクをコピー** があります。

**行の選択** — 曲リストの行は 1 回クリックすると選択し（再生しません）、ダブルクリックまたは Return で再生します。行にポインタを乗せると現れる ▶ は 1 回クリックで再生します。⌘-クリックで 1 つずつ追加・除外し、⇧-クリックで範囲を選択し、文字を打つとそのタイトルへ移動します。複数行を選ぶとメニューには複数曲に合う項目だけが残ります（**プレイリストに追加** は同じサービスの曲のときのみ）。Fidenne リスト・次に再生では Delete で外し、⌘Z で元に戻せます。Apple Music・Spotify・YouTube Music が所有するリストでは Delete は何もしません。3 サービスとローカルで共通です。

## 3. ストリーミングページ

Apple Music・Spotify・YouTube Music を 1 か所で検索して開く場所です。

- **オートメーション許可の案内** — `システム設定の「プライバシーとセキュリティ」>「オートメーション」で Fidenne の Apple Music へのアクセスを許可してください。`（Spotify は `Fidenne の Spotify へのアクセスを…`）が表示されたら、その画面で Fidenne のミュージックまたは Spotify をオンにします。オンにして Fidenne に戻るとリストを再読み込みし、案内が消えます。最初に尋ねるダイアログで許可しなかった場合でも、後から同じ場所でオンにできます。
- **サービスの選択** — サイドバー **ストリーミング** の下の **Apple Music**・**Spotify**・**YouTube Music** をクリックします（YouTube Music はオンにしたときのみ表示されます）。ページヘッダのサービス名横の点は接続状態と接続ウィンドウです。YouTube Music には [§8.1](#81-youtube-musicを使うchrome拡張機能) の拡張機能が必要です。
- **検索** — 結果は 1 画面に順番に表示されます：自分の Apple Music（ライブラリ・プレイリスト） → Apple Music カタログ（ライブラリにない曲） → この Mac のファイル。一番下の **YouTube Music で「検索語」を探す ↗** は YouTube Music タブで同じ検索を開きます。自分のライブラリを絞り込む検索（Apple Music・Spotify・YouTube Music）はスペースを無視します — `동트기전` でも `동트기 전` が見つかります。**ライブラリに追加** した曲が現れるまでは数分待つことがあります。
  - **Spotify の結果は別に**表示されます — 結果ヘッダの **Spotify** タブをクリックし、**Apple Music · ローカル** タブで戻ります。Spotify が自社コンテンツを他サービスの結果の横に並べないよう定めているためです。
  - **ライブラリに追加** — カタログの曲・アルバムを Apple Music ライブラリに入れます。最初に一度確認ダイアログが出ます（ライブラリが変更され、iCloud ライブラリなら他のデバイスにも表示されます）。表示されるまで時間がかかり「ライブラリに表示中」と出たあと **再生** に変わります。
- **順序を調整** — 開いたプレイリスト・アルバムの再生行にある **順序を調整** ボタンを押すと曲の行をドラッグして順序を変えられ、行ごとに **上へ移動**・**下へ移動**（キーボードは ⌥↑・⌥↓）もあります。終わったら **完了** を押します。この間 **#** 列が自分が決めた順序の番号になり、⌘Z で 1 歩ずつ元に戻せます。Fidenne 内の順序だけが変わるため、Spotify・Apple Music・YouTube Music のプレイリストの順序はそのままです。曲が 2 曲未満、またはリストがまだ読み込み中の場合はボタンが薄くなります。順序を保存できないと `順序を保存できなかったため、前の順序に戻りました`、順序ファイルを読めないと `順序ファイルを読み込めないため、順序を変更できません` と表示されます。
- **アルバムをライブラリに保存** — アルバムヘッダの **ライブラリ** ボタン（すでに保存したアルバムなら **保存済み**）でサービスに保存または削除します。保存方式はサービスごとに異なります。
  - **Spotify** — アプリが Spotify に保存をリクエストし、再読み込みして確認した結果だけを表示します。保存権限がないと `アルバム保存の権限を許可するには、Spotifyに再接続してください。` が出るので、Spotify 接続ウィンドウ（ストリーミングページの Spotify 横の点）で **Spotifyを接続** をやり直します。
  - **Apple Music** — iCloud ライブラリに入れます。リクエストが受け付けられると `ライブラリに追加しました。ミュージックアプリに表示されるまで少し時間がかかることがあります。` と表示され、アプリがしばらくして数回再確認し、見つかれば **保存済み** になります。最後まで見つからなくても `ミュージックにはまだ表示されていません` とだけ表示し、失敗とは断定しません。権限・サブスクリプション・iCloud ライブラリがない場合は理由を 1 文で通知し、ボタンはミュージックアプリでアルバムを開く動作に戻ります。
  - **YouTube Music** — アプリが直接保存はしません。拡張機能が開いている YouTube Music アルバムページの保存コントロールを一度クリックし、ページが示す結果を通知します（**YouTube Musicに保存**）。そのアルバムページがブラウザで開いている必要があり、確認できない場合は `保存されたかどうかを確認できませんでした。YouTube Musicで確認してください。` と通知し、再クリックはしません。曲単体も同じ方法で保存します。
- **曲をクリック** — **次に再生** / **今すぐ再生**。検索結果の曲行も同じです。現在 Fidenne が再生しているリストがあるときのみ **再生方法** を尋ね、そのようなリストがなければ（例：ミュージックアプリから始めた曲だけ流れている最中）尋ねずにクリックした曲をすぐ再生します。リスト上の **すべて再生**・**シャッフル** はリストを 1 周重複なく再生します。Apple Music の長いリストは最初に **再生を準備中…** が少し表示されることがあり、シャッフルで聴くには再生前に **シャッフル** をオンにします。
- **最初の画面** — 上から **続きを聴く**（横にその日の **今日の再生** カード）、**今日聴いた曲**（表示日が今日でなければ **最近聴いた曲**）、**自分のプレイリスト**、**以前よく聴いた曲**。続きを聴くカードの ▶ はそのカードのサービスと曲を再生し、保存された位置があればその位置から続けます。カードはそのサービスのプレーヤーが現在保持している曲（再生中または一時停止中の曲）に追従し、同じ曲が再生中なら ▶ が ⏸ に変わります。**リストを開く** はその曲を聴いたリストを開きます。
  - **今日聴いた曲** は過去 7 日間（今日を含む）に聴いた曲を横に送って見る 1 行です。1 日は午前 4 時に切り替わり、日付が変わる場所に線が表示されます。行頭の日付チップ（**今日・昨日・過去7日間・曜日**）は現在表示している日を濃く表示し、クリックするとその日へ移動します。昨日より古い日を見ている間、**過去7日間** チップは曲がある日の曜日まで展開して表示します。行のタイトルは現在表示している日に応じて **今日聴いた曲** と **最近聴いた曲** に切り替わります。曲タイルは曲リストの行のように 1 回クリックすると選択のみ行い、ダブルクリックまたは選択後に Return を押すと再生します（**以前よく聴いた曲** のアルバム行も同じです）。グループタイルは 1 回で展開・折りたたみされます。1 つのプレイリスト・アルバムから続けて聴いた曲は 1 枠にまとまり、枠の矢印をクリックすると曲が展開されます。
  - 行末の **すべて表示 ›** は別画面へ移動せず、その場で過去 7 日間をグリッド状に展開します。同じタイルが日付ごとに 1 行ずつ並び、グループタイルはクリックで展開・折りたたみされます。展開している間、行ヘッダ（タイトル・**折りたたむ**・**統計 ›**）と日付チップはページを下にスクロールしても最上部に固定されるため、どこからでも **折りたたむ** を押したりチップでその日へ移動したりでき、手動でスクロールするとアクティブなチップが追従します。曲タイルをダブルクリックするとその曲から画面の順序通りに連続再生し、折りたたまれたグループはスキップします。**統計 ›** は再生履歴ページを開きます。
  - **今日の再生** カードはその日の出力方式・デバイス・途切れを表示し、折りたたんだり展開したりできます。計測できなかった日には途切れの行は表示されません。再生統計には Spotify で聴いたものは入りません。
  - **セクションの順序と非表示** — セクションヘッダのハンドルをドラッグして順序を変えます（ハンドル上で ⌥↑・⌥↓ も可能です）。目のアイコンボタンはセクションを隠し、隠したセクションは一番下の **<名前> を再表示** で復元します。プレイリストタイルもドラッグして移動できます。変わるのは Fidenne 内の順序だけで、サービスのプレイリストはそのままです。
  - **ドラッグしてプレイリストに追加** — 曲タイル・展開されたグループ内の曲・プレイリストグループ・**個別に聴いた曲** グループをドラッグして（4 pt 以上）**自分のプレイリスト** の Fidenne プレイリスト・**お気に入りの曲**・サービスプレイリストタイル、またはタイムラインのプレイリストグループにドロップすると、ダイアログなしですぐに追加されます。コピーのみ行い、リスト同士を結合したり移動したりはしません。受け入れ先は強調リングと `「名前」に追加` のラベルが表示され、受け入れない場所（**個別に聴いた曲** グループ・アルバム・ラジオグループ・曲タイル・日付チップ・空き領域・自分自身・書き込み不可リスト）は禁止カーソルと理由が 1 行表示されます（`ここにはドロップできません`）。曲がすでにすべて入っていれば `すでにあります` です。追加するとトーストと **取り消す**（10 秒、⌘Z）が出ます。サービスプレイリストにはそのサービスの曲のみが入り、Spotify は自分が作成したか共同編集のリストに初回一度 **許可…** を押してから書き込み、Apple Music はミュージックアプリが起動しているときに通常のプレイリストにのみ追加されます。YouTube Music のサービスプレイリストは受け付けません。**サービス側に書き込んだものは元に戻すボタンがなく**、`サービス側で直接削除できます` と通知します。サービスプレイリスト・アルバムの曲行と「次に再生」リストも同じドラッグを受け付けます。
  - **この日の別のグループにまとめる** — 同じサービス・同じ日の曲を 1 つのグループにまとめます。ドラッグではなく曲タイルの ⋯ メニューにのみあり、まとめられる同じ日のグループがあるときに表示されます。手動でまとめたグループは同じ日の中で 2 曲から 1 つのグループとして表示され、その後に新しく聴いた曲は自動では合算されません。ホームが見る履歴にのみ適用され、再生履歴は変わりません。
  - **履歴から削除** — 曲タイルの ⋯ メニュー（またはタイルを選んで ⌫）から、その曲の再生記録をホームから削除します。`履歴から削除しました` と **取り消す**（10 秒、⌘Z）が表示され、グループは `このグループを履歴から削除しますか？` と一度確認が出ます（デフォルトボタンは **キャンセル**）。ホームから消えるだけで **統計からは削除されません**（`統計からは削除されません`） — 完全な削除は再生履歴ページの **再生履歴を削除** です。YouTube Music ホームでも同様に削除されます。
  - ドラッグで行うことはすべてドラッグなしでもできます — ⋯ メニューの **プレイリストに追加 ▸**、キーボード（←→ でタイル移動、メニューキーで ⋯ メニュー、⌫）、VoiceOver のカスタムアクション（**プレイリストに追加**・**この日の別のグループにまとめる**・**履歴から削除**）。
  - **ライブラリのアルバム** — **自分のプレイリスト** の一番上（Fidenne リストの次、サービスプレイリストの前）に **ライブラリのアルバム · 54** のような 1 枠があります。カバーは先頭 4 アルバムのモザイクで、クリックするとその場でアルバムが続いて展開され（クリックするとそのアルバム画面）、もう一度クリックすると折りたたまれます。保存したアルバムがなければ枠はなく、最初に読み込んでいる間は「読み込み中…」の 1 行だけが表示されます。3 サービス共通で、Spotify は接続されているときのみ表示されます。開いた状態はアプリを起動している間、サービスごとに記憶されます。

**Spotifyを接続（任意）** — キーがなくても Spotify アプリで曲を選べば Fidenne がサウンドを整え、現在の曲を表示します。検索・プレイリスト・再生操作は **自分の Spotify デベロッパアプリのキー** と Spotify Premium アカウントがある場合のみ有効になり、その規約はユーザーが自ら同意したものです。

接続画面には `接続すると、利用規約第9条（Spotify）に同意したことになります。` が表示され、すでに接続済みの方には同じ案内が一度表示されます。Spotify から取得した情報はこの Mac にのみ最大 30 日間保管されます。**接続を解除** をクリックすると確認を経てトークンを即座に削除し、この Mac の Spotify 情報（再生履歴内の Spotify の曲・Fidenne リスト・曲の関連付け・キャッシュ）は 4 日間非表示にした後に削除します。Spotify で聴いた曲は再生統計から除外され、Spotify が通知した露骨な表現マーク（`E`）は他のサービスと同じ位置に表示されます。Spotify のアートワーク上にはボタンを乗せないため、アートワークをクリックして開きます。ホームと再生履歴の Spotify アートワークは曲ごとに 1 つずつ取得し、取得できなかった曲は灰色のプレースホルダーにして再試行します。アートワークがブロックされても Spotify ライブラリの読み込みはブロックされません。接続途中でログインウィンドウを閉じても、すでに接続されている状態はそのまま残ります。

1. ストリーミングページの Spotify 横の点（または Spotify 画面の **接続**）を押して開く接続ウィンドウの **デベロッパダッシュボードを開く** をクリックし、アプリを 1 つ作成します。

4. **キーを確認** をクリックし、問題なければ **Spotifyを接続** をクリックします。ブラウザの Spotify ログインウィンドウが開きます。

接続後は「再生の権限を更新」・「接続を解除」が表示されます。**Spotifyのキューに従う・Jam用** をオンにすると、Fidenne が Spotify の共同キューを上書きしません。

**確認方法** — 曲をクリックすると下部バーに曲名とサービスアイコンが表示され、再生位置が動きます。

**ストリーミング最初の画面のサービス枠** — 選んだサービスがコンテンツを提供すると「プレイリスト」枠の次にサービス枠が表示されます。Apple Music はおすすめ・チャート・最近の再生、Spotify は最近の再生・よく聴く曲・保存したアルバムなどの枠です。接続と権限がある枠のみ表示され、枠のヘッダで順序を変えたり隠したりできます。枠の曲と Apple Music ステーションタイルは 1 回クリックで選択しダブルクリックで再生、Spotify アルバム・プレイリストタイルはアプリ内のリストページを開き、Apple Music から取得した枠のその他のタイルはミュージックアプリのそのページを開きます。ライブラリにない Apple Music の曲は **ライブラリに追加してFidenneで再生** で追加して再生します。Spotify・ローカル検索結果は **もっと見る** で続けて表示します。リストタイルを別の Fidenne プレイリストタイルの上にドラッグすると曲をまとめて追加し、同じ枠のタイル間にドロップすると順序が変わります。Fidenne で別に集めたお気に入りリストの名前は **Fidenneのお気に入りの曲** です。

**リストの最後** — Fidenne が保持しているリストで「次へ」を押すと最後の曲の次は最初の曲になり、「前へ」を押すと最初の曲の前は最後の曲になります。自動で終了したリストで再生を押すと最初から再生し、リストが自動で終了する場合はそのまま停止します。YouTube Music は Fidenne リストの曲を最後まで聴いて次の曲に進みます。リストの後を YouTube Music の自動再生で続けて聴くには、リストの **現在のプレイリストが終了したら YouTube Music の自動再生で続きを聴く** をオンにします。

## 4. ローカルページ

この Mac の音楽ファイルを聴く場所です。読み込む形式：WAV・AIFF・FLAC・ALAC・AAC・MP3・Opus（macOS が読み込める場合）。`.ogg`・`.oga` はまだ再生できません。

1. 最初は **フォルダを追加…** をクリックして音楽フォルダを選びます。
2. インデックス作成が終わったら **曲・アルバム・アーティスト・プレイリスト** から曲を探します。
3. 行をダブルクリックするか、選択後に Return を押すとその曲から再生します。

**確認方法** — 曲の行にアートワーク・タイトル・形式（例：FLAC · 96 kHz · 24ビット）・長さが表示され、ダブルクリックまたは Return を押すと下部バーにその曲が表示されます。

- **マルチチャンネルファイル** — ファイルが配置を明示している 5.1・7.1・7.1.4 ファイルは、マルチチャンネル出力デバイスへ処理なしでそのまま送ります（EQ・フィルター・ダウンミックスなし、レートはファイルのまま）。再生ピルに **マルチチャンネルそのまま · 5.1 · 48 kHz** のように表示され、ライブラリ行にもチャンネル構成が記されます。デバイスにスピーカーが足りないかレートを合わせられない場合は理由を通知して再生しません。別の配置のファイルは **このチャンネル構成は再生しません** と薄く表示されます。マルチチャンネル入力プラグインをオンにしておくとそのプラグインを通過します（[§6.9](#69-プラグインページ)）。
- **音楽フォルダ** メニュー — フォルダを追加…・**再インデックス**・リストからフォルダを削除 ▸（リストから外すだけでディスク上のファイルはそのまま）。
- **曲** — 検索欄（⌘F）で現在のリストを絞り込みます。再生できないファイルは形式の位置に理由（`破損したファイル` など）が表示されます。**アルバム・アーティスト** はファイルタグでまとめます。
- **プレイリスト** — 名前を入れて作成します。中で すべて再生・シャッフル・削除…（プレイリストのみ削除しファイルはそのまま）。「ファイルが見つかりません」はフォルダが外れたかファイルが移動された状態です。
- **複数曲の選択・並べ替え**（プレイリスト・次に再生） — ⌘-クリック・Shift-クリックで選び、行をドラッグして別の行の上にドロップすると移動します。**Return** は選んだ最初の曲を再生します。
- **次に再生** — 下部バーの **次に再生** ボタンで現在の曲と続く曲を表示します。同じレートの曲はギャップレスでつなぎ、レートが変わる箇所ではわずかに途切れます。
- ローカルファイルは Fidenne エンジンで再生します。PCM Direct では音源レートを維持し、サウンド処理をバイパスしてディザをオフにします。

**YouTube Music プレイリスト** はこのページではなく `ストリーミング › YouTube Music › 自分のプレイリスト` に集まります。読み込む方法は 2 つあります — ブラウザでリスト画面を開く（[§8.1](#81-youtube-musicを使うchrome拡張機能)）、Google テイクアウトファイル（[§4.1](#41-youtube-music-プレイリストの読み込み)）。Fidenne は YouTube Music サイトを自動で巡回して読み取ることはありません。読み込んだ曲行でできること：

- **種類** — 曲ごとに 曲・`ミュージックビデオ`・`音楽の動画`・`音楽ではない`・`種類不明` のいずれかとして扱います。初期状態では **`音楽ではない` のみ除外されます**。
- **追加・削除** — 行末のボタンで切り替えます。**除外された項目を表示** をオンにすると外れた曲も表示されます。選んだ状態は再読み込みしてもそのまま残ります。
- **曲メニュー** — **YouTube Musicで開く**・**リンクをコピー**・プレイリストに追加/削除。これらの曲は YouTube Music タブで再生されます。

### 4.1 YouTube Music プレイリストの読み込み

5. ダウンロードした zip を Finder でダブルクリックして解凍します。
6. Fidenne `ストリーミング › YouTube Music › 自分のプレイリスト` 一番下の **YouTube Musicライブラリ** を展開し、**YouTube Musicのプレイリストを読み込む…** → 解凍した `Takeout` フォルダをまるごと選びます。

## 5. 再生履歴ページ

このMacで聴いた履歴を確認する場所です。自動的にアップロードされることはなく、手動での書き出しのみに対応しています。

- **1回の基準** — Fidenneが開いている間に実際に30秒、または曲の長さの半分（短い方）再生されたもの。アプリが閉じている間の記録はありません。
- **ホームから削除した履歴** — ストリーミングの最初の画面で **履歴から削除** により非表示にした曲も、このページの統計にはそのまま含まれます。統計からも削除するには、下の **再生履歴を削除** を使います。
- **ローカルファイル** — タグ（タイトル · アーティスト · アルバム）のみを残し、ファイルパス · フォルダー名 · ファイル名は残しません。
- **書き出す** — JSON · CSV（選択した出典のみ）。**削除** — 折りたたみの **履歴の設定と集計基準** にある **再生履歴を削除** → **すべて削除**。元に戻すことはできません。**このMacに再生履歴を保存** をオフにすると、それ以降は記録されません。
- ジャンル · BPMは再生アプリが提供した値のみを使用します。値がない場合は推測しません。
- **Spotifyが提供したリスト** — タブを切り替えると、Spotifyが通知する上位の曲 · 上位のアーティスト（期間 **4週間 · 6か月 · 1年**）と最近聴いた曲をそのまま表示します。ご自身のClient IDで接続しておく必要があり、Fidenneはこのリストを使って回数 · 割合 · ジャンルを計算せず、画面を離れるとすべて破棄します。順位は再生回数順ではありません。行をクリックするとSpotifyでその曲が開きます（**OPEN SPOTIFY**）。

## 6. DSPグループ

音を調整する場所です。ヘッダーに現在の入力レート（停止中は最後の再生基準）が表示されます。サイドバーの **DSP** グループから **EQ** · **Ostrum** · **クロスフィード** などのページを選びます。Responseグラフはページ上部にあり、バンドの編集は **詳細** を開くと表示されます。

- **変更するとすぐに聴こえ、保存(⌘S)すると次回の起動にも残ります。** EQ · Ostrumのどちらも同じです。他のページへ移動して戻ってきても編集内容はそのまま残ります。
- ボタン · 項目名、案内、警告はアプリの表示言語（ここでは日本語）で表示されます。Ostrum や PCM Direct などの製品用語はそのままです。DSPはFidenneが処理する出力（DSD · PCMオーバーサンプリング）でのみ聴こえます。PCM Directでは通過しません。

### 6.1 Responseグラフ

線は **ターゲット**（オレンジの破線、目標） · **マイヘッドホン**（グレー、測定） · **補正後**（最も濃い線 = マイヘッドホン + EQ + Ostrum） · **EQカーブ**（青い線、バンドの点がこの線上）で、**もっと見る** メニューに EQ + Ostrum · Ostrum があります。EQを合わせるとは、**補正後** を **ターゲット** に沿わせることです。

- グラフ下の凡例で線の表示をオン/オフします。カードヘッダーの **View** で **Original** / **Target flat**（ターゲットを0 dBの水平線にする）を選びます。
- 曲線はEQのPreampとOstrumのHeadroom · Outputを差し引いて描画します（形状を比較するため）。実際の音にはそのままかかり、グラフ下の折りたたみ **グラフの読み方・注釈** の1行目にその値が示されます。
- EQ + Ostrumの線は、EQ（エンジン計算、左チャンネル）+ Ostrumの中央の音の大きさです。クロスフィードは中央を変えないため含めていません。
- 再生していなくても描画されます（停止中は最後の再生レート基準）。カードヘッダーの **リファレンス**（基準点 1 kHzなど） · **Range**（自動 · ±12 · ±18 · ±24 dB）は表示のみを変え、音は変えません。
- **スペクトラム** — グラフの背後に現在の音の帯域ごとの大きさが薄く表示されます。凡例の下の **Spectrum** 行で **DSPの後** · **前後を重ねる** · **DSPの前**、解像度 · スムージング · ピークホールドを選びます。再生中のみ動きます。
- **過大設定の検出**（グラフ下の1行） — EQ · Ostrum · クロスフィードを合算した曲線が過度に持ち上がったり（+6.2 dB超）、0 dBを超えたり、急峻すぎたりすると、グラフに赤い区間を描画します。制限はしません。
  - バンドを修正する補正は、**補正を提案…** で **補正を適用** を押したときのみ行われます。ウィンドウは **業界の慣例**（Preampのみ下げる）で開き、**改善**（超過したブースト · 急な側面を作るバンドのみを最小限に修正）は手動で選んだときのみ使用します（業界の慣例で解消できないものがある場合は「改善」で開きます）。変更されるバンドの表を確認し、**補正を適用** を押して初めて変更されます。「改善」は曲線を削るため、狙った音と変わる場合があります。**補正を取り消す** で1回分元に戻ります。
  - 自動で行うのは **クリッピング防止 — Preamp自動低下**（デフォルトはオフ）の1つだけです。オンにすると、合計が0 dBを超えたときにPreampのみを必要な分だけ下げ、バンドは変更しません。

### 6.2 Equalizer

EQページの **EQをオンにする** でオン/オフを切り替えます。**マイEQ** で保存したEQを選び、**AutoEQ** でヘッドホンとターゲットを選びます。**保存済みの内容に戻す** · **リセット** · **保存**(⌘S)は保存行にあります。

1. グラフの点をドラッグするか、バンド行のスライダー · 数値欄でバンドを変更します。すぐに音に反映されます。
2. 気に入ったら **保存**(⌘S)を押します。

**うまくいったかの確認** — ヘッダー下の行が `✓ 保存済み · 次回の起動もこのEQで開始します` になります。保存前はオレンジ色で `● 未保存 — 保存(⌘S)すると次回の起動にも残ります` と表示されます。

- **プリセット ▾** — 名前を付けたEQを残して選び直します。
  - **最近** 5件と **すべてのプリセット**。選ぶとすぐに聴こえ、次回の起動もこのEQで開始します。そのプリセットに合わせたヘッドホン · ターゲットと強度がAuto EQ行に一緒に入り、**バンド数** はそのEQのバンド数になります（強度を残していないプリセットは100 %）。
  - プリセットを選んだ状態で保存(⌘S)すると、**そのプリセットにも** EQとヘッドホン · ターゲットが上書きされます。ヘッドホン · ターゲットだけを変更しても保存が有効になります。
  - **別名で保存…** は現在のEQを保存し、新しい名前で残します（現在のプリセットはそのまま、100個まで）。**プリセットを管理…** は名前の変更 · 削除、**前回の保存内容に戻す** は保存するたびにその前にあったEQ（直近20個）です。
- **保存済みの内容に戻す** は最後に保存したEQへ、**リセット** はすべてのバンドとPreampを0 dB（フラット）に戻します。どちらもすぐに反映されます。
- 保存していないEQが聴こえている状態でアプリを閉じると、一度確認を求めます — 保存して終了 · 保存せずに終了 · キャンセル。
- **バンド行** — 先頭に **Preamp**、続いてバンドごとにオン欄と番号 · ゲインスライダー · 種類（PK · LS · HS · LP · HP · BP · NO · AP · G） · チャンネル（L+R · L · R） · Gain · Freq · Q欄。行の上には **EQプリセットを開く…** · **31バンドグラフィック** · **バンドを追加** · **バンドを削除** · **バンドをリセット**。バンドは256個までで、**EQプリセットを開く…** はAutoEq · Equalizer APO形式のファイルを開きます。
- **マイEQに読み込む** — Room EQ Wizard(REW)のフィルター設定、Equalizer APO設定、AutoEqのParametricテキストファイル（.txt、2 MBまで）を新しいEQとして読み込みます。Playback ChainのEQパネルで **マイEQ** の **読み込む…** を押すか、ファイルをEQ設定欄にドラッグ＆ドロップします。選択するとまず **読み込んだもの**（バンド数 · プリアンプ）と **読み込まなかったもの**（このEQにないフィルター種類 · 範囲外の値 · Qなしで書かれたフィルター · 256バンドを超えたフィルター · Include · 条件ブロック · チャンネル指定などの行とその理由）が表示されます。値は丸めたり変更したりせずスキップし、読み取れない行がある場合はファイル全体を読み込まず何行目かを通知します。名前を決めて **マイEQに保存** を押すと保存され、保存するだけでは **マイEQ** から選ぶまで音は変わりません。GraphicEQ曲線はフィルターではないためここでは保存しません（上の **EQプリセットを開く…** で曲線からフィルターを合わせます）。
- **EQ計算方式(0.7)** — EQフィルターの係数をアナログプロトタイプに合わせて計算します（matched）。以前はナイキスト（出力レートの半分）付近で曲線が曲がっていましたが、現在は高い周波数（特に16 kHz以上）で設定した曲線が実際の曲線により近くなります。高域にフィルターを置いた既存のEQは、同じ設定でも高域の音が少し変わる場合があります。エンジンが出力レートで処理するため、352.8 kHzとDSDでは差が極めて小さく（テスト信号で0.002 dB以下）、44.1 · 48 kHzのような低いレートで顕著になります。聴感で確認したものではありません。
- **Clipping & Headroom**（バンド行の下） — この再生でクリッピングが発生したか、リミッター、**Apply Headroom N dB** 提案ボタンがあります。
- **EQ方式** — **Parametric**（デフォルト、レイテンシーなし） / **Minimum Phase** / **Linear Phase**（レイテンシー約0.2秒、次の再生開始から）。リニアフェーズの場合は **リニアフェーズの長さ** で長さを選びます。どちらがより良く聴こえるかは確認していません。
- エンジンがそのレートでEQを作成できない場合はオレンジの行で通知し、EQなしで再生します（保存したEQはそのまま）。EQをオフにした直後に一瞬（0.1–0.3秒）少し小さく聴こえてから戻るのは、大きな音を防ぐためです。

### 6.3 Ostrum

低音 · 存在感 · 幅 · 倍音をまとめて調整するFidenneのトーンシェイパーです。ノブは回すとすぐに聴こえ、残すにはヘッダーの **保存**(⌘S)を押します。

1. **Ostrum On** をオンにします。
2. **プリセット ▾** からおすすめの初期値を1つ選ぶか、**Mix** が0のときに表示される **自然に始める** を押します。
3. ノブを少しずつ動かしながら聴き、気に入ったら保存します。

**うまくいったかの確認** — パネル最上部の行が「適用済み · リビジョン N」になり、Composite Responseグラフが変わります。

**プリセット ▾** — おすすめ初期値 **自然に**（最も控えめ、最初に推奨） · **明瞭なOST・ボーカル** · **低音重視・電子音楽** · **夜間・疲れにくく**（最も弱め）。まだ聴いて確定した値ではなく提案です。**現在の設定をマイプリセットとして保存…** でマイプリセットを残し、同じメニューから選択 · 名前変更 · 削除を行います。

| ノブ · 項目 | 役割 |
|---|---|
| **Mix** | 全体の量。0だとBass · Presenceが聴こえません。最初に上げます |
| **Bass** | Sound · Compression · Tune。**スプリットベース** は重低音とその上の低域を分けて扱います。**トポロジー** は Blend（デフォルト） / Manual 〔実験〕 |
| **Presence** | 高域を上げる量（Intensity）と方式（Off · Analog · Min Phase · Linear Phase）。Linear Phaseは次の再生から、または **Restart Now** |
| **Width** | 左右の差の大きさ |
| **Harmonics** | 倍音を加えます（Curve · Amount） |
| **Headroom · Output** | 全体のレベル。**推奨Headroom** が表示されたら **Headroomを推奨値に設定** を押します。横の **変わるたびに自動で**（デフォルトはオフ）をオンにすると、ノブが推奨値に追従します |

- **Tune** はPresenceの基準周波数です。Mixを上げるにはTuneを1.1–22 kHzの範囲内に置きます。そうでない場合はノブの横にオレンジの行で通知します（エンジンが設定を受け付けないときも、理由と変更すべき点を1文で示します）。Tuneノブは左が低いHzです。
- **ニュートラルチューン** をオンにするとBass · Presenceを外し、Width · Harmonics · Outputのみを使用します。各項目の横の **ⓘ** にいつ使うかとトレードオフが書かれています。
- Bassコンプレッションが効いている間、グラフに薄い紫の斜線と `圧縮中 −x dB` が表示されます。

### 6.4 Crossfeed

ヘッドホンで左右が分かれすぎて聴こえるとき、反対側の音を少し混ぜます。

1. **クロスフィードをオンにする** をオンにします。
2. **軽め · 普通 · 濃いめ** の中から1つ選びます（混ぜる量が少ない順）。
3. さらに調整するには2つのノブを回します — **量（Feed）** はどれだけ混ぜるか（−15 … −1 dB、−1側ほど多い）、**周波数（Cutoff）** はどの高さまで混ぜるか（300–2 000 Hz）。

**うまくいったかの確認** — 選んだボタンが押された状態になり、小さなM/Sグラフ（再生中）でSideの線が下がります。

- **マイ設定** メニューで現在の値に名前を付けて保存 · 読み込み · 削除ができます（20個まで）。ノブの下の **ⓘ** に「頭の中に閉じこもったように感じるとき · 左右が狭すぎるときにどちらへ回すか」が載っています。
- OstrumのWidthと同時にオンにすると「幅を2か所で調整しています」と表示されます。両者は同じ帯域で互いの効果を一部打ち消します。

### 6.5 Headphone ▾ · Target ▾ (EqualizerのAuto EQ行) · 詳細 — ファイル · 高域 · 生成AI（折りたたみ）
<a id="65-①-headphone--②-target-equalizer-의-auto-eq-탭--measurement--target-files-접힘"></a>

ヘッドホンの測定データに合わせてEQを自動作成する場所です。EQページの **AutoEQ** で **マイヘッドホン** と **ターゲット** を選びます。バンドの編集は **詳細** にあります。

DSPページのEQ欄の最上部には、**マイEQ**（保存したEQを選ぶ）と **AutoEQ**（マイヘッドホン · ターゲット · バンド · 適用）が上下に並び、現在使っている方に印が付きます。もう一方で何かを選ぶと、印がそちらに移ります。その下に **EQ方式**（パラメトリック · 最小位相 · リニアフェーズ）と保存行があり、より詳しい設定は下の **詳細** にあります。

1. **マイヘッドホン** から自分のヘッドホンを選びます。リストにない場合は **ヘッドホンを検索…**。
2. **ターゲット** からターゲットを選びます — 測定者のターゲットカーブ（DF · DF t · Harman …）または別のヘッドホン。
3. 行末の **適用** を押します（[§6.6](#66-bands--strength--auto-fit-equalizerのauto-eq行--自動フィットの内容折りたたみ)）。

**うまくいったかの確認** — **適用** のあと、ヘッドホン · ターゲット · 適用したバンド数が表示されます。

- ヘッドホン · ターゲットを選んだだけではEQは変わりません。変わるのは「適用」を押したときです。
- **ヘッドホンを検索…** — squig.linkの測定リストを取得してこのMac内で検索します（検索語は送信されません）。最初は **リストを取得** を押し、一度取得したリストは30日間再取得しません。以前のバージョンで取得したリストにイヤホンの測定リストが抜けている場合は、開いたときに抜けている分だけをバックグラウンドで取得して補います（squig.linkをオンにしている場合のみ）。**測定サイトからリストを再取得** ボタンでいつでも再取得できます。行をクリックすると確認欄が開き、**適用**(Return)を押すと変更されます。**☆** はお気に入りです（マイヘッドホン · ターゲットヘッドホン別々）。
- **ターゲット検索** — DSPページのAutoEQ **ターゲット** リストには検索欄があります。入力すると測定リストからヘッドホンを最大12件表示し（現在表示中のマイヘッドホンは除きます）、行をクリックするとそのヘッドホンをターゲットにします。検索結果 · ターゲットのお気に入り · マイヘッドホンのお気に入り行の末尾には常に **☆ / ★** が表示されており、お気に入りの追加と削除ができます。お気に入りから外しても現在選んでいるターゲットは変わりません。測定リストをまだ取得していない場合は、先に取得するよう案内が表示されます。Playback Chainパネルのターゲットリストは従来のままで、一番下の行からDSPページへ移動できます。
- マイヘッドホンとターゲットの測定機器が異なる場合、ステータス行がその旨を表示し、**測定機器の差を補正**（デフォルトはオン）で合わせます。測定機器の関係が不明なターゲットはリストから非表示にします。ヘッドホンにイヤホン用ターゲットのような異なる種類を選んだ場合は、黄色の行で通知しますが制限はしません。
- **詳細 — ファイル · 高域 · 生成AI**（折りたたみ）：
  - **ファイルとして開く** — **Open measurement…** · **Open target…** で手持ちの測定 · ターゲットファイル（2列 Hz · dBテキスト）を開きます。
  - **高域（自動フィット）** — 高域をどこまで補正するか（すべて · 境界より上は補正しない · 6–8 kHzより上は半分など）。「適用」を押したときに反映されます。
  - **生成AIで調整** — 現在の設定を **AIに渡すテキストをコピー** するかファイルに書き出し、お使いの生成AI（ChatGPT · Claudeなど）で調整したあと、回答を貼り付けて **ペーストした回答を読み込む**。アプリから外部へは何も送信しません。

### 6.6 Bands · Strength · Auto fit (EqualizerのAuto EQ行) · 自動フィットの内容（折りたたみ）
<a id="66-③-auto-fit-equalizer-의-auto-eq-탭--auto-fit--refinement-접힘"></a>

- **バンド数** — バンド数。AutoEQの **10 · 16** の選択肢と、詳細の **5 · 10 · 15 · 32** および **その他の数**（1–32）で決めます。10がデフォルトです。合わせたあと4–8 kHzに狭い凹凸が残る場合は、12–16に上げてやり直してみてください。
- **強度** — 補正の強度（0–100 %、デフォルト100 %）。下げるとすべてのバンドのゲインが同じ割合で小さくなります。
- **適用** — 押すと合わせたバンドがバンド行に入り、**すぐに聴こえます**。残すには保存(⌘S)。合わせられない場合はボタンが無効になり、理由がオレンジ色で表示されます。
- **自動フィットの内容**（折りたたみ） — バンドごとに1文（例：「3 kHz付近を4.0 dB下げる — 中高域…」）と誤差の数値が載っています。音が良いという判定ではありません。
- Ostrumがオンになっている場合、Auto fitはEQのみを合わせるため、**補正後** の線がターゲットから外れて見えることがあります。

### 6.7 A/Bボタンのパネル — A/B · ABX · Auto Bypass · Loop · 音量合わせ(Level-matched Comparison)

A/B · ABX · Auto Bypass · Loop比較は **このベータ版では非表示にしています** — DSPページにA/Bボタンは表示されません。修正後に再びオンにします（[既知の制限事項](KNOWN_LIMITATIONS.md)）。

### 6.8 コンボリューション (IR) ページ

サイドバーの **DSP** グループの **コンボリューション** ページで、IR（インパルス応答）ファイルを音楽に適用します。補正用IRや4チャンネルBRIRを使用できます。

- **IRファイルを選ぶ…** — WAVまたはAIFF(AIFC)、1 · 2 · 4チャンネル、44.1–192 kHz、チャンネルあたり1 048 576サンプルまで、16/24/32-bit整数または32/64-bit浮動小数点。アプリにIRは同梱されていません。ご自身で測定したか使用権のあるファイルを選びます。
- 1チャンネルは左右に同じIR、2チャンネルはL · Rチャンネルに別々、4チャンネルはトゥルーステレオです。4チャンネルファイルは **チャンネルの順序** でファイルの順序を確認します。デフォルトは **LL · LR · RL · RR（デフォルト）**、もう一つの順序は **LL · RL · LR · RR** です。
- 新しいファイルを選ぶと、**現在のゲインとそのファイルの提案ゲインのうち小さい方の値** をリクエストし、ゲイン欄に表示されます。ファイルを最初に選んだだけではオンになりません。**オンにする** でオン/オフを切り替えます。
- **ゲイン** を直接変更したら **適用** またはReturnで反映します。**提案値** は提案ゲインをそのまま適用します。**応答ピーク · 提案ゲイン · ゲイン上限** はエンジンが報告した値です。ゲイン上限は表示グラフの範囲だけでなく、**0 Hzからナイキストまでの全帯域応答と1 dBの余裕** を反映しています。提案値はその応答上限を基準に0.2 dBの余裕を持たせます。IR自体を自動正規化することはありません。
- 実際に適用している間は、**IRなしで、同じレイテンシーで比較** でIRだけを外して比較できます。IRはEQ · Ostrum · クロスフィードの後、モジュレーターの前の最後のPCM処理です。サンプルレートが異なる場合はIRをエンジンレートに変換します。オンにするとレイテンシーが約24–49 ms増え、実際のレイテンシーと適用状態をパネルで確認できます。

### 6.9 プラグインページ

サイドバーの **DSP** グループの **プラグイン** ページで、Audio Unit(AU)エフェクトプラグインを音が通る経路に挿入します。変更内容は次の再生から聴こえ、オフにすると原音のまま通過します。

1. **プラグインを追加** を押すと、このMacにインストールされているエフェクトプラグインがメーカー別に表示されます。1つ選びます。初めて見るプラグインやバージョンが変わったプラグインは、FidenneがmacOSの検証ツール(auval)で先に検査し（`プラグイン n/m を検査しました`）、検証に合格したものだけが使えます。
2. カードの **オンにする** でオンにします。スロットは **最大4個** で、ページヘッダーに使用中の数（例：2/4）が表示されます。
3. 任意： **エディタを開く** でプラグインの画面を別ウィンドウで開きます（独自の画面がないプラグインは `このプラグインには独自の画面がありません`）。

- **位置** — プラグインは3か所のいずれかに配置されます： **EQ · Ostrum の前** · **EQ · Ostrum とクロスフィードの間** · **クロスフィードの後**。ページ上でFidenneのEQ · Ostrumとクロスフィードは、位置の間の細い線として表示されます（固定であり、ここではオフにできません）。同じ位置の中では上から順に処理され、≡をドラッグするか ⌥↑ · ⌥↓ で順序を変更できます — 音が通過する順序も変わります。カードのメニューからも同じ操作ができます。
- **削除** — カードの **削除** は保存された設定がある場合、一度確認を求めます。
- **通知** — プラグインがステレオで使えない、曲のサンプルレートを受け付けない、処理が遅れる、レイテンシーが大きすぎる、不正な音を出す、または音が大きすぎる場合、Fidenneはそのプラグインをオフにし、理由をカードに記載します。**再びオンにする** または **再読み込み** で復帰します。インストールされていないプラグインの設定は保持されます。保存されたリストを読み取れない場合、リストは変更されません。
- プラグインはFidenne外の別プロセスで動作し、再生中の音がそこへ渡されます。プラグインの動作は開発元の規約に従います。プラグインはFidenneが処理する出力で動作し、音の設定はアプリが保存して次回の起動時に復元します。
- テストしたのはテスト用AUまでであり、市販のプラグインすべてを確認したわけではありません（[既知の制限事項](KNOWN_LIMITATIONS.md)）。

**マルチチャンネル入力プラグイン** — 同じページの **マルチチャンネル入力プラグイン** 欄で、5.1 · 7.1 · 7.1.4ローカルファイルを5.1 · 7.1入力を受け付けるAudio Unitに通します。**マルチチャンネル入力プラグインを使用** をオンにし、**マルチチャンネル入力プラグインを選ぶ** でプラグインを選ぶと、出力を **2チャンネル(ヘッドホン)**（デフォルト：プラグインが返した2チャンネルがEQと出力へ続きます）または **元のチャンネルのまま** から選べます。ステータス行に入力レイアウト · レート · プラグインのレイテンシーが表示され、プラグインが遅れたり停止したりすると再生を止めて理由を記載します。処理バイパス（PCM Direct）では使用しません。Fidenneには空間オーディオレンダラーがありません。ヘッドホンでの空間化が必要な場合は、無料のAudio Unitプラグイン（例：Sennheiser dearVR MONITOR）をこの欄に接続して使用できます。

**うまくいったかの確認** — 再生中にカードに `動作中 · レイテンシー ○ ms` が表示され、Playback Chainのプラグインチップがオンになっています。

## 7. 入出力 · 診断ページ

### 7.1 出力の独立制御 · 出力方式

ページ最上部の **出力方式** で3つの中から1つ選びます。カードごとに1行で何を通過するかを示し、**使用中の設定** の行がその方式で読み込む設定を知らせます。フィルター · DSD変換 · PCM · ヘッドルームなどの詳しい値は **詳細** を開いたところにあり、現在の方式で使わない行は薄く表示されたまま保存した値を保持します。

- **PCM Direct** — Fidenneは音を処理しません。再生アプリ → macOS → DACへそのまま送られます。曲ごとにサンプルレートを合わせません（音がFidenneを通らないため、曲（入力）のレートに合わせて出力レートを変えられないからです） — DACと曲のレートが異なる場合はmacOSが変換します。開始時に1回だけDACレートを決めます（Spotifyは44.1 kHz、DACがDSD · 352.8 kHzのような通常のPCMではないレートに残っている場合は曲のレート、不明な場合は44.1 kHz）。
- **PCMオーバーサンプリング** — Fidenneがフィルターでアップサンプリングし、整数PCMとして送ります（1ビットDSDには変換しません）。出力レート · ビット深度 · ディザーは **詳細 › PCM** で決めます（下述）。
- **DSD (DoP)** — Fidenneがフィルター → DSD変調器 → DoPでDSDを送ります。
- **内蔵スピーカー · AirPods · 3.5 mm · HDMI** — Fidenneが音を処理して送り、最後にmacOSがシステムミキサーでミックスして送ります。DSDカードは薄くロックされ、PCMでのみ出力されます（`このデバイスではDSD出力が制限されています`）。保存してあるDSD設定は消えず、DACに戻ると再び使われます。ステータス行とデバイス行も、実際に出力されるPCM（システムミキサー経由）を示します。再生中に変更できない項目には理由が1行表示されます。
- EQ · Ostrum · クロスフィードをオフにすると、PCMオーバーサンプリングとDSDにはトーンを変える処理はなくなります。ただし、その形式に必要な変換（アップサンプリングフィルター · DSD変調器 · ディザー · ヘッドルーム）はかかり、選んだフィルターと変調器によって音の性格が変わる場合があります。
- **サウンドプリセット** — **マイプリセット** カードはドラッグして順序を入れ替えられます（カードのメニューで前 · 後ろへ移動することもできます）。**おすすめ** 行の末尾にある目のアイコンを押すとおすすめカードが折りたたまれ、同じ位置の目アイコンで再表示できます。おすすめの順序は変わりません。
- PCM Directのローカルファイルは、音源のレートで音声処理をバイパスし、ディザーをオフにします。
- PCM Directに切り替える前にDACの音量を確認してください — Fidenneのヘッドルームがかからないため、より大きく聴こえることがあります。
- **再生中の音には触れません。** 曲が自動で次の曲へ移るとき、PCM Directは停止したり巻き戻したりDACレートを変えたりしません。レートが異なれば現在のレートを継続し、macOSが変換するため途切れません。レートを曲に合わせる処理は、曲を手動で選んで開始するとき、音が出る前にのみ行います。一時停止 · 再開 · シークでもレートは変わりません。曲ごとに判明したレートはサービスと根拠（曲 · アルバム）を区別して記憶しておき、次に手動で選ぶときに使います。同じアルバムでもリリース版が異なれば別の記憶として扱い、正確なリリース版が分からない場合は推測しません。

選んだ出力方式は次の起動にも残ります。ただし、DSD · PCMオーバーサンプリングはそのDACでその形式が確認されたことがある場合のみ復元し、そうでなければ **PCM Directで開始** し、その旨を1行で通知します。アプリを起動しただけでは音は始まりません。

**詳細 › PCM — 出力レート · 曲間**（PCMオーバーサンプリングの設定です。PCM Directのローカルファイルは音源レート維持 · 処理バイパス · ディザーオフを使用します。）

- **出力レート** — 44.1 · 48 · 88.2 · 96 · 176.4 · 192 · 352.8 · 384 · 705.6 · 768 kHzです。新規設定のデフォルトは音源レート維持です。デバイスが受け付けないレートはリストに薄く残り、`このデバイスは受け付けません` と付きます。選んだレートをデバイスが受け付けない場合は、デバイスが受け付ける最も高いレートに変えるボタン（例：**192 kHzに変更**）が表示されます。低いレートで24-bitのノイズ余裕が基準に満たない場合は、その事実が1行で表示されます。
- **音源のレート系列に合わせる** — 以前の設定を引き継ぐときに適用される選択肢です。オンにすると、44.1 kHz系統（44.1 · 88.2 · 176.4 …）の曲は44.1系統で、48 kHz系統（48 · 96 · 192 …）の曲は48系統で出力します。ポップアップが倍率の行（例：`88.2 / 96 kHz (×2)`）に変わり、先頭の行 **自動（デバイスの最高）** は曲の系統でデバイスが受け付ける最も高い倍率を選び、横に `自動 → 384 kHz` のように結果が表示されます（デフォルトではありません）。系統が変わる曲の間には一瞬無音になります。曲のレートがまだ不明または推測の場合は系統を変えず、今の系統を維持します（`音源のレートを確認するまで — 今の系列を維持`）。デバイスがその系統を受け付けない場合は別の系統に変換して出力し、一度通知します。レートは曲間でのみ変わり、曲の途中で変わることはなく、システムタップで受け取る音はセッション開始時の形式に従います。
- **1行表示** — エンジンが実際に行った処理が `音源 44.1 kHz → 出力 176.4 kHz (×4) · 24-bit` のように表示され、音源の整数倍でない場合は括弧内に `ダウンサンプル` または `変換` と記されます。×1や `ダウンサンプル` ではリミッターを使えず（`この倍率（×1・ダウンサンプル）ではリミッターを使えません`）、88.2 kHz未満では超高域検査が `該当なし` と表示されます。低い出力レートでもフルスケールに近づいているかはトゥルーピークで判定します。
- **曲間** — **そのまま**（デフォルト：音楽の音に触れず、曲間をデジタル無音でつなぎます）または **なめらかに**（曲が終わる直前の0.02秒間、音を下げます）。選ぶと再生をやり直さず次の曲から適用されます。曲ごとに `今回の曲: そのまま · レートが変わったため前に 250 ms 無音` のように1行表示されます。この方式はローカルファイルをPCMで再生するときに適用され、ストリーミング音声を受けて処理する再生 · DSDでは従来通りです（その場合この行は出ません）。
- **レート変更時の待機** — DACごとに設定します： **オフ** · **0.25秒**（デフォルト） · **0.5秒** · **1秒** · **2秒**。DACが新しいレートを捕捉する間に最初の音が途切れる場合は長くします。出力デバイスを選ぶ前は設定できません。
- **ビット深度**(24 · 16-bit) · **ディザー** — 従来通りです。
- **44.1 kHz系統の上限 · 48 kHz系統の上限** — **詳細 › PCM** でDACごとに系統別の最高レートを下げます。系統に合わせて選ぶ自動選択が、不安定なレートを避けるようにするときに使います。

**内蔵スピーカー · 3.5 mm端子 · AirPods(Bluetooth) · HDMI · DisplayPort · AirPlay**

- FidenneはこのようなデバイスへもEQ · Ostrum · クロスフィード · フィルターとエンジンPCM出力を処理して送ります。最後にmacOSが **システムミキサー** でミックスしてデバイスに送るためビットパーフェクトではなく、ステータス表示行に `システムミキサー経由 · ビットパーフェクトではありません` と表示されます。出力はPCM Float32で、ビット深度 · ディザーは選択できず（薄く表示）、出力レート選択も使いません — エンジンはデバイスの現在のレート以下でサポートされるPCMレート（44.1 ~ 768 kHz）のうち最も高いレート（デバイスが48 kHzなら48 kHz）で処理し、必要に応じてmacOSがデバイスレートへ1回変換します。ステータス表示行に `デバイス ○ kHz · macOSが1回変換（最高品質）` やBluetoothの遅延が表示される場合があります。
- Fidenneはこのデバイスのレートを変更しないため、**レート変更時の待機** は `該当なし: このデバイスはシステムミキサー経由で、レートを変更しません` となります。他のアプリによってデバイスレートが変わると、そのレートで1回再起動し、再生中だったローカルファイルは停止します（`もう一度再生を押してください`）。Bluetooth機器がマイクを使う通話モードになるとFidenneの処理を休み（`通話音質に切り替わったためFidenneの処理を一時休止します`）、マイクを使うアプリを閉じると自動で再開します。
- 音量はMacの音量です — 初めて使うデバイスでは `Macの音量を0かごく小さくしてから開始し、聴きながらゆっくり上げてください。` という案内が表示されます。
- Fidenneはこの経路でも音を処理して送り、最後にmacOSがシステムミキサーでミックスして送るためビットパーフェクトではありません。この版で実際のスピーカー · AirPods · モニターで確認したのは一部です（[既知の制限事項](KNOWN_LIMITATIONS.md)）。

- **出力DAC** — 選択 · 更新 · 再接続。エンジンが使うPCMレート（44.1 ~ 768 kHz）を1つも受け付けないか、2チャンネル形式がないデバイス（ほとんどのドングル · 4 · 8チャンネルインターフェース · 一部のモニター）は、名前の末尾に `· PCM Directのみ` が付きます。そのデバイスではDSPとライブラリ再生は使えず、PCM Directでのみ聴けます。Fidenneは内蔵スピーカー · AirPods · HDMIへも音を処理して送るためこの表示は付かず、最後にmacOSがシステムミキサーでミックスして送ります。同じUSB DACを別のポートに挿しても認識します。確実でない場合は **同じデバイスで使う** / **別のデバイスで使う** を一度尋ねます。

### 7.2 DAC形式確認（旧「エンジン出力形式」）

自分のDACがどの形式（DSD128 · DSD256 · PCM 24 · 16-bit）を受け付けるかを示す表です。形式ごとに **確認済み**(✓) · **エンジンが拒否しました**(⚠ + 理由) · **確認前** · **不明** で表示され、DACごとに記憶されます。

- **すべて確認** — 再生を止めた状態で押すと、まだ確認していない形式を順番に設定してみて元に戻します。音は出ませんが、DACがカチッと鳴ったり表示が一瞬変わったりすることがあります。
- DACが選んだ形式を受け付けない場合、他のレートに下げずに開始しません。
- **初めてDoPを送るとき一度確認します** — `<DAC名>へDSD(DoP)を初めて送信します`。表の「確認済み」はDACがDoPをデコードできるという意味ではなく、デコードできないDACは大きなノイズを出します。
  音量を下げるかヘッドホンを外し、DACの説明書にDoP対応の記載があれば **DoP 対応の DAC · 開始**、分からなければ **PCM 24-bit で再生**。DACのインジケーターにDSDが点灯するか確認し、間違えて選んだ場合は表の下のDoP行にある **もう一度リクエスト** を押します。
- macOSの音量と連動する音量調節機能があるDACでは、DSD · PCM整数出力においてFidenneがその音量を引き継いで同じ大きさに下げて送り、終了したら元に戻します。Playback Chainの出力デバイス行に `DAC音量 −○ dB をFidenneが引き継ぎ中` と表示されます。引き継げない場合は `このDACの音量をFidenneが引き継げませんでした` と通知します — そのDACはPCM Directで聴きます（[トラブルシューティングガイド](TROUBLESHOOTING.md#dac-音量と-dsddop--整数-pcm)）。
- **DACがN秒以内に再接続されたら再生を再開** — 同じDACのみを待ちます。「待たない」でオフにします。
- **終了後の出力** — 入出力 › 詳細。Fidenneを終了するときにシステム出力を戻す先です。オンにする前に使っていたデバイスが接続されていればそのデバイスに戻り、ない場合のみこの選択に従います。**最後に使ったDAC**（デフォルト）は最後に音を出した外部デバイスであり、Mac内蔵スピーカー · ヘッドホン端子は除きます。そのデバイスがないか **Macのスピーカー** を選ぶとMacのスピーカーに切り替わります。Macのスピーカーに戻すときは音量を最小に下げてから戻します。外部DACの音量は変えないため、上げたまま終了すると次の再生が大きく聴こえることがあります。再生中でも変更できます。
- 他のアプリがDACを使用していても開始を試みます。そのアプリが譲らない場合は `他のアプリ(…)がDACから退かないため…` を一度表示し、再試行しません。その間、他のアプリの音がMacのスピーカーに移ることがあります。
- `DAC再生経路がmacOS内で停止しました…` が表示されたら、USBケーブルを抜き差しするかFidenneを再起動します（[トラブルシューティングガイド](TROUBLESHOOTING.md)）。

### 7.3 ストリーミングアプリの自動再生 · 入力と出力デバイス

**エンジン開始後** — エンジンをオンにするとき何をするか選びます。**自動検出** は曲を新しくかけず、再生中のアプリに追従します（ブラウザの音声はこれにしておき、ブラウザ側で再生します）。**Apple Music** · **Spotify** はそのアプリの現在の項目を、**YouTube Music（ブラウザ）** は開いているタブに ▶ を送ります。**自動再生しない** はエンジンのみをオンにします。MusicとSpotifyが同時に再生された場合は、後から再生した方に追従し、もう一方を一時停止します。

**入力** — 音を受け取る経路です。選んだ入力は次の起動にも引き継がれます。

- **Fidenne Inlet**（推奨） — 再生アプリの元のレートをそのまま受け取ります。同じ欄で **インストール… / アップデート… / アンインストール…**。新しい版がある場合は、音が出ていないときにホーム画面で通知します。インストール · アンインストール時にmacOSが管理者パスワードを求め、一瞬すべてのアプリの音が途切れます — 聴いていないときに行ってください。通知音はFidenne Inletには入りません。再生中にこのデバイスのレートが変わると1–3秒無音になってから新しいレートで続きます。「古い名前でインストールされています」と表示されたら再インストールします（選択はそのまま）。
- **システムタップ**（リスト名 **Process Tap**） — インストールなしでこのMacのすべてのアプリの音を48 kHzで受け取ります。受け取っている間その音はFidenneからのみ出力され、エンジンをオフにするとすぐ元通りに聴こえます。初めて使うときmacOSがオーディオ録音の許可を求めます — 拒否すると無音になります（システム設定 › プライバシーとセキュリティ › 画面収録とシステムオーディオ録音）。1つのアプリの音声だけを受け取るには、そのアプリの出力をFidenne Inletに送り、入力でFidenne Inletを選びます。
- **＋ 他の入力デバイス** — すでに使っている別のループバックデバイスを選びます（出力と2チャンネル入力がともにあるデバイスのみ、**✕** で削除）。

**Apple Musicのオリジナルレート** — Apple Musicの曲のオリジナルレートに合わせて入力レートを変えます。聴いた曲のレートをこのMacに記憶し、次回は最初から正しいレートで出力します。初めて聴く曲はレートが分かるまで最初の音を一瞬（通常1秒以内、長くても2秒）出しません。Spotifyはオリジナルレートを通知しないため、44.1 kHzに合わせます。

### 7.4 フィルター · モジュレーター · 出力ゲイン（カード） — DSD経路の音設定
<a id="74-필터--모듈레이터--출력-게인-접힘--dsd-경로의-소리-설정"></a>

DSD · PCMオーバーサンプリングの設定は **入出力 · 診断 › 詳細** にあります。**フィルター** · **DSD変換** · **PCM** · **ヘッドルーム** · **バッファー** をそれぞれ開きます。おすすめの組み合わせと **現在の設定をプリセットとして保存…** は **サウンドプリセット** カードにあります。

**どこから聴いてみますか？** カードの **おすすめの組み合わせ N個** は目的別のおすすめです。カードごとに「聴きどころ」が書かれており、カードに書かれた項目だけが変更されます。再生中に選ぶと一時停止してから再開します。

1. **フィルター** — 処理方式（基本SRC · 長タップ拡張 · 超長タップ） · 系統 · 長さ。〔実験〕バッジが付いたフィルターは注意点を示します。長タップ · 超長タップは音を遅らせるため映像とずれる可能性があるとして **レイテンシー ○○ ms** を表示します — 映像を観るときは基本SRCとバッファー **低レイテンシー** が最もずれにくくなります。折りたたみの **条件で選ぶ · コスト比較** で最大レイテンシー · CPUで絞り込んで選ぶこともできます。20 Hz–18 kHzの応答はすべてのフィルターで実質的に同じで、異なるのは20 kHz以上と時間応答です。長タップ拡張に **Cardinal Sinc 128K** · **Cardinal Sinc 64K** があり、それぞれソースレートに合わせてカットオフを追従させる **追従** ペアがあります（44.1 · 48 kHzの曲ではペアと同じ音です）。すべて固定長sincで、レイテンシーはリストに記載の値（128K 約116 ms · 64K 約70 ms、44.1 kHz系統）です。これらのフィルターは自動検査と測定でのみ確認しており、聴き比べたものではありません。
2. **DSD変換** — **変換方式** は **安全**（5次、軽め） / **精密（デフォルト）**（7次 · 推奨） / **CLANS**（テスト） / **Trellis**（テスト · 負荷大）、出力レートはDSD128 / DSD256。DSD256はそのDACで確認されたあとにデフォルトになります。**CLANS** は0.7.0で新しく追加されたテスト用の変換方式で、ノイズシェイプを固定した7次変調器であり、「精密」と同じ保護を使います。44.1 kHz系統のDSD128 · DSD256でのみ使え、ディザーとは併用せず、選ぶと「CLANS はテスト中の方式です。途切れたりおかしいと感じたら「精密」に戻してください。」が表示されます。Trellisはテスト中の方式です — 先に来る音まで見越してビットを選び、7ビット遅れて出力され、実験ディザーとは併用しません。選ぶと「Trellisは試験中の方式です。音が途切れたり、おかしく聞こえたりする場合は「精密」に戻してください。」が表示されます。音が途切れると同じ案内がもう一度表示されますが、方式を自動で変えることはありません。このMacがTrellisの計算を時間内に終えられない場合は再生を止め、「このMacではTrellisの処理が間に合わず、再生を停止しました。「精密」「安全」またはCLANS変調器を使うと負荷が下がります。」と **変換方式を選ぶ** ボタンが表示されます。押すとこの変換方式の選択に移動します。「精密」が常にデフォルトであり、手動で選ばない限り変わりません。
   - **ディザー** — 安全方式で選びます。「精密」の新しいディザー選択は配布版では提供されておらず、以前の設定でディザーがオンになっている場合はオフにできます。CLANS · Trellisはディザーを使用しません。
3. **PCMヘッドルーム** — **自動（推奨）** がデフォルトです。EQ · Ostrumが持ち上げた分だけ全体を下げてクリッピングを防ぎます。スライダー · ボタンで変えると **手動** になり、**自動に戻す** で戻ります。アプリを再起動すると自動になります。DACのボリュームとは異なります — 聴こえる音量はDACで調整します。

- **バッファー** — 入出力 › 詳細で選び、DSD · PCMオーバーサンプリング · PCM Directに共通で適用されます。低レイテンシー · 標準 · **安定（デフォルト）**。音質は同じで、操作が聴こえるまでの時間と音切れへの強さのみが異なります。停止状態で変更し、次の再生から適用されます。
- **現在の設定をプリセットとして保存…** — ① フィルター · ② DSD変換（実験ディザー含む） · ③ ヘッドルームを1つのプリセットとして保存します。保存したプリセットは下部バーの出力方式メニューからも選べます。
- **現在の選択ガイド** — 選んだフィルターが何を変え、どこを聴き、何を引き受けているかと、周波数応答グラフがあります。
- 精密変調器が不安定になり安定化が働いた場合は、回数とともに「安全に切り替える」 · 「DSD256に切り替える」を提案します。

### 7.5 Playback Chain · 実際の動作・診断

- **Playback Chain** カード — ウィンドウヘッダーのもの（[§2.1](#21-ページヘッダ)）と同じです。「出力を安全に停止しました。」が表示されたら **DACを再接続** を押します。
- **実際の動作・診断**（折りたたみ） — リクエストしたレートと実際のレート、残りのヘッドルーム、出力レイテンシーの推定値、音落ち · 途切れの回数。レイテンシーはソフトウェアによる推定値であり、DACのアナログ出力を実測したものではありません。

### 8.1 YouTube Musicを使う（Chrome拡張機能）

YouTube MusicはSafari · Chrome · Edgeで聴きます。音はFidenne Inletが受け取ってFidenneへ送り、拡張機能は **曲情報と操作** を追加します — 下部バーに曲が表示され、バーの再生 · 停止 · 次へ · 前へがそのタブを操作します。**実験的機能** であり、YouTube Musicが画面を変更すると動作が止まることがあります。他のサービスが再生中のときにYouTube Musicのタブが勝手に（自動再生 · 連続再生）音を出そうとすると、Fidenneはそのタブを止め、聴いていた曲をそのまま維持します（`自分で再生を始めたYouTube Musicのタブを停止しました — 聴いていた曲はそのままです`）。そのページで直接押すか、FidenneからYouTube Musicの曲をかけたときはYouTube Musicが音を引き継ぎます。

**YouTube Musicページの自動再生スイッチはオンでもオフでも構いません。** Fidenneのリストを再生している間はFidenneが元の状態を記憶し、必要なときにスイッチを一時的にオフにしてリスト順に曲を最後まで聴けるようにします。リスト制御が終わるか、アプリと拡張機能の接続が切れると元の状態に戻します。その間に手動で変更した状態は上書きしません。リストの最後でYouTube Musicが選ぶ曲へ続けて聴くには、Fidenneの **現在のプレイリストが終わったらYouTube Musicの自動再生で続けて聴く** とページの自動再生の両方をオンにします。

**初回のみ — 拡張機能のインストール（デベロッパーモード）**

1. 設定 › **一般** の **YouTube Music（実験的機能）** をオンにします。
2. 設定 › **プライバシー** › **YouTube Music** で **ブラウザの機能拡張と接続（Safari・Chrome・Edge）** をオンにします。
3. 同じ場所の **インストール案内…** を押します。小さな案内ウィンドウのヘッダーで **Chrome** または **Edge** を選びます。
4. **① アドレスをコピー** → ブラウザのアドレスバーに貼り付けてReturn（`chrome://extensions` · `edge://extensions`）。
5. **② デベロッパーモード** をオンにします。
6. **③** 新しく現れた **パッケージ化されていない拡張機能を読み込む**（Edgeは **Load unpacked**）を押します。案内ウィンドウの **パスをコピー** → フォルダー選択ウィンドウで **⌘⇧G** → **⌘V** → Return → **開く**。
7. **④** 開いていたYouTube Musicのタブを再読み込みします(⌘R)。
8. **タブのスリープ除外** — ブラウザが使っていないタブをスリープさせるとYouTube Musicが応答できなくなります。Chromeは 設定 › パフォーマンス › メモリセーバー › **常にアクティブにするサイト**、Edgeは 設定 › システムとパフォーマンス › リソースの節約 › **これらのサイトをスリープ状態にしない** に `music.youtube.com` を追加します。Safariにはサイトごとに指定するスリープ除外がないため、バーが止まったらそのタブを1回再読み込みします。

**うまくいったかの確認** — 案内ウィンドウの一番下の行が **ブラウザ 1個 接続済み** になり、music.youtube.comで曲をかけると下部バーにその曲が表示されます。

**使い方**

- **ストリーミングページから再生する** — サービスで **YouTube Music** を選ぶと、読み込んだプレイリスト · 検索欄が表示されます。曲を押すとYouTube Musicのタブでその曲から再生します。Chromeが閉じている場合はFidenneがバックグラウンドで起動します。
- **ブラウザが最初の再生をブロックしたら** — `ブラウザが最初の再生をブロックしました・タブで▶を1回クリックしてください` が表示されます。**ブラウザで▶を1回クリック** を押してそのタブで▶を1回押すと、それ以降はバーのボタンが効くようになります。ブラウザは人がクリックしていないページが勝手に音を出すのを防ぐためです。Edgeは `edge://settings/content/mediaAutoplay` でmusic.youtube.comを **許可** に入れると、この1回の操作が不要になる場合があります（未確認）。
- **複数のブラウザ** — 拡張機能が2つ以上のブラウザに接続されており、現在選んでいるブラウザではない方でYouTube Musicを再生し始めると、Fidenneはそのブラウザへ切り替えて `再生中のブラウザ: <名前>` と1行通知します。Fidenneが再生コマンドを送った直後の数秒間は切り替わらず、先ほど止めたタブへは戻らず、選んでいたブラウザの接続が切れたまま別のブラウザが再生中の場合もそちらへ移ります。
- **どのブラウザへ送られるか** — Fidenneで曲を選ぶ操作（曲 · リストの再生 · ホーム · 検索）は、YouTube Musicのタブを **最後に前面にしていたブラウザ** へ送られます。たとえばEdgeで聴いていてSafariでYouTube Musicを開いた場合、次の曲選びはSafariへ行き、開始するとEdgeのタブは停止します。1つのブラウザにタブが複数ある場合は最後に前面にしていたタブです。バーの再生 · 停止 · 次へ · 前へは現在表示されているタブを操作します。接続されたブラウザにYouTube Musicのタブがない場合、FidenneはそのブラウザでYouTube Musicを開きます。この動作は拡張機能0.4.50からです — 古い拡張機能は従来通りに動作します。
- **タブが応答しないとき** — 曲を押したのにそのタブが応答しない場合、Fidenneはそのタブを1回再読み込みします（30秒に1回まで）。古い拡張機能の場合はタブを手動で再読み込みしてください(⌘R)。
- **プレイリストを取り込む** — YouTube Musicでプレイリスト画面を開くと、表示されている曲がFidenneの **マイプレイリスト** に `12曲 · ブラウザから · …` のように保存されます。長いリストは最後までスクロールすると続けて取り込まれます。**リストを削除** はFidenne側からのみ削除します。
- **右クリックで取り込む** — music.youtube.comの曲メニュー(⋮)一番下の **Fidenneに追加 ›**、またはブラウザの右クリックメニューの **この曲をFidenneに追加 ›** で、曲1つを **Fidenne いいね (♥)** · Fidenneプレイリスト · **新しいプレイリスト…**（「プレイリスト N」として作成され、名前はアプリで変更します）に追加でき、プレイリスト画面では **このリストをFidenneに追加** でリスト丸ごとを追加できます。
- **ライブラリ** — YouTube Musicのライブラリ（高く評価した曲 · プレイリスト · アルバム · アーティスト）画面を直接開くと、そのリストを取得してきます。**次に再生** にはFidenneで再生したリスト、そうでなければタブの「次のトラック」リストが表示されます。
- **音量 · 音質** — Playback Chainの音源行でページの音量が100 %でない場合はオレンジ色になります — YouTube Musicの音量バーを最大まで上げます。音質 — Premiumの場合はYouTube Musicのプロフィール写真 › **設定** › **再生と制限** › **オーディオ品質** を **高** にします。広告中は曲情報を表示せず「広告中」とだけ表示します。
- **アプリをアップデートしたあと** — `chrome://extensions` の **Fidenne for YouTube Music** カードで再読み込み(↻)を1回押します。`ブラウザの拡張機能が古い版…` の行が残る場合は **拡張機能フォルダーを開く** を押してからもう一度 ↻。Fidenneアプリに同梱される拡張機能が新版(0.4.50)であるため、この ↻ をしないと新しい動作が反映されません。
- やり取りされるのは曲名 · アーティスト · アルバム · 長さ · 位置 · キュー · アルバムアートなどで、このMacの中だけでやり取りされます。デベロッパーモードでのインストールが基本で、Safariはアプリ内に組み込まれています（[Safariで使う](#safariで使う)）。
- **保存する** — アルバムヘッダーの **YouTube Musicに保存** は、拡張機能が開いているアルバムページの保存コントロールを1回クリックします（[§3](#3-ストリーミングページ)）。拡張機能が古い版の場合は保存の代わりに **YouTube Musicで開く** のみが表示されるので、前述の **アプリをアップデートしたあと** を実施してください。

#### Safariで使う

Safari機能拡張はFidenneアプリ内に含まれているため、別途インストールするファイルはありません。設定 › 一般の **YouTube Music（実験的機能）** をオンにし、Safariで機能拡張を許可します。設定 › プライバシーの **ブラウザの機能拡張と接続（Safari・Chrome・Edge）** スイッチはChrome · Edge接続用であり、Safariとは別です。

1. まずFidenneがアプリケーションフォルダにあるか確認します。ダウンロードした.dmgの中やダウンロードフォルダから開いたままではSafariが機能拡張を表示せず、その場合FidenneのSafari欄と設定 › プライバシー › YouTube Musicに `Safari機能拡張は、Fidenneをアプリケーションフォルダに移動して開き直すと、Safariに表示されます。` と表示されます。Fidenneを終了してアプリを **アプリケーション** フォルダに移動し、そのフォルダから開き直します。
2. 設定 › プライバシー › YouTube Musicの **Safariの設定を開く**（YouTube Music接続ウィンドウのSafari欄にもあります）を押します。Safariの機能拡張設定が開いたら、FidenneのYouTube Music機能拡張をオンにします。Safariだけが開いて機能拡張設定が見えない場合は、Safari › 設定 › **機能拡張** でオンにします。
3. music.youtube.comを開き、Safariのアドレスバー横の機能拡張アイコン列からFidenneアイコンを押して、このWebサイトで機能拡張を許可します（**常に許可** を選べば1回で済みます）。Safari › 設定 › **Webサイト** でも同じ許可設定を確認できます。
4. そのタブを再読み込みします(⌘R)。

**うまくいったかの確認** — music.youtube.comで曲をかけると下部バーにその曲が表示されます。Safari 18.4以降が必要です。Fidenneアプリはアプリケーションフォルダにあっても、ホームフォルダのApplicationsフォルダにあっても構いません（.dmgの中やダウンロードフォルダから開いたアプリは不可）。Safariは使っていない機能拡張をスリープさせることがあるため、バーが止まったらそのタブを1回再読み込みします。**Fidenneをアップデートしたあとは** Safariが機能拡張を再読み込みするため、開いていたYouTube Musicのタブを1回再読み込みします(⌘R)。接続がずれた場合は、ストリーミングページの拡張機能の行の下に `Safariから音が出ていますが、Safari機能拡張がFidenneとつながっていません・YouTube Musicのタブならそのタブを再読み込みしてください` または `Safari機能拡張はつながっていますが、YouTube Musicのタブが応答していません・そのタブを再読み込みしてください` が表示されます。使っていないSafariには何も表示しません。

### 8.2 YouTube Musicアプリウィンドウ — 現在はなし

Fidenneウィンドウ内でYouTube Musicにログインして聴く方式は現在ありません。YouTube Musicは [§8.1](#81-youtube-musicを使うchrome拡張機能)の拡張機能で使います。そのウィンドウでログインしたことがある場合は、残ったWebストレージをFidenneを終了したあとターミナルで `rm -rf ~/Library/WebKit/*/WebsiteDataStore/5c0f7e2a-3b1d-4e8f-9a6c-2d7b8e1f4a90` により削除し、Googleアカウントの「お使いのデバイス」からログアウトします。

## 10. サポートファイルの送信

問題が発生したときに、何が起きたかをまとめた診断バンドルを作成して送信します。

1. **ヘルプ › 問題報告用の診断を作成…** をクリックします（設定 › 一般 › ヘルプにも同じボタンがあります）。
2. 初回起動時に「問題報告用の診断記録」に同意している場合はすでに記録されているため、問題が発生したあとアプリを終了する前にすぐバンドルを作成します。オフにしていた場合は **診断記録を開始** をクリックしておき、次に問題が発生したときに作成します。
3. **バンドルを作成して内容を表示** で含まれる内容を確認します。バンドルは .zip ファイルとしてダウンロードフォルダに保存されます。
4. **メールで送る** をクリックすると、メールアプリが宛先・件名・本文のひな形を入力した状態で開きます。別のメール（Gmail など）を使う場合は、隣の **メールのひな形をコピー** で同じ内容をコピーして貼り付けます。ダウンロードフォルダの .zip ファイルを直接添付してください。内容をコピーして貼り付けると文字数制限で途切れ、問題が発生した時点の記録が欠落することがあります。ファイルが見つからない場合は、Finder の「ダウンロード」を開きます。アプリのバージョンと macOS のバージョンは、ひな形とバンドルに自動的に含まれます。

**確認方法** — メールアプリで新規メールが開き、**zipファイルを表示** で Finder 上に .zip ファイルが選択された状態で表示されます。

- **今おかしかったことを記録** — 違和感があった瞬間に ⌥⌃⌘K（ヘルプメニューにもあります）を押すと、その時刻だけがこの Mac の診断記録にマークされ、バンドル内でその箇所を見つけやすくなります。診断記録に同意していなくても記録され、外部に送信されることはありません。バンドルを作成する際、書き出しウィンドウに **ご自身で記録した時刻** と **ご自身で確認されていませんが、こんなことも起きていました**（音途切れや停止など自動で検出された事象）が分けて表示され、項目ごとにバンドルに含めるかどうかを選べます。
- バンドルには数値やステータス、その時間帯に聴いた曲の時刻・サービス・レートと曲ごとに付くランダムなラベル（直近 200 曲まで）が含まれます。ファイルパス・デバイス名・アカウント情報は含まれません。
- **診断バンドルはメールでお送りください — GitHub の Issue にはアップロードしないでください。** 送信するかどうか、どこに送るかはユーザー自身が決めるもので、アプリが勝手に送信することはありません。お送りいただいた報告とバンドルは AI ツール（Anthropic の Claude など）で読み取る場合があります（[プライバシー](../../../PRIVACY.ja.md)）。診断メニューの **サポート用の診断を書き出す…** でも同じバンドルを作成できます。
- あわせて記載するとよい内容は [トラブルシューティングガイド §9](TROUBLESHOOTING.md#9-それでも解決しない場合--何を集めて送ればよいか) をご覧ください。

## ベータ版のご案内と報告先

Fidenne は現在 **パブリックベータ** です。`https://github.com/fidenne/fidenne/releases` からダウンロードできます。Apple シリコン搭載 Mac と macOS 15 以降が必要です。

- 問題の報告はメール **fidenne.support@gmail.com** が基本です。リポジトリの Issue（**バグ報告** テンプレート）には症状のみを記載しても構いません。診断バンドルやセキュリティ上の問題は、Issue ではなくメールでお送りください。
- あわせて記載するとよい情報：DAC と出力方式・いつ何をしていたときに何が聞こえたか。アプリのバージョンと macOS のバージョンはメールのひな形とバンドルに自動的に含まれます。

詳しい手順は [タスク別ガイド §30](HOW-TO.md#30-ベータ版を入手して問題を報告する) を参照してください。
